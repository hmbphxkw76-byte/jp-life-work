一、主题核心概述

1.1 主题定义与监测范围

含（business-config 3.1）：面向个人地域决策支持——地域选择框架（7 维评分框架、候选地域速览、决策流程）；地域间公共服务差异视角（医疗资源地域差、教育资源地域差）；地域生活笔记（定居地档案模板、生活发现、防灾与安全、地域防灾情报渠道、季度观察）。 不含（交叉引用，不在本主题展开）：薪资地域差；求职渠道地域策略；保险体系与就医流程细节；就学手续与学制细节；灾害时外国人支援政策环境；岗位密度 / 薪资地域差活值。

1.2 受众与用途

输出地域选择框架、地域差对比与决策输入；不给落户价位、不给单一「最优地域」结论；个人地域选择为自记录个案，标注记录日期；统计类数据注明都道府県 / 市町村口径（business-config 第二节）。

1.3 核心监测问题

  1. 候选地域在 7 维评分框架（岗位供给、薪资×成本、外国人支援、同胞密度、交通/归国便利、灾害风险、生活品质）下如何横向比较？
  2. 目标地域的司机求人件数、賃貸挂牌行情等预期指标最新读数如何？
  3. 地域间公共服务差异（医师数 / 病床数、日语指导体制）的最新官方数据与地域差结构如何？
  4. 外国人支援窗口与多语言防灾情报渠道的可得性在自治体间差异如何？
  5. 个人地域选定期与定居地档案何时可建立并滚动维护？

三、当前现状梳理

3.1 岗位供给（目标地域司机求人件数）

  • 登记册 #1「目标地域司机求人件数」：待基线确立（优先数据源 HelloWork 地域检索）。
  • 口径与触发（登记册 / business-config 第七节）：求人件数 = HelloWork 地域检索，在招口径 ≠ 实际雇佣人数；目标地域岗位密度 / 条件显著变化（联动 02-career-driver 求人抽样）→ 01。

3.2 居住成本（賃貸挂牌行情）

  • 登记册 #2「目标地域賃貸挂牌行情（预期指标）」：待基线确立（优先数据源 賃貸门户）。
  • 口径（business-config 第四节 / 登记册）：登记口径（地価公示）≠ 挂牌口径（賃貸门户），预期指标 ≠ 实际成交 / 登记值；薪资×成本维度按"名义薪资 − 房租 / 物价 = 可支配"评估，"地方" ≠ "东京圈"的薪资对比须同岗位分层。

3.3 外国人支援（支援窗口与多语服务）

  • 登记册 #3「目标地域外国人支援窗口」：待基线确立（优先数据源 自治体官网）。
  • 候选地域速览（事实，基线报告，"待实地补充"）：埼玉（本庄 / 深谷 / 熊谷）物流仓密集、近东京、成本中；群马（太田 / 伊势崎）传统物流重镇、外国人多；爱知（名古屋周边）岗位最厚、支援体制最成熟；静冈（富士 / 沼津）新东名自动驾驶实证沿线；福冈（北九州 / 福冈）归国方便、薪资佳；北海道 / 东北 薪资含冬季手当、豪雪初学者不宜。
  • 决策流程（事实，基线报告）：Offer 阶段用 7 维框架打分（≥3.5 考虑）；入职前读该自治体「外国人生活ガイド」（官网多有中文版）；落地 1 个月后实际体验 vs 预期复盘，写入 02-地域生活笔记。
  • 多语言防灾情报渠道（事实，基线报告，2026-11-12 验证）：国家预警 = 气象厅警報・注意報（jma.go.jp）；多语言版 = 防災気象情報多语言版（含简体中文，data.jma.go.jp）；中央防灾 = 防災庁（2026-11-02 由内阁府防灾改组发足，bousai.go.jp）；多语言灾情媒体 = NHK WORLD-JAPAN 多语言链接（约 20 种语言，nhkworld）。
  • 待复核：自治体防灾邮件 / LINE 公式账号 / 防灾行政无线的具体渠道与登记方式（待定居地确定后补）。

四、初步结论

结论 1：本主题当前处于"框架就绪、活值待建"状态。证据：7 维评分框架与决策流程已建立（基线报告 01 节）；登记册 #1–#4 均待基线确立 / 待记录。标注：事实。

结论 2：地域差在公共服务领域呈系统性存在。证据：病院一般病床 879,728 床（厚生労働省 令和 6 年医療施設調査，2024-10-01）；日本語指導が必要な児童生徒 84,759 人、其中外国籍 73,313 人、较上次 +27.0%（文部科学省，令和 7 年度）。标注：事实。

结论 3：横向比较须先固定口径，否则存在混算风险。证据：登记册口径清单列明登记口径 ≠ 挂牌口径、都道府県 ≠ 市町村、従業地 / 居住地口径须区分。标注：事实。

结论 4：不就学风险与日语指导资源存在地域差。证据：调查已全国实施但自治体间把握体制仍有差异；日语指导教室有无、教员配置密度因自治体差异大（基线报告标注「推断」）。标注：推断。

结论 5：候选地域速览为定性判断，不构成「最优地域」结论。证据：基线报告候选地域速览表（自述"待实地补充"）；business-config 第二节结论边界。标注：事实（属定性清单，非排名）。

结论 6：多语言防灾情报已具备国家级入口，自治体层登记动作待补齐。证据：气象厅多语言版、NHK WORLD-JAPAN 多语言链接可访问（2026-11-12 验证）；自治体防灾邮件 / LINE 具体渠道待定居地确定后复核。标注：事实 + 待办。

风险与不确定性：

  • 登记册 4 项活值均未建立，报告无法给出数值化地域对比。
  • 门户数据为预期指标，不等于实际成交 / 登记值。
  • 统计域口径（都道府県 vs 市町村、従業地 vs 居住地）未固定前，地域差解读存在混算风险。
  • 基线报告无免责声明节与顶部导航（遗留项，待下一期重写补齐）。
  • 个人定居地档案为空白模板，个人地域选择尚未记录。
