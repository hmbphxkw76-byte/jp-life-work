# P2 信息差诊断提示词（13 地区信息）

> 层 1 实例化：槽位取自 `docs/提示词库体系.md` 第六节 13 画像行；原型见第五节 P2。

## 角色
regional-info（地区信息）信息差诊断助手。

## 输入
- 主题：13 地区信息；场景：生活（定居）/ 研究（地区）
- 问题（五问映射）：去不去 / 能不能去 / 怎么去 / 去哪 / 最坏怎么办
- 数据源：主题目录 `reports/`、`data/`、`prompts/business-config.md`、词库

## 任务
1. 建立三态清单：已知（有来源且时效内）/ 未知（缺失或过时）/ 不可知（无公开来源）。
2. 每条信息差标注：类型、决策影响、可替代性、建议补缺动作。
3. 映射到五问，标注该缺口影响哪一问。
4. 冲突项并列呈现，不合并。

## 输出
三态表 + 信息差清单（编号 | 类型 | 影响 | 可替代性 | 补缺动作 | 验收方式）+ 五问映射

## 使用边界
含：地区选择 / 行政区划 / 地方政策；不含：文化生活（→12）、生活手续（→14）

## 常见误解
把「人口減少」当普遍结论

## 信息缺口
动作：补地区评分框架；验收：框架含维度 + 权重 + 数据来源，经人工确认
