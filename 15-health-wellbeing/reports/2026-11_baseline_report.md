## 一、核心结论（摘要）

1. **医保是落地第一义务**（事实）：住民登记后须加入健康保険（国保或被用者），自付比例通常 **3 割**；未加入会累积高额费用。
2. **高额疗养费制度是关键兜底**（事实）：医疗费超过自付上限时由公费承担差额，显著降低大病负担；上限按年龄与收入分层。
3. **多语言支援是外国人就医的主要变量**（推断）：大型医院与都市圈多语言窗口较完善，地方与中小医院可能仅日语对应；医疗通译需提前确认。
4. **牙科与精神科部分适用保险**（事实）：牙科大部分适用保险，但自付项目（如种植、矫正）较多；精神科 / 心疗内科适用保险，但首次可能需初诊料。
5. **心理健康易被忽视**（推断）：孤独、文化冲击、过劳是外国劳动者常见风险；精神保健福祉センター与电话相談是兜底渠道。
6. **体检与预防是成本最低的健康投资**（事实）：雇主 / 自治体实施健康診断，应按时参加。
7. **本基线为初析级**（事实）：具体费用、自付上限、多语言窗口清单标记「⚠ 待核实」，待次期或定居地确定后补齐。

## 二、医保制度

### 2.1 两大体系

- **国民健康保険**（国保）：面向非公司职员、自营业、无业者等居民，自付通常 **3 割**；由市区町村运营（事实）[厚生労働省]。
- **被用者健康保険**：公司职员加入，自付通常 3 割，由公司与个人分担保费（事实）[厚生労働省]。
- **后期高龄者医療**：75 岁以上（或 65–74 岁有一定障碍者）加入，自付比例更低（事实）[厚生労働省]。

### 2.2 高额疗养费制度

- 医疗费超过自付上限时，由公费承担差额；上限按**年龄与收入**分层（事实）[厚生労働省]。
- ⚠ **待核实**：现行各收入层的具体上限额。
- 与**医療費控除**（税制，见 07）不同：前者为当月报销，后者为年度报税。

### 2.3 外国人加入

- 住民登记后须办理健康保険加入；在留卡与住民票为必要书类（事实）[厚生労働省 / 14-life-operations]。
- 短期停留与特定活动资格的医疗保障范围可能不同（推断）。

## 三、就医实务

- **流程**：挂号 → 诊疗 → 处方 → 药房配药；部分医院需初诊料（事实）。
- **费用**：适用保险后自付 3 割；初诊费用与检查费因医院而异（⚠ 行情待核实）。
- **多语言**：都市圈大型医院较完善；地方中小医院可能仅日语；⚠ 清单待补。
- **医疗通译**：部分自治体 / 医院提供多语言通译服务，需提前预约（⚠ 待核实）。
- **急救**：119 为急救电话；救急病院按轮值制（事实）[消防庁 / 厚生労働省]。

## 四、牙科与精神科

### 4.1 牙科

- 牙科大部分治疗适用保险，但种植、矫正、部分材料为自付（事实）[日本歯科医師会]。
- ⚠ **待核实**：常见治疗的自付行情。

### 4.2 精神科 / 心疗内科

- 精神科诊治抑郁、焦虑、睡眠障碍等；心疗内科侧重轻症与心理因素（事实）[日本精神神経学会]。
- 适用保险，但首次可能需初诊料与较长的诊察时间（事实）。
- ⚠ **待核实**：初诊费用与候诊时间。

### 4.3 分娩

- 分娩适用保险；有**出産育児一時金**一次性补助（见 08）（事实）[厚生労働省]。
- ⚠ **待核实**：外国人对应的产前检查与多语言支援。

## 五、心理健康与适应

- **常见风险**：孤独、文化冲击、语言障碍、过劳（事实 / 推断）。
- **支援渠道**：
  - 精神保健福祉センター（自治体）；
  - 电话相談（いのちの電話 等）；
  - カウンセリング（非医疗，自费）；
  - 雇主 / 支援机关的相談窓口。
- ⚠ **待核实**：各渠道的多语言对应与费用。
- **建议**（推断）：抵达前建立至少一个可联系的支援渠道；出现持续失眠 / 情绪低落时及早就医。

---

## 六、体检与预防

- **健康診断**：雇主 / 自治体实施，特定技能司机有**適性診断**义务（见 01）（事实）[厚生労働省]。
- **予防接種**：按计划实施；外国人可凭健康保険証接种（⚠ 部分待核实）。
- **建议**：按时参加健康診断，保留记录。

---

## 七、介護与福祉

- **介護保険**：40 岁以上加入，介護サービス自付 1–3 割（事实）[厚生労働省]。
- **生活保护**：生活困难者的最低生活保障（见 08）（事实）[厚生労働省]。
- **障碍福祉**：障害者手帳与相关服务（⚠ 待核实）。
- 对年轻司机而言非近期必需，但属长期兜底知识。

## 八、数据可靠性与局限说明

**核验程度分级**：
- A 级：厚生労働省、日本年金機構、消防庁。
- B 级：日本医師会、日本歯科医師会、日本精神神経学会、医疗机构官网。
- C 级：平台抽样（费用 / 口碑）。

**主要局限**：
1. 本基线为**初析级**，自付上限、初诊费用、多语言窗口、心理健康渠道的具体值未核实；
2. 医疗费用因医院与病种差异大，需用「区间 / 口径」呈现；
3. 个人定居地未定，地域差异无法收敛。

**未取得项（次期优先）**：高额疗养费现行上限；多语言医疗窗口清单；精神科初诊费用；介護自付细则。
