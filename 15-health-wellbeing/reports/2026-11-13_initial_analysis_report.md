## 一、主题核心概述

**主题定义**：在日外国人的医疗制度与健康管理——医保体系、就医实务、多语言支援、牙科精神科、心理健康、体检预防、介護福祉。

**监测范围（含）**：国保 / 被用者 / 后期高龄者 / 高额疗养费；就医流程与费用；多语言与通译；牙科 / 精神科 / 分娩；心理健康与适应；健康診断 / 予防接種；介護保険 / 福祉。

**监测范围（不含）**：社保费 / 年金 / 税（→ 07-economy-finance）；在留 / 家属 / 生活保护（→ 08-visa-immigration）；劳动安全 / 过劳（→ 09-politics-law / 03-career-management）；文化适应（→ 12-culture-life）；地域医疗差异（→ 13-regional-info）；保险加入手续（→ 14-life-operations）。

**核心监测问题**：
1. 医保自付比例与高额疗养费上限如何？
2. 就医流程与多语言支援是否可行？
3. 牙科 / 精神科 / 分娩的费用与保险适用如何？
4. 心理健康的支援渠道有哪些？
5. 体检与预防的参加方式如何？
6. 介護福祉的兜底机制是什么？

## 三、当前现状梳理

- **医保**：国保 / 被用者自付通常 3 割；高额疗养费为兜底（事实）[厚生労働省]。
- **就医**：流程标准化，但多语言与通译因医院而异（推断）。
- **牙科 / 精神科**：部分适用保险；自付项目与初诊费用需具体核对（⚠ 待核实）。
- **心理**：孤独、文化冲击、过劳为常见风险；精神保健福祉センター与电话相談为兜底。
- **体检**：健康診断按时参加；特定技能司机有適性診断义务。
- **介護**：40 岁以上加入；非近期必需但属长期兜底。

## 四、初步结论

1. **医保是刚性义务**（事实）：住民登记后必须加入。
2. **高额疗养费是关键兜底**（事实）：上限按年龄 / 收入分层。
3. **多语言是主要变量**（推断）：都市圈较好，地方需提前确认。
4. **心理健康易被忽视**（推断）：建议提前建立支援渠道。
5. **具体值仍为信息差**（事实）：自付上限 / 费用 / 窗口清单待补。
