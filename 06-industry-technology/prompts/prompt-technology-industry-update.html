09 技术与数字化 · 动态更新提示词

用途：周期性刷新「技术与数字化」知识库，动态获取物流 DX 政策、数字化岗位采用条件、技能需求的最新官方口径，保持个人技能对照与转型评估同步。可直接整体复制，替换顶部变量后提交给 AI 执行。

继承声明（三层体系）：本文件 = 通用基座 × 知识库主题更新类型模板 × 本主题专属配置。冲突时本文件优先。

运行变量（每次运行前填写）

{{TOPIC_DIR}}            = 06-industry-technology（固定）
{{HANDBOOK_PATH}}        = 06-industry-technology/reports/日本技术与数字化知识手册.md
{{DOC_LIST}}             = 手册内对应章节（由主题提示词第五节声明）

一、主题专属硬性约束

通用约束（逐点引用、事实与推断分离、口径标注等）自动继承通用规范第一至四节。本主题额外强制：

  1. 受众定位："阶段 4 技术/数字化扩展"准备库：物流数字化技能地图、数字化岗位与转型路径。与 04-industry-logistics（产业趋势）、05-industry-autonomous（自动化）互补：本主题写个人技能与岗位对接。
  2. 术语口径区分（正文中不得混用）：
  3. WMS ≠ TMS ≠ WCS；
  4. 「オペレーター」≠「システム担当」≠「改善/分析岗」；
  5. 技能等级自评须注明评估标准版本。

二、来源优先级（通用框架的本主题实例化，冲突时报双份并标注）

① 国土交通省/経済産業省（物流 DX 政策、GX）＞ ② 日本ロジスティクスシステム協会、WMS/TMS 主要厂商（Netsuite、楽天ロジスティクス、CASSA 等）官方资料 ＞ ③ 求人门户系统岗频道（预期指标）＞ ④ 技术学习平台（官方文档优先）

三、基线锚定（防止已修正事实回退）

更新时必须读取 {{HANDBOOK_PATH}}（单份知识手册）与受影响章节的当前版本（含 reports/archives/ 内历史版），继承其结构与全部已核实结论。本清单随每次修正持续追加：

- ❌（首期为空）——产生修正后逐条补记。

四、更新协议 + 事件触发器表

刷新窗口与差异对比规则继承通用模板。本主题必查重大事件触发器（命中任一项即触发对应文档重点更新；无触发则降级为核验/收敛型轻运行，不得为制造变化而虚构变化）：

- 物流 DX 政策/补贴新动向 → 01
- 目标数字化岗位采用条件变化 → 02
- 新工具/系统技能需求出现 → 01/02
- 个人技能里程碑（证书/项目完成） → 01/02

五、手册章节更新要点（知识库主题更新类型）

明确要动态获取 / 保持的内容：

【导航与使用约定】更新：篇目状态与最近更新日期；保持：篇目结构（手册前部导航区，含更新日志）
【01 物流数字化技能地图】动态获取：岗位技能要求抽样、政策推动的技能需求；更新：个人技能对照；保持：技能地图框架
【02 数字化岗位与转型路径】动态获取：转型岗位求人抽样（标注口径）；更新：路径评估（推断标注）；保持：路径框架

七、执行方式（建议）

  1. 启动 1–2 个并行研究子代理：① 物流 DX 政策与技能需求；② 数字化岗位求人抽样。全部限定日/英来源、逐点引用，每条数据必须附可直接访问的 URL；求人门户数据标注为预期指标。
  2. 子代理返回后，由主代理读取 {{HANDBOOK_PATH}}（单份知识手册）与受影响章节当前版本做差异合并，继承已修正事实、应用第四、五节更新要点。
  3. 对冲突数据保留双份引用；对无法核实项单列"待复核清单"。
  4. 回写完成后运行 python prompts/tools/md2html.py 06-industry-technology/reports 重新生成 HTML；运行 python prompts/tools/archive_reports.py 执行保留策略。

八、输出格式要求

  • 增量回写 {{DOC_LIST}} 中受影响章节；未受影响章节不动；结构性内容（技能地图框架、路径框架）按第五节"保持"。
  • 变更摘要与待复核清单写入手册内「导航与使用约定」的更新日志区（格式见知识库模板 T3），不单独成文。
  • 正文新增数据点一律附 [Source: 完整URL, 年份]；表格按通用规范二.2 呈现（主题文字超链接 + hover 来源，不设"来源"列）；推断显式标注。
  • 新增知识在现有文档中找不到位置时，在手册内新建 ## NN 章节（编号顺延）；禁止把不相关内容塞进既有章节，禁止新建独立 .md 文件。
  • 文件命名与保留策略：reports/ 顶层保留最新 3 份（*_baseline 基线版固定保留，永不进入 archives），其余入 reports/archives/，归档上限 7 份。

  • [ ] 技能等级自评均注明评估标准版本
