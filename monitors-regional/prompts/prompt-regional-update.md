## 一、主题定位与受众

就业地选择与地域生活库：地域选择框架（岗位密度、薪资、生活成本、外国人支援）+ 地域生活笔记。地域数据须注明都道府県/市町村口径。

## 二、来源优先级实例化

① 国土交通省（住居・地価統計）、総務省統計局（地域统计）、各都道府県/市町村官网 ＞ ② HelloWork 地域检索（岗位密度一手聚合）、JETRO 地域信息 ＞ ③ 賃貸/生活门户（挂牌口径，仅预期指标）＞ ④ 地域媒体。

## 三、术语口径区分

登记口径（地価公示）≠ 挂牌口径（賃貸门户）；勤務地 ≠ 注册地 ≠ 通勤圈（继承 monitors 求人四元组教训）；"地方"≠"东京圈"的薪资对比须同岗位分层。

## 四、事件触发器表

```
- 目标地域岗位密度/条件显著变化（联动 monitors-career-driver 求人抽样） → 01
- 地域生活支援制度变化（自治体） → 02
- 个人选定目标地域 → 01/02
```

## 五、文档群更新要点

```
【00-index】更新：篇目状态与最近更新日期；保持：篇目结构
【01 地域选择框架】动态获取：目标地域岗位密度（HelloWork 地域件数）、薪资地域差（锚 monitors 岗位 × 地域分层）、生活成本地域差；保持：选择框架与评分维度（推断标注）
【02 地域生活笔记】动态获取：目标地域自治体多语言支援、外国人登记相关制度；更新：个人笔记；保持：笔记结构
```
