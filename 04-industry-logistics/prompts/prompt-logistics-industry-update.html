一、主题专属硬性约束

通用约束（逐点引用、事实与推断分离、口径标注等）自动继承通用规范第一至四节。本主题额外强制：

  1. 受众定位：日本物流产业的中观研究库：产业概览、增长赛道（EC/冷链/3PL）、自动化趋势、行业数据跟踪。服务于"阶段 4 技术/数字化扩展"的行业判断。
  2. 术语口径区分（正文中不得混用）：
  3. EC 物流 ≠ 冷链 ≠ 3PL 委托形态；
  4. SPPI ≠ WebKit 运賃指数（口径不同禁止混算）；
  5. 倒産件数 TDB ≠ TSR 口径。
  6. 交叉验证锚（只读）：行业宏观数字锚 01-ssw-driver 登记册 #7/#8/#9（SPPI、倒産、2024年問題），只读引用、不得独立回写；冲突时先回官方原文复核，由 01 主责更新。

与 05-industry-autonomous 的分工

  • 本篇（04）写产业面：产业规模、赛道结构、企业动向、行业数据；
  • 05 写技术与制度面：自动驾驶技术路线、法规与实装进展；
  • 同一事实只在一篇展开，另一篇仅给结论与跨主题链接。

七、执行方式（建议）

  1. 启动 2–3 个并行研究子代理：① 物流白書与产业概览；② SPPI/倒産件数/运賃指数；③ 增长赛道市场规模估计。全部限定日/英来源、逐点引用，每条数据必须附可直接访问的 URL。
  2. 子代理返回后，由主代理读取 {{HANDBOOK_PATH}}（单份知识手册）与受影响章节的上一版快照做差异合并，继承已修正事实、应用第四、五节更新要点。
  3. 对冲突数据保留双份引用；对无法核实项单列"待复核清单"。
  4. 回写完成后运行 python prompts/tools/md2html.py 04-industry-logistics/reports 重新生成 HTML；运行 python prompts/tools/archive_reports.py 执行保留策略。
