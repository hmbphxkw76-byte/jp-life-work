## 研究边界档案（基线首建，年度刷新复核）

### 行业边界

- **含**：道路货物运送业（トラック・宅配便・路線貨物）、倉庫業・3PL、冷链、国際物流・フォワーディング、物流自動化的产业面（导入率 / 投资 / 企业动向）。
- **不含**：自动驾驶技术路线与法规细节（→ 05）、个人技能与岗位行情（→ 06）、在留资格与特定技能制度（→ 08）、行业法规条文（→ 09）。

### 产业链分层口径

```
上游：车辆 / 仓储设备 / 燃料 / 物流信息系统
中游：运输（幹線・路線）・倉庫・3PL・宅配
下游：荷主（製造・小売・EC・医薬 / 生鮮）
```

### 玩家清单与入选标准

- **入选标准**：上市或公开数据可得的行业代表企业，按综合物流 / 宅配 / 干线 / 冷链 / 仓储分层；进出须在本节留痕。
- **首期清单**：日本通運、SGHD（佐川急便）、ヤマト運輸、日本郵便、福山通運、西濃運輸、名鉄運輸、センコー、日本ロジスティクス、ニチレイロジ、グローバルゲート、ロジクエスト。
