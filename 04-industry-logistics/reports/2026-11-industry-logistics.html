一、执行摘要

核心结论

结论 1：日本物流呈"少数大手 + 海量零细"的二元结构。证据：30 辆以下中小事業者占 85%（トラック白書，时点待更新）；物流业规模约 28 兆日元 / 229 万人（物团连，令和 2 年度）。标注：事实。

结论 2：增长赛道优先级为 3PL 仓库 SV ＞ 冷链 ＞ 宅配分拣中心 ＞ 绿色物流。证据：本规划视角的赛道优先级排序。标注：事实（规划排序，非行业统计）。

结论 3：自动化按"干线先于末端、岗位重组而非消失"的渐进路径推进，转型窗口在当下。证据：行业级结论；新東名深夜優先レーン 2025-03 起运营（国交省）；"全职司机消失被预期为 2030 年代以后"。标注：事实（行业级结论与实证状态）；其中"2030 年代以后"为预期性表述。

结论 4：道路货运价格处于上行读数。证据：SPPI 道路货运指数 113.3（+4.6%）（日銀 SPPI，时点待核验）。标注：推断（+4.6% 的口径与月次未核验前，仅作方向性判读）。

结论 5：司机缺口是最大结构性约束。证据：2030 年度 162,912 人（约 16 万）推算（国交省检讨会中间总结（NX 总研试算），2022 年推计）；趋势栏标注"持续关注修正"。标注：推算值本身为事实；作为约束的判断为推断。

二、研究范围与方法

监测范围

含：道路货物运送业（トラック・宅配便・路線貨物）、倉庫業・3PL（受託物流）、冷链（コールドチェーン）、国際物流・フォワーディング、物流自動化的产业面（导入率、投资、企业动向）。

不含（交叉引用，不在本主题展开）：自动驾驶技术路线、法规与实装细节（→ 05-industry-autonomous）；个人技能地图、岗位行情、转型路径（→ 06-industry-technology）；在留资格、特定技能制度细节（→ 08-visa-immigration）；行业法规条文与政策解读（→ 09-politics-law）；经济与收入环境（→ 07-economy-finance）。

受众与视角

面向在日本物流行业就业 / 拟进入该行业的个人，保持中性全景刻画，不给投资评级、不出具 Go/No-Go 决策建议（边界归投资尽调型、可行性型）；趋势判断一律标「推断」。

核心监测问题

  1. 日本物流产业的规模与结构（营业收入、从业人数、事业者数）最新读数是多少，"少数大手 + 海量零细"的二元结构是否延续？
  2. EC / 冷链 / 3PL 三条增长赛道的市场规模与就业形态如何演化？
  3. 物流自动化的产业面（导入率、投资、企业动向）进展到哪一步，对岗位结构的影响路径如何？
  4. SPPI 道路货运指数、物流倒産件数等价格与结构指标的最新读数与趋势如何？
  5. 「物流 2024 年问题」对策（司机时间外规制）对运力与运价的传导进展如何？

结构性结论（事实）：日本物流是"少数大手 + 海量零细"的二元结构；个人职业策略上——大手学制度、中小拿机会。

增长赛道（EC / 冷链 / 3PL / 绿色物流）

EC 物流：驱动力为 EC 化率持续上升（食品、日用品带动）与宅配便处理量长期高位；就业形态为宅配司机（ルート）、分拣中心（仕分けセンター）作业与 line 管理、客服对应；特征为自动化最前沿——大手宅配的分拣中心大量导入自动分拣机、AMR 机器人；注意点为再配达対応、クレーム对应等客户接触强度高，日语要求高于普通货运。

冷链：驱动力为生鮮 EC、医药（ワクチン / 医药品 GSP）、外食供应链；岗位属性为温度带管理（冷藏 / 冷冻 / 定温）、温度记录与验证、HACCP 意识；薪资通常高于常温岗位（具体薪资结构与谈判口径归 02-career-driver）；个人机会为冷链经验是稀缺技能标签（司机→冷链组长→品質管理辅助）；风险为温度异常的责任归属要在契约层面确认。

3PL：定义为荷主企业将物流全案外包——仓储 + 运输 + 系统 + 人员管理一揽子；岗位谱系为现场作业、SV（supervisor）、WMS 操作、KPI 报告担当、荷主折冲；对外国人最友好的增长点为语言多样性与现场翻译·带人能力是显性价值。

绿色物流：政策为 2050 碳中和目标 → EV / 氢燃料卡车导入、ECO 驾驶普及、共同配送；岗位影响为 ECO 驾驶数据管理、充电 / 加氢设施运营、燃费 KPI。

赛道优先级（本规划视角）

优先级1：3PL 仓库 SV      （管理×数字交叉点，阶段 3→4 的桥）
优先级2：冷链专业经验     （稀缺标签，随时可叠加）
优先级3：宅配分拣中心     （自动化暴露量最大，利于学技术）
优先级4：绿色物流实绩     （作为附加成果，非独立赛道）

竞争格局要点

  1. 二元结构：少数大手 + 海量零细（30 辆以下中小占 85%），个人职业策略上大手学制度、中小拿机会。
  2. 自动化前沿在宅配分拣中心：大手宅配大量导入自动分拣机、AMR 机器人，是"会用新系统的人"的最短暴露路径。
  3. 3PL 是管理岗与数字化岗位的交叉点：3PL 仓库 SV 被评估为阶段 3→4 的桥（管理岗路径归 03-career-management）。
  4. 产业面与技术面的分工：本主题只写产业面（规模、赛道、企业动向）；技术路线与法规细节归 05-industry-autonomous。

六、驱动因素与风险

政策大方向

  1. 物流 2024 年问题：司机时间外规制 → 运力不足 → 运费上涨、荷主负担转嫁改革 → 具体进展以 01-ssw-driver 登记册为准（只读锚）。
  2. 省人化省力化：自动驾驶卡车、仓库自动化、无人配送 → 技术面归 05-industry-autonomous。
  3. 地域物流再生：人口稀疏地区配送维持 → 外国人材 + 共同配送。
  4. 外国人材受入扩大：特定技能（自动车运送业受入上限现行 22,100 人 / 5 年，2024–2029；使用率待查）+ 2027 育成就劳 → 制度细节归 08-visa-immigration。

自动化产业面（三条行业级结论）

  1. 干线先于末端：高速干线（夜间、点对点）是最早被改造的场景；城市 / 最后一公里配送的自动化更远。
  2. 岗位不是消失而是重组：长途司机转向监控员 / 编组担当 / 中継司机；仓库纯体力岗减少，设备运营与数据岗增加；运行管理 / 配车岗位反而增强。
  3. 转型窗口在当下：全职司机消失被预期为 2030 年代以后，但"会用新系统的人"从今天就能开始积累。

岗位结构影响矩阵（10 年预期）

其他实证与制度读数

  • 新東名自动驾驶实证：深夜優先レーン运营中（国交省，2025-03 起；扩大区间待观察）。
  • 西濃運輸 × T2 中継输送自动驾驶实证开始（岐阜，2026-11-11 建档记录）。
  • 自动车运送业特定技能受入：上限 22,100 人 / 5 年（现行，ISA，2024–2029；使用率待查）。

风险与不确定性

  • 登记册 #1、#4 待基线确立，规模与赛道判断缺权威锚。
  • SPPI 未标月次、WebKit 運賃指数无数值，運賃趋势无法交叉验证。
  • 物团连（令和 2 年度）与 TSR（2021）口径与时点不一致，不可合并。
  • 司机缺口为 2022 年推计推算值，存在修正风险。
  • 中文来源仅作线索，须回溯日文官方原文。

七、趋势判断（推断）

本节为推断层，与上文事实层分离；推断依据为历史报告结论与登记册活值，存在修正风险。

  1. 二元结构延续（推断）：中小事業者占比 85% 的结构性读数未出现反转信号，"少数大手 + 海量零细"预计延续。
  2. 自动化渐进改造（推断）：干线先于末端、岗位重组而非消失的路径判断维持；"全职司机消失被预期为 2030 年代以后"为预期性表述，不作为确定时点。
  3. 道路货运价格方向性上行（推断）：SPPI 113.3（+4.6%）在月次与口径未核验前，仅作方向性判读，不作幅度外推。
  4. 司机缺口构成中期约束（推断）：162,912 人（2022 年推计）作为结构性约束的判断为推断；官方修正可能改变幅度。
  5. 增长赛道分化（推断）：3PL、冷链、宅配分拣中心受自动化与 EC 驱动快于干线零细市场；绿色物流作为附加成果而非独立赛道。
