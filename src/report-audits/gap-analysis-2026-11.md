**一句话结论**：行业政策面已强，但**法律服务交付面**（申请救济、退出救济、家庭事件、中介合规、风险兜底）与**关键词 / 检索面**存在系统性缺口，14/15/16 尚未达到可交付深度。

## 二、内容覆盖缺口（按移民生命周期）

- **A 行前**：个人资质自评矩阵缺失；成本—收益全景账本缺失；时间窗口与倒计时缺失。
- **B 招募・中介・合同（最大风险缺口）**：中介防骗与劳务合规专题缺失（日本認定送出機関 / 送出機関名单核验、骗术图谱、无资质法律后果、合同逐条审查清单）。
- **C 申请・审查・不许可救济**：不许可 / 拒签救济链缺失；材料瑕疵可补救性分级缺失。
- **D 落地与在留**：银行 / 账户 / 保证会社门槛未收敛；在留卡 ≠ 在留资格 ≠ 住民票例外情形缺失；驾照转换全流程缺失。
- **E 劳动合规**：维权程序级内容缺失（监督署 / 解雇 / 未払 / 労災 / 骚扰）。
- **F 资格切换**：永住 / 归化实务数值与证据链模板缺失；2 号 / 育成就劳实务；技人国 / 高度专门职未独立化。
- **G 家庭・育儿**：保育 / 教育 / 家庭事件全缺。
- **H 退出・转型・回国**：16 的 12+1 项执行指标几乎全部「⚠ 待核实」，导致 00「最坏怎么办」无法收敛。
- **I 风险与救济（最高优先级）**：在留资格取消・退去强制・収容・仮放免・出国命令・上陸拒否 / 入国禁止全链缺失；刑事 / 行政风险联动缺失。

## 三、主题设置缺口

- 领域主题（01–13）vs 阶段主题（14–16）错配，用户旅程断裂。
- 深度分层缺失，无「初析 → 执行 → 研究」升级规则。
- 决策层与执行层脱节（00 缺失清单未随 14/16 上线刷新）。
- 词库与业务线不一一对应（16 业务线 vs 14 词库主题）。
- 横向资格地图缺失（2 号 / 技人国 / 高度专门职 / 永住 / 归化分散）。

## 四、关键词布局缺口

- **词库层**：缺 `life-operations`（25 条）与 `health-wellbeing`（20 条）实体；高价值缺失词集中在核心制度（外免切替、収容、仮放免、在留特別許可、上陸拒否、入国禁止、未払、源泉徴収、扶養控除、青色申告、分離課税）、家庭事件（保育園、認定こども園、転校、出産育児一時金、児童扶養手当、国際結婚、離婚、相続）、住房生活（保証会社、公営住宅、UR、印鑑）、中国侧领事（护照、户籍、档案、居住证、健康证、翻译件、大使馆、领事、对外劳务合作、商务部、送出機関、認定送出機関、無資格）、风险救济（黑名单、诈欺、保证金、違約金、解約金、诬告、拖欠、生活保護）。
- **报告正文与搜索层**：中文长尾搜索词几乎无布局；无 SEO 元数据层；无「问题—报告」索引；`index.html` 不是搜索入口；词库 `exports/*.jsonl` 未与报告检索打通。
