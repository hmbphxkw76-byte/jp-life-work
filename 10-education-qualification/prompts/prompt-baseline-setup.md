# 日本 · 资格与教育投资 · 首期基线报告提示词（职业就业调研型）

> **用途**：执行「日本 资格与教育投资 就业调研机制」的**机制建立**任务：产出首期基线（深度调研）报告与配套指标登记册，作为后续所有周期更新的对比锚与制度基础。
> **现状**：本业务线基线已于 2026-11 产出（[reports/{{YYYY-MM}}-<slug>.md](../reports/{{YYYY-MM}}-<slug>.md) + 同名 HTML，v1.0，数据基准 2026-11-12）。**正常运行永不重跑基线提示词**；仅在①报告与登记册全部丢失（灾难恢复），或②经维护规范批准的九节结构重排时启动。
> **产出**：md 源稿 + 同目录自包含 HTML，落盘 `{{OUTPUT_PATH}}`；指标活值与研究边界档案回写 `{{REGISTRY_PATH}}`。
>
> **继承声明（四层体系）**：本文件 = [通用基座](../../engine/report_templates/prompt-generic-base.md) × [监测报告通用规范](../../engine/report_templates/monitoring-common-spec.md) × [基线报告类型模板（职业就业调研型）](../../engine/report_templates/employment-research/prompt-baseline-setup-template.md) × [业务专属配置](./business-config.md)。冲突时以本文件为准。

**任务目标**：产出九节就业调研基线报告（核心结论、行业与政策发展趋势、人才供需与薪酬、雇主与企业类型细分、岗位技能要求、行业认可的职业资质与证书、就业落地路径建议、数据可靠性与局限说明、参考来源清单）与研究边界档案首建；多口径并列不合并；运行后回写 `{{REGISTRY_PATH}}`；基线报告**无上期报告**，不读取 `{{PREVIOUS_REPORT_PATH}}`。

## 一、项目专属硬性约束

1. **受众与结论边界**：面向拟在日本从事货运司机工作、需要职业资格与教育投资规划的读者；预算建议标「建议」，不承诺资格必过、不保证讲习开班期次；实际入学前以居住地教育委员会与学校公示为准（见[业务配置第二节](./business-config.md)）。
2. **来源语言规则**：制度类须日文官方原文；教育统计须文科省等官方调查；费用行情须多源交叉验证。
3. **术语口径**：法定必携资格 ≠ 任用有利资格；「技能講習」≠「特別教育」；受讲料 ≠ 教习料 ≠ 検定料；学士 ≠ 短期大学士 ≠ 専門士／高度専門士。
4. **边界纪律**：在留资格要件链接 08、岗位资格需求链接 02 / 03、日语备考链接 11、地域教育资源链接 13、永住年收财务链接 07；本报告只写资格地图 + 教育投资决策，不复制在留要件。
5. **内容边界**：驾照取得路径与费用以 01-ssw-driver 登记册 #14 为只读锚，本主题不独立改值或回写。

## 二、来源优先级

见[业务配置第五节](./business-config.md)：① 文科省 / 厚労省 / 国交省 ＞ ② 各资格认定中央机构 ＞ ③ 全日本トラック協会 ＞ ④ 教习机构官网（费用，仅预期指标需交叉验证）。每条数据附完整 URL，每格活值附 `[来源, 年份]`。

## 三、基线锚定与重启条件

- 基线报告一经产出即为对比锚：结构、口径裁决与已核实结论由后续周期更新完整继承。
- **正常运行不重跑**。重启仅限两种情形：①灾难恢复（报告与登记册全部丢失）；②九节结构经维护规范批准重排。重排须在[业务配置](./business-config.md)第十二节版本记录留痕，并同步评估周期更新提示词。
- 现状：首期基线保留现行结构（业务固化锚），结构映射见[业务配置第 3.2 节](./business-config.md)。

## 五、追踪表与边界档案

按[业务配置第八节](./business-config.md)的 9 项追踪指标逐项核对并填写「是否更新」；运行后回写 `{{REGISTRY_PATH}}` 的核心指标与[研究边界档案](./business-config.md)（领域边界、资格分层、主体清单与入选标准、口径清单）。未核实项注明「待核实」，不补值、不外推；prompt 模板内不填活值。

## 六、执行方式（建议）

1. 并行启动 3–4 个研究子代理：① 法定资格制度与讲习要件；② 讲习日程与费用行情；③ 学校教育与子女教育（mext.go.jp 外国人子女就学调查、就学案内与援助、给食费）；④ 高等教育与技人国学历路径（募集要项、通信制学费、ISA 审查口径）。全部限定日 / 英来源、逐点引用，每条数据附可直接访问的 URL。
2. 主代理合并差异，冲突口径保留双份引用，无法核实项单列「待复核清单」。
3. 与 01-ssw-driver 登记册 #14 交叉验证驾照费用（只读锚，不回写）。

## 七、渲染与交付

- 交付格式：md + 同目录自包含 HTML（`python engine/tools/md2html.py`）；HTML 须通过 `python engine/tools/lint_reports.py`。
- 基线导航采用简化锚点目录，不强制 `.report-nav`。
- 落盘后将[业务配置第一节](./business-config.md)的 `{{BASELINE_REPORT_PATH}}` 指向本报告（重建场景）。

## 八、质量自检（通用清单之外的本主题专属项）

- [ ] 法定必携资格与任用有利资格已区分；「技能講習」与「特別教育」已区分
- [ ] 学历称号（学士 / 短期大学士 / 専門士 / 高度専門士）已区分
- [ ] 费用口径（受讲料 vs 教习料 vs 検定料）逐项标注
- [ ] 驾照费用与 01-ssw-driver 追踪项 #14 一致
- [ ] 技人国要件未在本主题复述，仅引用 08-visa-immigration
- [ ] 追踪表 9 项均已核对并填写「是否更新」
- [ ] `{{REGISTRY_PATH}}` 已读已写：变更摘要与登记册一致；prompt 模板自身无硬编码活值
- [ ] HTML 通过 lint（标签配对）
