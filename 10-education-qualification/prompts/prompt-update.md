# 日本 · 资格与教育投资 · 周期更新提示词（职业就业调研型）

> **用途**：覆盖职业就业调研型**三档节拍**——月度核验轻运行 / 季度主更新 / 年度复盘，以及重大事件触发器命中时的模块升级。可直接复制，替换顶部变量后提交给 AI 执行。
> **产出**：季度 / 年度报告落盘 `{{OUTPUT_PATH}}`（`reports/{{YYYY-MM}}-<slug>.md` 或 `reports/{{YYYY-MM}}-<slug>.md` + 同名 HTML）；月度轻运行只更新登记册，不重写报告；事件触发插刷件 `reports/{{YYYY-MM}}-<slug>.md`（命名不在标准正则内，validate 仅 WARN 不阻断，属预期）。
>
> **继承声明（四层体系）**：本文件 = [通用基座](../../src/report_templates/prompt-generic-base.md) × [监测报告通用规范](../../src/report_templates/monitoring-common-spec.md) × [周期更新类型模板（职业就业调研型）](../../src/report_templates/employment-research/prompt-update-template.md) × [业务专属配置](./business-config.md)。冲突时以本文件为准。

## 运行变量（每次运行前填写）

```
{{CURRENT_DATE}}         = 本次执行日期，格式 YYYY-MM-DD
{{CADENCE}}              = 月 / 季 / 年（按本次节拍填写）
{{PREVIOUS_REPORT_PATH}} = 上一期同周期报告路径（首期季度为空，仅锚定基线）
{{BASELINE_REPORT_PATH}} = reports/{{YYYY-MM}}-<slug>.md
{{REGISTRY_PATH}}        = data/education_indicator_registry.md
{{OUTPUT_PATH}}          = reports/{{YYYY-MM}}-<slug>.md 或 reports/{{YYYY-MM}}-<slug>.md
{{REPORT_VERSION}}       = 本次版本号，格式 vYYYY.MM.DD
```

固定值（不填，读自业务配置第一节）：`{{REGION}}`、`{{TOPIC}}`、`{{FRESHNESS_PRIORITY}}`、`{{SOURCE_LANGUAGE_RULE}}`、`{{REPO_RAW_URL_BASE}}`。

**任务目标**：完成「核验 → 更新 → 建议 → 可靠性」闭环；按节拍实例化（见第一节）；继承已修正事实清单；无触发且窗口未到时不启动，不得虚构变化。

## 一、节拍与触发

三档节拍设计见[周期更新类型模板第一节](../../src/report_templates/employment-research/prompt-update-template.md)：

| 节拍 | 定位 | 触发条件 | 输出 |
|---|---|---|---|
| 月度 | 核验型轻运行：只核验登记册活值与触发器状态，不重写报告 | 常规月度窗口；**无触发不启动新报告**，仅在登记册标注「截至本次日期无更新」 | 登记册更新记录；命中触发器时升级为季度重点更新 |
| 季度 | 主更新节拍：全模块刷新 | 每季度窗口，或任一重大事件触发器命中 | 完整九节更新版报告（结构逐字继承基线） |
| 年度 | 复盘：预测对照 + 清单复审 + 路线图重排 | 每年固定窗口 | 年度版报告 + 登记册年度复盘留痕 |

业务触发器清单（`事件 → 受影响模块`）见[业务配置第七节](./business-config.md)：

```
- 资格制度 / 讲习义务变化 → 01 资格地图
- 讲习日程与费用变化 → 01 / 02
- 目标岗位资格要求变化（联动 02-career-driver、03-career-management 触发器） → 01
- 个人取得资格 → 01 / 02
- 文科省外国人子女就学 / 日本語指導政策变化 → 03
- 学校教育费用调查（学習費調査 / 私立納付金 / 給食費）发布 → 03
- 大学制度改革 / 编入·社会人入学制度变化 → 04
- 技人国学历·职历审查口径变化（联动 08-visa-immigration） → 04
- 通信制 / 社会人入试制度与学费带变化 → 04
```

## 二、项目专属硬性约束

1. **受众与结论边界**：面向拟在日本从事货运司机工作、需要职业资格与教育投资规划的读者；预算建议标「建议」，不承诺资格必过、不保证讲习开班期次。
2. **来源语言规则**：制度类须日文官方原文；教育统计须文科省等官方调查；费用行情须多源交叉验证。
3. **口径纪律**：法定必携资格 / 任用有利资格不得混用；「技能講習」与「特別教育」不得混用；受讲料 / 教习料 / 検定料不得混用；学历称号不得混用；本人教育预算与子女教育支出两本账分开记。
4. **边界纪律**：在留资格要件链接 08、岗位资格需求链接 02 / 03、日语备考链接 11、地域教育资源链接 13、永住年收财务链接 07；本主题只写资格地图 + 教育投资决策。
5. **交叉验证锚**：驾照取得路径与费用以 01-ssw-driver 登记册 #14 为只读锚，本主题不独立改值或回写；讲习费用多源交叉验证。

## 三、各模块更新要点

按[业务配置第 3.2 节](./business-config.md)的结构映射逐模块实例化：

- **资格地图（对应岗位技能要求 / 行业认可的职业资质与证书）**：物流 / 运输相关法定必携资格、任用有利资格、远期资格的法定依据、要件、考试 / 讲习日程；个人取得状态更新；保持资格分类框架与投入产出规则。
- **学习体系与教育投资（对应就业落地路径建议）**：语言 / 资格 / 学历三账户、年度预算纪律（每年教育支出 ≤ 月收入 1 倍）、公共免费资源包；费用行情多源并列、注明口径；更新投资决策记录，保持评估框架。
- **日本学校教育体系与子女教育（对应行业与政策发展趋势 / 数据可靠性与局限）**：6-3-3-4 学制框架、公立 / 私立 / 国际学校对比、外国人子女就学手续、日本语指导体制、教育成本与就学援助；动态获取年度调查公表值；保持「制度 + 手续 + 成本」结构，不做学区 / 升学策略。
- **高等教育与技人国学历路径（对应就业落地路径建议）**：高等教育体系定位、社会人入学 / 编入、通信制大学在职学历、学费带；「大学毕业 vs 10 年实务经验」对比表的时间 / 成本 / 风险要素；在留要件一律交叉引用 08 手册不复述。

## 四、基线锚定与防回退

- 读取 `{{PREVIOUS_REPORT_PATH}}`（首期季度为空）与 `{{BASELINE_REPORT_PATH}}`，继承结构与全部已核实结论。
- 逐条继承「已修正事实清单」，产生修正后追加（格式见[通用基座第五节](../../src/report_templates/prompt-generic-base.md)）；严禁重新引入已被推翻的说法；无来源不得入清单。
- 已修正事实清单以最新版报告文首为单一事实源；登记册不重复维护。

## 五、追踪表与登记册联动

按[业务配置第八节](./business-config.md)的 9 项追踪指标逐项核对并填写「是否更新」；运行前从 `{{REGISTRY_PATH}}` 读取活值与研究边界档案 → 复核有效性 → 运行后回写。数据变更摘要至少覆盖全部 9 项；未核实项单列「待复核清单」。prompt 模板内不填活值。

## 六、执行方式（建议）

1. 按调研维度并行启动研究子代理（资格制度 / 讲习费用 / 学校教育与子女教育 / 高等教育与技人国学历路径），全部限定日 / 英来源、逐点引用，每条数据附可直接访问的 URL。
2. 主代理读取 `{{PREVIOUS_REPORT_PATH}}` 与基线做差异合并，继承已修正事实清单，应用第三节更新要点。
3. 冲突数据保留双份引用；无法核实项单列「待复核清单」。
4. 回写报告与登记册后运行 `python src/prompts-tools/tools/md2html.py` 重新生成 HTML，并运行 `python src/prompts-tools/tools/lint_reports.py` 校验。

## 七、渲染与交付

- 交付格式：md + 同目录自包含 HTML；季度 / 年度报告含顶部九锚点导航（`.report-nav`），`.nav-url` = `{{REPO_RAW_URL_BASE}}` + `/reports/{本期文件名}`。
- HTML 须通过 `lint_reports.py` 标签配对校验。
- 月度报告常驻 `reports/` 顶层；每主题保留最新 12 期，超出移入 `reports/archives/`。

## 八、质量自检（通用清单之外的本主题专属项）

- [ ] 结构逐字继承基线（或经批准的九节骨架），无增删节、无顺序调整
- [ ] 已修正事实清单已继承并续写，无回退
- [ ] 法定必携资格与任用有利资格已区分；「技能講習」与「特別教育」已区分
- [ ] 学历称号（学士 / 短期大学士 / 専門士 / 高度専門士）已区分；费用口径逐项标注
- [ ] 驾照费用与 01-ssw-driver 追踪项 #14 一致；技人国要件未复述，仅引用 08
- [ ] 追踪表 9 项均已核对并填写「是否更新」
- [ ] `{{REGISTRY_PATH}}` 已读已写，变更摘要与登记册一致
- [ ] 数据变更摘要与待复核清单已产出
- [ ] HTML 通过 lint（标签配对）

## 落盘后审计（提交前必做）

落盘后依次运行 `python src/prompts-tools/tools/audit_preflight.py --report <报告相对路径>`、`python src/prompts-tools/tools/audit_check.py --report <报告相对路径>`，修正全部 P0/P1 后执行 `python src/prompts-tools/tools/audit_pipeline.py --submit --report <报告相对路径>` 提交审计（未通过初审不得合并）。
