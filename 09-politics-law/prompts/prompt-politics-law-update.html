七、执行方式（建议）

  1. 启动 2–3 个并行研究子代理：① 入管法及关系法令改正；② 劳动维权渠道与咨询窗口；③ 移民政策动向。全部限定日/英官方来源、逐点引用，每条数据必须附可直接访问的 URL；媒体报道须回溯原文。
  2. 子代理返回后，由主代理读取 {{PREVIOUS_REPORT_PATH}} 指定上一版快照做差异合并，继承已修正事实、应用第四、五节更新要点。
  3. 对冲突数据保留双份引用；对无法核实项单列"待复核清单"。
  4. 回写完成后运行 python prompts/tools/md2html.py 09-politics-law/reports 重新生成 HTML；运行 python prompts/tools/archive_reports.py 执行保留策略。
