# 类型模板 · 知识库主题更新（动态获取）

> **层级定位**：第 2 层类型模板 = [通用基座](../通用基座/prompt-generic-base.md) × 本文件差异配置。适用于本仓库 `NN-*` 下**以单份知识手册为单位**的主题（每个 `NN-{topic}/` 即一个"主题项目"）。与监测类的区别：产出不是单份新报告，而是**增量回写既有单份知识手册**；锚定对象是知识手册自身的历史版本。
>
> **继承声明**：运行变量、全局约束、基线锚定、更新协议、执行方式、自检骨架均自动继承通用基座与《[监测报告通用规范](../monitoring-common-spec.md)》，本文件只写**类型差异**；与上层冲突时以本文件为准。

---

## 类型差异 T1 · 主题项目结构（NN-* 主题目录约定）

```text
NN-{topic}/
├── data/                           # 主题数据（来源台账/指标活值，按需落文件）
├── prompts/
│   └── prompt-{slug}-update.md    # 第 3 层主题提示词 = 本模板 × 主题专属配置
└── reports/
    ├── 日本{中文名}知识手册.md      # 单份知识手册（## NN 章节名 组织各章节）
    ├── 日本{中文名}知识手册.html    # 与 md 同名的生成产物（随源文件入库）
    └── archives/                  # 归档旧版知识手册（由 archive_reports.py 维护）
```

> **单文档硬约束**：每个主题仅维护**单份知识手册 `.md`** 及同名 `.html`，禁止同一主题拆分为多份零散 `.md`。原 00-index 导航内容已并入手册前部「导航与使用约定」章节。

## 类型差异 T2 · 专属运行变量

```
{{TOPIC_DIR}}            = 主题目录路径（如 08-visa-immigration）
{{HANDBOOK_PATH}}        = 单份知识手册路径（{{TOPIC_DIR}}/reports/日本{中文名}知识手册.md）
{{DOC_LIST}}             = 本次更新涉及的章节清单（由主题提示词声明，对应手册内 ## NN 章节）
{{REGISTRY_PATH}}        = 指标活值登记册路径（**强制，继承通用基座**）；规范写法 `NN-{slug}/data/{slug}-indicator-registry.md`，prompt 文件内可写作 `../data/{slug}-indicator-registry.md`（等价）；登记册为活值唯一存放处，prompt 模板内禁止持有具体数值
```

锚定对象：`{{PREVIOUS_REPORT_PATH}}` 在本类型中语义为 **`{{HANDBOOK_PATH}}` 的当前版本**（git 历史为最终回退锚）。

## 类型差异 T3 · 输出形态（覆盖通用基座第七节）

- **增量回写**：直接更新 `{{HANDBOOK_PATH}}` 中受影响的章节（`## NN 章节名`）；未受影响章节不动；结构性内容（路线、框架表）按模块要点"保持"。
- **每次更新必须产出**（写入手册内「导航与使用约定」的更新日志区，不单独成文）：
  1. **数据变更摘要**：| 章节 | 变更点 | 旧值/旧说法 | 新值（来源/年份）| 性质（新增/修订/无变化）|
  2. **待复核清单**：无法核实的条目 + 推荐复核入口。
- **新增知识**在现有章节中找不到位置时，在手册内新建 `## NN 章节名`（编号顺延）；禁止把不相关内容塞进既有章节，禁止新建独立 `.md` 文件。
- 正文新增数据点一律附 `[Source: 完整URL, 年份]`；表格按《监测报告通用规范》二.2 呈现（主题文字超链接 + hover 来源，不设"来源"列）；推断显式标注。

## 类型差异 T4 · 来源登记

每主题在提示词或 `data/` 中维护**主题来源台账**：机构/域名、类型（官方一手/国际组织/行业机构/门户/媒体）、语言、用途（对应模块）。新增来源须先归类再引用；中文来源按项目语言规则处理。

## 类型差异 T5 · 执行方式建议

1. 触发器前置检查（同通用基座第六节第 1 条）。
2. 并行子代理 2–4 个，按手册章节分工；每个子代理限定主题来源台账范围、逐点引用、**每条数据必须附 URL**。
3. 主代理差异合并：读取知识手册当前版本 → 继承已修正事实 → 按"更新/动态获取/保持"回写对应章节 → 更新手册内更新日志区。
4. 回写完成后运行 `python prompts/tools/md2html.py {{TOPIC_DIR}}/reports` 重新生成 HTML（与 md 同目录，随源文件入库）。
5. 运行 `python prompts/tools/archive_reports.py` 执行保留策略：`reports/` 顶层保留最新 3 份（`*_baseline` 基线版固定保留，永不进入 archives），其余入 `archives/`，归档上限 7 份。

## 类型差异 T6 · 主题专属必填区（第 3 层填写清单）

第 3 层主题提示词 = 本类型模板 × 以下配置：

1. 【主题定位与受众】一句话说明本主题服务哪条人生/职业路线
2. 【来源优先级实例化】五层框架 → 本主题具体域名/机构清单 + 语言规则
3. 【术语口径区分】（如适用）
4. 【事件触发器表】→ 触发手册章节编号
5. 【手册章节更新要点】逐章节：更新 / 动态获取 / 保持
6. 【关键信息追踪表】编号 + 信息项 + 优先数据源（**prompt 内严禁填活值**；活值存 `{{REGISTRY_PATH}}`）
7. 【已修正事实清单】首期为空，随修正追加
8. 【指标登记册】运行前读、运行后写 `{{REGISTRY_PATH}}`；登记册格式见通用基座五-A；首期运行须同时创建登记册并填入基线值
