# 类型模板 · 市场指标监测（月度）

> **层级定位**：第 2 层类型模板 = [通用基座](../通用基座/prompt-generic-base.md) × 本文件差异配置。适用于「指标台账 + 信号规则 + 周期性简报」的监测项目（如 monitors-dubai/apartment-monitor）。就业调研类项目请用《[职业就业调研类型模板](../职业就业调研/prompt-employment-research-template.md)》。
>
> **继承声明**：运行变量、全局约束、基线锚定、更新协议、追踪表、执行与输出骨架均自动继承通用基座与《[监测报告通用规范](../monitoring-common-spec.md)》；本文件只写**类型差异**。本类型对核验纪律要求严于通用规范，冲突时以本文件为准。

---

## 类型差异 T1 · 专属运行变量

```
{{REGISTRY_PATH}}        = 指标台账文件路径（xlsx：指标台账/信号规则/首期基线值/监测日历 四表）
{{BASELINE_REPORT_PATH}} = 首期基线报告路径
```

## 类型差异 T2 · 发布日历判定（必做，覆盖通用基座第三节第 3 条）

动笔前判定本期处于发布周期哪个位置并写入报告开头：

1. 确定执行日与本期性质：正常周期执行（T+0）/ 基线后紧邻刷新（T+1）/ 补录执行。
2. 列出「本期应发布但未发布」清单，给出**官方页面依据**（不是"没查到"，而是"官方页面显示的最新一期是什么"）。
3. T+1 刷新期明确写「官方发布窗口未开，价值在于核验、口径澄清与阈值距离」，不得虚构变化。
4. **数据空窗 ≠ 市场静止**：用「证据强度变化 / 口径澄清 / 阈值距离」三类实质性发现填充结论。

## 类型差异 T3 · 来源分级（严于通用规范，覆盖其第三节）

| 级别 | 定义 | 处理方式 |
|---|---|---|
| 官方一手 | 政府/央行/统计机构/多边机构原始发布 | 可直接采信 |
| 行业机构 | 研究机构、经纪商研究报告 | 可采信，标注机构与报告名 |
| 挂牌门户 | 挂牌价、询盘量、挂牌量 | 仅作预期指标，不得替代登记/成交数据 |
| 媒体转述 | 媒体对官方数据的转述 | 须标「需核实原文」，不得与官方一手同等处理 |

经济/官方统计指标一律取官方一手渠道（第 3 层实例化机构清单）。

## 类型差异 T4 · 核验方法

1. **三状态标注**：已核验（原始页面直连确认，写明页面标题）/ 部分核验（转载或仅摘要）/ 未核验（不得作为事实引用）。
2. **版本归属纪律**：引用预测类报告必须核对报告版本日期；`Next Release Date` 已过但页面未更新 ⇒ 标「新版未更新／未核验」。
3. **冲突处理四类模板（必查）**：同页冲突 ⇒ 以标注统计周期/样本量的表格为准；跨页冲突 ⇒ 分别注明页面，不拼接成同一序列；媒体 vs 官方 ⇒ 以官方为准；口径冲突 ⇒ 并列呈现，禁止相减、取均值、加总。
4. **口径警示**（第 3 层自列常见混淆，如：均价 ≠ 中位价；挂牌 ≠ 成交）。

## 类型差异 T5 · 信号判定

- 按台账「信号规则」判定红/黄/绿灯，必须执行确认标准：连续 2 期同向（流量类用均值）、排除失真信号、多指数互证（≥2 独立来源同向）。
- 区分「水平阈值」与「累计变动阈值」、「矩阵灯」与「规则灯」，不一致时说明差异来源。
- 输出**阈值距离**（距红线多少 bp/pp），而不是只写"接近"。
- 专题预警（触发时启用）：预警面板 / 关键区分 / ≥4 条证据 / 传导量化表（≥4 档情景、写明全部假设）/ 情景分析（只给可观测触发条件，**不赋概率**）/ 反向校准 + 来源核查表。

## 类型差异 T6 · 报告结构（固定顺序，覆盖通用基座第七节第 1 条）

```text
1. 结论先行：状态 + 信号矩阵计数 + 是否翻转 + 本期性质与价值 + 要点清单
2. 关键数字卡：指标名、数值（单位）、统计周期、发布日期、来源简称 + URL、实际/预测/计划标注
3. 指标逐项对比：编号、指标、上期值、本期读数、方向、信号/阈值距离、来源（机构·周期·发布日·URL·核验状态）
4. 信号灯判定：先行信号矩阵 + 规则逐条判定
5. 与首期基线的偏离：基线值、本期值、偏离度、性质；解释"零偏离"含义
6. 数据缺口与未核验项：状态标签（未发布/缺席/未取得/未重算/无官方值/未核验）
7. 下期观察清单（8–10 条，带日期与触发条件）
8. 台账更新编号（实质修订/新增口径记录/复核确认/未取得/结论不变 五类）与来源清单
9. 免责声明（固定原文，不得改写）
```

## 类型差异 T7 · 图表与交付（HTML 简报时）

- 图表 ≥4 张，全部内联 JS，不依赖外部数据文件；浅底深字研报风；每图标题含单位与来源，图下注明口径与限制。
- 交付校验：`node --check` 内联 JS 语法自检（记录 Node 版本与退出码）；`<table>/<tr>/<td>/<div>` 开闭配对一致；图表容器 id 与 JS 引用一一对应；浏览器预览并给出落盘路径与文件大小。

## 类型差异 T8 · 台账与跨期衔接

- 台账按 `{{REGISTRY_PATH}}` 四表更新；明确下期对比锚（本期报告 + 台账基线值）。
- 季度/年度衔接的编号范围必须写出；若存在自动化记忆文件（`.workbuddy/memory/automations/*/memory.md`），追加本期执行记录与下期注意项。

## 类型差异 T9 · 禁止事项清单

- ✗ 编造数值、占位符数据、估算值冒充实测；把预测/计划值写成实绩。
- ✗ 用中介/经纪商口径替代官方缺失数据；口径冲突时静默择一、相减、取均值或加总。
- ✗ 把单点读数当成趋势；把一次读数当成信号确认；为制造周期变化而虚构变化。
- ✗ 给情景赋概率（无可校准依据时）；省略来源 URL 或只写域名不写路径；改写免责声明。
