1. **薪资口径必须区分含赏与与不含赏与**（事实）：含赏与年收约 **430 万日元**（月收约 27 万＋年间赏与约 106 万，行业报告口径，原始来源待核验）与官方月均现金给与 **341,158 円**（不含赏与，厚労省毎月勤労統計 2026-09，锚 01-ssw-driver #5）**不可直接对比**；谈 offer 时须先确认口径。[Source: https://www.mhlw.go.jp/toukei/itiran/roudou/monthly/r08/2609p/2609p.html, 2026]
2. **2024 新规降低加班收入天花板，但运力缺口构成长期利好**（事实＋推断）：月 45h / 年 360h 上限与月 100h 未满红线压低加班收入；2030 年度缺口 **162,912 人**（约 16 万，锚 01-ssw-driver #4，NX 总研试算）意味着行业结构性缺人——**推断：对外国人司机长期利好**。[Source: https://driver-roudou-jikan.mhlw.go.jp/truck/notice, 2026]
3. **特定技能专门中介 / 登录支援机关是风险最低主渠道**（建议）：与接受企业绑定、包支援义务；筛选须核「特定技能受入计划书认定」（未认定企业无法雇特定技能者）。
4. **驾照路径是落地关键瓶颈**（事实）：外免切替普通免许可换、准中 / 中型需另考；普通教习全国官方均价 324,381 円（AT 限定，総務省 2026-09）；大型 25–28 万円（TRUCK-BANK 2026-06）；MT 通学 30–40 万円（くらシム 2026-10-18）。
5. **个人工作条件记录是永住证据链与转职谈判的基础设施**（建议 / 推断）：月度 / 半年记录与凭证归档直接服务自我保护、转职谈判与永住审查；登记册 #5 目前为「待记录」。

## 二、行业与政策发展趋势

### 2.1 岗位制度框架（2024 年新制度后）

- **车种与驾照对应**（2024 年新制度后，见 5.2 表）：普通免许（总重 3.5t 未满）、準中型（3.5–7.5t，2024-05 新设）、中型（7.5–11t）、大型（11t 以上）、第二种免许（载客）。（来源：本主题知识手册 01，2026-11-11 核对）
- **特定技能 1 号考试**：第一种驾照即可；AT 限定需在期限内解除或换 MT。
- **职业驾驶资格**＝驾照＋雇主实施的**事業用自動車運転者講習**（新任驾驶员讲习）。
- **外免切替（中国驾照）**：普通免许可直接换；准中 / 中型需另考——手续与在留条件见 [08-visa-immigration](../../08-visa-immigration/reports/2026-11-visa-immigration.md)，驾照费用行情见 [10-education-qualification](../../10-education-qualification/reports/2026-11-education-qualification.md)。

### 2.2 2024 年（令和 6 年）劳动合规新规——「物流 2024 年问题」

2024-04-01 起，自动车运送业全面适用働き方改革：

| 规制 | 数值 |
|---|---|
| 时间外劳动上限（原则） | **月 45 小时 · 年 360 小时** |
| 特别条项（36 协定）上限 | **年 960 小时** |
| 时间外＋休日劳动合计 | **月 100 小时未满**、2–6 个月平均 80 小时以内 |

来源：厚生劳动省ポータルサイト [driver-roudou-jikan](https://driver-roudou-jikan.mhlw.go.jp/truck/notice)（2026）。

**对个人的影响**：

1. **加班收入天花板下降**（新规前月 100h+ 加班的公司很多）——工资谈判时看公司**是否已适应新规**（适应差的公司可能转嫁为倒班增加或大量离职）。
2. **运力不足 → 行业结构性缺人 → 对外国人司机反而是长期利好**（2030 年度缺口 162,912 人、约 16 万，见监测项目 #4，锚 01-ssw-driver）。
3. **月 100h 未满是红线**：超过说明公司违法或制度混乱，入职前必须问清。

### 2.3 安全规范与现场制度

| 制度 | 内容 | 个人要点 |
|---|---|---|
| **点呼** | 出车前后由运行管理者进行指示＋确认 | 酒气检查（アルコールチェック）必须配合；拒检＝重大违规 |
| **运行指示書** | 记载行车路线、时刻、载货 | 必须携带并按其运行 |
| **驾驶时间记录（運行記録）** | 每日记录驾驶开始 / 结束、行驶距离 | 数字化（デジタル走行記録計）公司为主 |
| **连续驾驶休息** | 4.5h 连续驾驶后至少 30min 休息 | 长途干线关键规则 |
| **定期训练** | 每年法定 5 项训练（安全 / 省燃费等） | 出席率记入个人档案 |
| **日常点检** | 出车前 60+ 项检查 | 发现异常必须报告，禁止「带病出车」 |

- **事故与异常处理流程**：事故发生→确保安全、救护优先→报警（110）→联系公司运行管理者→**不可自行与对方「私了」**；车辆异常→立即靠边→报告→等指示；货物异常（破损 / 短缺 / 温度异常）→拍照、保留传票、当日报告（冷链温度异常是高责任场景）；交通违规→点数制（6 点内停驾照 courses），特定技能者重大违规直接影响在留更新。
- **饮酒与药物（红线）**：酒测出车前后各一次，**检出即点呼不通过→当日停驾**；前夜饮酒次日晨检出（残留酒精）也是事故实绩高发点——当天的酒当天止；特定技能者因酒精 / 药物事故＝几乎必然失去在留资格。
- **恶劣天气与季节性风险**：冬季积雪（北陆 / 东北 / 北海道）——冬用轮胎、链子携带义务地区；台风（7–10 月）——停运判断权在公司，个人不硬闯；夏季高温——冷链货物风险、车厢内热中症。
- **入职初期 90 天安全路线图**：W1–2 点呼 / 点检 / 传票流程背熟、跟乘先辈路线；W3–6 独立短路线、每日复盘（急刹 / 急转 / 礼让记录）；W7–12 全路线独立、学习异常处理与客户对应。安全实绩（无事故无违规月数）是阶段 3 管理岗评估与资格切换审查的正面材料。
- **局限说明**：本维度无统计数字，属合规要点（事实），故在第 8 节一并声明其证据边界。

## 三、人才供需与薪酬（核心模块）

### 3.1 薪资水平（多口径并列，不合并）

- **卡车司机平均年收**：**约 430 万日元**（月收约 27 万＋年间赏与约 106 万，**含赏与年收口径**；手册 02，2026 年市场数据，**原始来源待核验**）——与官方「月均现金给与 341,158 円（不含赏与）」**不可直接对比**。[Source: https://www.mhlw.go.jp/toukei/itiran/roudou/monthly/r08/2609p/2609p.html, 2026]
- **官方月均统计值**：運輸業・郵便業 现金给与总额 **341,158 円（+4.9%）**（厚労省毎月勤労統計 2026-09，2026-11-06 公布；不含赏与）——官方活值以 [01-ssw-driver 登记册 #5](https://github.com/hmbphxkw76-byte/jp-life-work/blob/main/01-ssw-driver/data/ssw_driver_indicator_registry.md) 为准。
- **全ト协賃金実態**：**2025 年度版**（+5.3% 全职务；jta.or.jp，2026-07-01 公表）——男性大型司机月薪 39.5 万円（+4%）；全职务平均含奖金 41.64 万円（+7.1%，**全职务口径，非男性大型**）（jta.or.jp 直读，A 级；原件待复核）。[Source: https://jta.or.jp/member/chosa/chinginjittai2025.html, 2026]
- **求人市场示例**（手册 02，2026，**原始来源待核验**）：大型干线 月给 **35–43 万**；一般配送 **25–33 万**；冷链 / 危险品附加 **2–5 万**。
- **特定技能 1 号硬性要求**：**工资与日本人同等以上**——面试时拿同岗位日本员工待遇基准对照。

### 3.2 工资构成拆解（看 offer 必看项）

| 项目 | 说明 | 警惕点 |
|---|---|---|
| 基本给 | 固定部分 | 占比过低＝靠加班凑收入 |
| 乗務手当 / 出勤手当 | 按乘务日数 / 出勤次数 | 请假即减收 |
| 时间外手当 | 加班费（1.25 倍起） | 是否按法定计算、有无「固定残業代」 |
| 早朝 / 深夜手当 | 22–29 时 1.25 倍以上 | 夜间干线的主要收入来源 |
| 积込 / 积下ろし手当 | 装卸费 | 有无——影响实际劳动强度 |
| 赏与 | 年 1–4 个月不等 | 特定技能初期公司是否同等待遇 |
| 各类保险 | 雇保 / 健保 / 厚生年金 | 必须加入（永住证据链） |

**年收换算公式**：（基本给＋诸手当）×12＋赏与−欠勤减额。

### 3.3 入职前必问清单与红牌信号

**必问清单（面试验证用）**：

- [ ] 平均月加班时间？最近 3 个月实绩？
- [ ] 36 协定特别条项是否签订？年加班上限多少？
- [ ] 固定残业代制还是全额实算制？
- [ ] 休日：每月休息天数？运输行业常见的「シフト休」如何安排？
- [ ] 赏与・昇给实绩（前 3 年）？
- [ ] 特定技能员工现有几名？支援体制（自家 / 登录支援机关）？
- [ ] 社保（健保＋厚生年金）加入？——从第一天起影响永住证据链

**红牌信号（出现即谨慎）**：

- 月给数字漂亮但「乗務手当」占比 >50% 且无加班实算
- 「残業は自己申告制」（＝不给加班费的话术）
- 无厚生年金（只有国民年金）→ 违法＋毁永住积累
- 高离职率（面试可问「先辈特定技能员工现在几人在职」）

### 3.4 求人样本（只读引用 01-ssw-driver）

- 登记册 #3 记 **10 条样本**立档（岗位 × 地域 × 月収 × URL），其中 9 条完成官网回溯；样本分层为东京圈 / 大阪圈 / 地方＋特定技能专项，月给区间汇总为东京圈 22–45 万円、大阪圈 32–38 万円（桑原经官网回溯修正）、地方 25–36 万円（聚合平台转载口径）。逐条样本、核实状态与来源分级见 [01-ssw-driver 第 3.3 节](../../01-ssw-driver/reports/2026-11-ssw-driver.md)。
- **口径提示**：平台样本「月収」含 / 不含手当口径须逐条注明，不得与实收直接对比；本主题不独立改值。

| 大型综合物流（佐川急便 / SGHD、雅玛多、日通、福山通运） | 全国网络、特定技能接收先行（佐川 2025 年接收越南司机，业界首批案例之一） | 待遇公告高于行业均值；认定与支援体制较完整 | [01-ssw-driver](../../01-ssw-driver/reports/2026-11-ssw-driver.md)（只读引用） |
| 地方中坚运输企业 | 地方缺人明显、竞争小、生活成本低 | 直接应聘地方企业官网；干线 / 大型岗位地方反而高（月 35 万+常见） | 手册 05 地域策略 |

### 4.2 受入资格筛查（雇主侧硬条件）

- **只投能做「特定技能受入计划书认定」的企业**：未认定企业无法雇特定技能者——让对方出示认定证明或说明申请进度。
- **支援体制**：自家实施还是登录支援机关（费用由企业负担——法定）；登记支援机关名单与费用行情见 [01-ssw-driver 第 6.3 节](../../01-ssw-driver/reports/2026-11-ssw-driver.md)。
- **社保加入**：健保 / 厚生年金 / 雇保从第一天起影响永住证据链。

## 五、岗位技能要求

### 5.1 岗位类型谱系

| 类型 | 车辆 | 特点 | 新人难度 |
|---|---|---|---|
| 路线配送（ルート配送） | 轻型～普通（2t 前后） | 固定客户、每日同路线，家庭配达 / 法人配达 | ★ 最适合入场 |
| 仓库内配送 / 场内运输 | 托盘车、2t | 仓库与厂区间短驳，节奏稳定 | ★ |
| 一般区域配送 | 普通～中型（2–4t） | 多点配送、要搬运装卸 | ★★ |
| 冷链配送（冷蔵 / 冷凍） | 冷藏冷冻车 | 生鲜 / 医药，时限严、温控管理责任重 | ★★ 薪资略高 |
| 中型·大型干线 | 中型（4–11t）/ 大型（11t+） | 长距离、夜间多、体力要求高 | ★★★ 薪资最高 |
| 特殊车辆 | 牵引（トレーラー）、罐车、危险品 | 需追加资格（けん引 / 危険物乙4 等） | ★★★★ |

**入场策略（建议）**：从特定技能 1 号（卡车）入境 → 先做路线配送 / 仓库关联岗位 → 1–2 年内视条件向中型 / 冷链 / 干线升级。

### 5.2 车种与驾照对应（2024 年新制度后）

| 车牌种类 | 对应车辆 | 备注 |
|---|---|---|
| 普通免许 | 总重 3.5t 未满（货物 2t 未满） | 2024-05 起新设**準中型**，普通范围收窄 |
| 準中型免许 | 总重 3.5–7.5t | 新制度下进入中型世界的第一张牌 |
| 中型免许 | 总重 7.5–11t | 需 21 岁＋驾龄 2 年（取得时点） |
| 大型免许 | 11t 以上 | 需 21 岁＋驾龄 3 年（取得时点） |
| 第二种免许 | 载客（出租车 / 巴士） | 特定技能出租车 / 巴士路径才需要 |

### 5.3 一天的工作流（典型路线配送）

```text
出勤 → 点呼（酒测/健康确认/运行指示） → 日常点検 → 出库
→ 配送循环（積込→搬入→伝票受领） ×N → 归库 → 后处理（伝票整理/清扫/充电加油）
→ 退勤（点呼确认）
```

- **点呼（てんこ）**：每次出车前后的法定程序（酒测、健康、指示传达）——运行业务的中枢制度。
- **日常点検**：出车前检查项目 60+ 项，记录入点检表。

### 5.4 分野内的职业深化方向

| 方向 | 关键能力 |
|---|---|
| 冷链专家 | 温度管理记录、医药 / 生鲜 GSP 意识 |
| 干线 / 大型 | 长距离耐力、车检 / 油耗管理 |
| 调度（配車） | 排班、路线优化、客户调整 |
| 运行管理员 | 法定资格：运行管理者资任者讲习＋1 年实务（→ [08-visa-immigration](../../08-visa-immigration/reports/2026-11-visa-immigration.md)） |

## 六、行业认可的职业资质与证书

### 6.1 驾照体系与取得费用

| 路径 | 要点 | 费用 / 合格率 |
|---|---|---|

## 七、就业落地路径建议（结论章）

> 本章为建议与推断层，与前三节事实数据分离；不承诺就业结果、不保证薪资水平、不给「必过」式断言。

### 7.1 求职渠道矩阵

| 渠道 | 特点 | 优先级 |
|---|---|---|
| **特定技能专门中介 / 登录支援机关** | 与接受企业绑定，包支援义务，风险最低 | ★★★ 主渠道 |

| トラバイト等运输专门转职站 | 司机岗位全、薪资行情直观 | ★★ |

### 7.2 地域选择策略（影响收入与生活）

| 因素 | 建议方向 |
|---|---|
| 运输需求 | 大都市圈岗位多但竞争 / 物价高；地方（北关东、东海、九州）缺人更明显 |

| 冬季 | 避免初入行就选豪雪地带（驾驶风险） |

### 7.3 简历与面试

- **履歴書**：JIS 规格手写或打印均可，照片正装，全角日期，学历职历从新往旧不空白（空白期写「日本語学習」等）。
- **职务经历书**：突出**驾驶经历（车种 / 里程 / 事故率）、装卸 / 仓库经验、资格（驾照 / 试验合格）**；中文驾照驾龄换算为「運転歴○年」并注明车种；附上 ClassNK 合格证明、JLPT / JFT 成绩（复印件）。
- **面试高频问题与回答方向**：

| 问题 | 回答方向 |
|---|---|
| なぜ日本で？なぜ運送業？ | 物流职业规划（司机→管理→技术）＋已考取的试验合格＝行动证明 |
| 運転歴・車種？ | 实话＋车种对应表（→ 5.2） |
| 夜勤・長距離できる？ | 诚实回答体能边界，给出意向区间 |
| 日本語は？ | 当场演示：点呼应答 / 传票确认 / 事故报告三段话术 |
| 給与の希望？ | 参考市场数据报价区间，问清构成（→ 3.2） |

- **面试日语速成包**：自己紹介（中国から参りました…特定技能の試験に合格しています…将来は運行管理も…）、点呼应答（はい、体調に問題ありません。異常ありません。）、確認表現（〜という理解でよろしいでしょうか。）、辞退表現（検討して、明日までにお返事いたします。）。

### 7.4 契约审查清单（签约前逐项核对）

- [ ] 雇佣契约书：职务 / 场所 / 工资构成 / 时间外 / 休日与面试口径一致

### 7.5 工作条件记录与永住证据链（建议 / 推断）

- **记录模板**（手册 06）：公司概况（公司名称 / 所在地、车种与路线类型、特定技能员工数、支援体制、受入计划书认定编号）；月度记录表（实收工资、构成、加班 h、出勤日、夜班数、备注）；半年对比表（月均收入、月均加班、与契约差异、与同行 offer 数据对比、行动判断）；工作环境定性记录（每半年 1 次）；凭证归档索引。
