# 日本 · 签证与在留资格 · 事件触发解读 / 年度台账复盘提示词（政策法规解读型）

> **用途**：事件触发单份解读（新政策 / 修订 / 配套细则出台后）与年度台账复盘统一入口。可直接复制，替换顶部变量后提交给 AI 执行。
> **产出**：单份解读件 `{{OUTPUT_PATH}}`（`reports/{{YYYY-MM}}-<slug>.md` + 同名 HTML）或年度台账复盘（`reports/{{YYYY-MM}}-<slug>.md` + 同名 HTML）。解读件命名不在标准正则内，validate 仅 WARN 不阻断，属预期。
>
> **继承声明（四层体系）**：本文件 = [通用基座](../../src/report_templates/prompt-generic-base.md) × [监测报告通用规范](../../src/report_templates/monitoring-common-spec.md) × [事件触发解读类型模板（政策法规解读型）](../../src/report_templates/policy-analysis/prompt-policy-review-template.md) × [业务专属配置](./business-config.md)。冲突时以本文件为准。

## 运行变量（每次运行前填写）

```
{{CURRENT_DATE}}         = 本次执行日期，格式 YYYY-MM-DD
{{TRIGGER_TYPE}}         = 本次触发类型（新政策 / 修订 / 细则 / 年度台账复盘）
{{PREVIOUS_REPORT_PATH}} = 上期解读 / 复盘路径（如无则空，仅锚定基线）
{{BASELINE_REPORT_PATH}} = reports/{{YYYY-MM}}-<slug>.md
{{REGISTRY_PATH}}        = data/visa_immigration_indicator_registry.md
{{OUTPUT_PATH}}          = reports/{{YYYY-MM}}-<slug>.md 或 reports/{{YYYY-MM}}-<slug>.md
{{REPORT_VERSION}}       = 本次版本号，格式 vYYYY.MM.DD
```

固定值（不填，读自业务配置第一节）：`{{REGION}}`、`{{TOPIC}}`、`{{FRESHNESS_PRIORITY}}`、`{{SOURCE_LANGUAGE_RULE}}`、`{{REPO_RAW_URL_BASE}}`。

**任务目标**：完成「原文回溯 → 逐条解读 → 影响评估 → 台账更新」闭环；新政策先登记发布与生效日期、官方 URL 后才可进入解读；征求意见稿登记但标注「非最终文本，以正式发布为准」；无触发时不启动新解读，台账标注「截至 {{CURRENT_DATE}} 无更新」。

## 一、节拍与触发

事件触发解读 + 年度台账复盘设计见[事件触发解读类型模板第一节](../../src/report_templates/policy-analysis/prompt-policy-review-template.md)。业务触发器清单（`事件 → 受影响模块`）见[业务配置第七节](./business-config.md)：

```
- 出入国在留管理庁特定技能制度改定（分野扩缩、要件变更、在留上限调整） → 01 / 02 / 05
- 「自動車運送業」技能試験・日本語試験新年度日程或大纲变更 → 03
- 育成就劳制度法案 / 运用要領 / 分野别运用方针进展 → 06
- 永住許可ガイドライン改定（年収・年金・日本語・制度理解要件） → 07
- 「家族滞在」在留资格要件变化 → 08
- 資格外活動許可规则变化 → 08
- 外务省 / 领馆签证费、审查期间、申请流程调整 → 04
- 01-ssw-driver 监测报告「已修正事实清单」追加 → 对应文档回写
```

## 二、项目专属硬性约束

1. **官方原文铁律**：媒体转述仅作线索；引用逐条附官方原文 URL 与版本日期。
2. **结论边界**：不构成法律意见；应对建议标「建议」；歧义条款多解并列。
3. **术语口径**：特定技能 / 技能实习 / 特定活动 / 育成就劳、1 号 / 2 号、「自動車運送業」分野（无 2 号）不得混用。
4. **边界纪律**：法规条文深度解读归 09、永住年收财务归 07、日语学习归 11、现场层归 02、行业结构归 04。
5. **交叉验证锚**：分野在留者数（锚 01 #1）、受入上限与试验要件（#2）、试验费用（#3）与 01-ssw-driver 最新报告 / 登记册只读核对；冲突回官方原文复核，由 01 主责更新，本主题不得独立回写。

## 三、各模块要点

按[业务配置第 3.3 节](./business-config.md)的结构映射逐模块实例化：

- **特定技能制度概览（对应监管框架总览）**：制度定位、1 号 / 2 号对比、分野一览、与其他资格关系；受入上限与分野在留者数取官方最新值（活值走登记册）。
- **特定技能 1 号・自动车运送业 / 考试与日语要求 / 2 号与升级路径（对应重点政策逐条解读）**：本分野课加条件、要件、技能試験（ClassNK）与 JFT-Basic / JLPT 日程费用、2 号要件与备选资格路径。
- **育成就劳制度与新动向（对应重点政策逐条解读）**：法案进展、运用要領・分野别运用方针、MOC 国家名单。
- **永住与长期在留规划 / 家属带同与家庭规划（对应影响对象矩阵 / 合规应对建议）**：永住許可ガイドライン最新口径、取消风险、10 年时间线；家族滞在扶养要件、資格外活動許可（周 28 小时上限·个别许可要件）、子女就学衔接。
- **申请流程与材料（对应合规应对建议）**：海外申请 / 国内移行两条路径、材料清单、风险点。

> 若本期按九节骨架重排：九节标题逐字继承基线（或经批准的骨架），不得增删节或调整顺序；重排须在[业务配置](./business-config.md)版本记录留痕。

## 四、基线锚定与防回退

- 读取 `{{PREVIOUS_REPORT_PATH}}`（如无则空）与 `{{BASELINE_REPORT_PATH}}`，继承监管框架地图、解读规则与全部已核实结论。
- 逐条继承「已修正事实清单」（以 01-ssw-driver 报告文首为单一事实源），产生修正后追加（格式见[通用基座第五节](../../src/report_templates/prompt-generic-base.md)）；严禁重新引入已被推翻的说法；无来源不得入清单。
- 上年趋势判断逐条复判，原文保留；不得删除或改写上年判断。

## 五、追踪表与登记册联动

按[业务配置第八节](./business-config.md)的 11 项追踪指标逐项核对并填写「是否更新」；运行前从 `{{REGISTRY_PATH}}` 读台账 → 增量登记 / 状态变更 → 运行后回写。政策变更摘要覆盖本期新增 / 修订 / 生效 / 废止清单及影响方向；未核实项单列「待复核清单」。prompt 模板内不填活值。

## 六、执行方式（建议）

1. 原文回溯先行：完成官方原文登记（URL、版本日期、文本完整性）后再启动逐条解读子代理。
2. 主代理读取 `{{BASELINE_REPORT_PATH}}` 做框架对齐，继承已修正事实清单，应用第三节要点。
3. 与现行制度冲突的解读须并列新旧对照；无法核实项单列「待复核清单」。
4. 回写报告与登记册后运行 `python src/prompts-tools/tools/md2html.py` 重新生成 HTML，并运行 `python src/prompts-tools/tools/lint_reports.py` 校验。

## 七、渲染与交付

- 交付格式：md + 同目录自包含 HTML；年度台账复盘报告含顶部九锚点导航（`.report-nav`），`.nav-url` = `{{REPO_RAW_URL_BASE}}` + `/reports/{本期文件名}`。
- HTML 须通过 `lint_reports.py` 标签配对校验。
- 基线报告常驻 `reports/` 顶层不归档；解读件按保留策略执行（年度复盘保留 5 期，超出移入 `reports/archives/`）。

- [ ] 与 01-ssw-driver 最新报告 / 登记册交叉验证一致，未越界回写
