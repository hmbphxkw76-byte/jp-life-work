# 日本 · 签证与在留资格 · 首期基线报告提示词（政策法规解读型）

> **用途**：执行「日本 签证与在留资格 政策解读机制」的**机制建立**任务：产出首期监管框架基线报告与配套政策台账。
> **现状**：本业务线基线已于 2026-11 产出（[reports/{{YYYY-MM}}-<slug>.md](../reports/{{YYYY-MM}}-<slug>.md) + 同名 HTML，v1.0）。**正常运行永不重跑基线提示词**；仅在①报告与登记册全部丢失（灾难恢复），或②经维护规范批准的九节结构重排时启动。
> **产出**：md 源稿 + 同目录自包含 HTML，落盘 `{{OUTPUT_PATH}}`；政策台账回写 `{{REGISTRY_PATH}}`。
>
> **继承声明（四层体系）**：本文件 = [通用基座](../../src/report_templates/prompt-generic-base.md) × [监测报告通用规范](../../src/report_templates/monitoring-common-spec.md) × [基线报告类型模板（政策法规解读型）](../../src/report_templates/policy-analysis/prompt-baseline-setup-template.md) × [业务专属配置](./business-config.md)。冲突时以本文件为准。

## 一、项目专属硬性约束

1. **官方原文铁律**：媒体转述仅作线索；引用逐条附官方原文 URL 与版本日期。中文来源仅作线索定位，引用须回溯日 / 英原文（外务省领馆中文页费用类可作一手，须注明领馆与适用起始日）。
2. **只盯官方文本**：不采集舆论反应（边界归舆情监测型）；原文有歧义处并列多解，不静默择一。
3. **结论边界**：不构成法律意见；合规应对建议标「建议」；重大合规决策提示咨询执业法律专业人士。
4. **术语口径**：特定技能 / 技能实习 / 特定活动 / 育成就劳不得混用；1 号 / 2 号不得混用；「自動車運送業」分野（无 2 号）不得与其他运输岗位混用。
5. **边界纪律**：法规条文深度解读归 09、永住年收财务归 07、日语学习归 11、现场层归 02、行业结构归 04；官方统计活值只读引用 01 登记册。

## 二、来源优先级

见[业务配置第五节](./business-config.md)：① 出入国在留管理庁 / ssw.go.jp / e-Gov / 国土交通省 ＞ ② JFT-Basic / JLPT / OTIT ＞ ③ 行业协会 ＞ ④ 中介（仅流程参考） ＞ ⑤ 媒体（须回原文）。每条数据附官方原文 URL 与版本日期。

## 三、基线锚定与重启条件

- 基线报告一经产出即为对比锚：监管框架地图、解读规则与已核实结论由后续事件触发解读完整继承。
- **正常运行不重跑**。重启仅限两种情形：①灾难恢复（报告与登记册全部丢失）；②九节结构经维护规范批准重排。重排须在[业务配置](./business-config.md)第十二节版本记录留痕，并同步评估解读提示词。
- 现状：首期基线保留现行九章结构（业务固化锚），结构映射见[业务配置第 3.3 节](./business-config.md)。

## 五、追踪表与边界档案

按[业务配置第八节](./business-config.md)的 11 项追踪指标逐项核对并填写「是否更新」；运行后回写 `{{REGISTRY_PATH}}` 的核心指标与[研究边界档案](./business-config.md)（领域边界、制度分层、主体清单与入选标准、口径清单）。未核实项注明「待核实」，不补值、不外推；prompt 模板内不填活值。

## 六、执行方式（建议）

1. 原文回溯先行：逐渠道核对官方原文，完成台账登记后才进入解读环节。
2. 并行启动 2–4 个研究子代理：① 特定技能制度与 2 号路径；② 考试与申请流程；③ 育成就劳；④ 永住与政策日志。全部限定日 / 英来源、逐点引用，每条数据附可直接访问的 URL。
3. 主代理合并差异，冲突口径保留双份引用，无法核实项单列「待复核清单」。
4. 制度类数字与 01-ssw-driver 最新报告 / 登记册交叉验证一致（只读锚，不回写）。

## 七、渲染与交付

- 交付格式：md + 同目录自包含 HTML（`python src/prompts-tools/tools/md2html.py`）；HTML 须通过 `python src/prompts-tools/tools/lint_reports.py`（免责声明双条件）。
- 基线导航采用简化锚点目录，不强制 `.report-nav`。
- 落盘后将[业务配置第一节](./business-config.md)的 `{{BASELINE_REPORT_PATH}}` 指向本报告（重建场景）。
