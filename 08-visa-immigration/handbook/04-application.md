# 04 申请流程与材料

> 信息核对日期：2026-11-11。材料清单为通用模板，实际以 ISA 及国土交通省当期格式为准。
>
> **边界**：活值查 [data/visa_immigration_indicator_registry.md](../data/visa_immigration_indicator_registry.md)；跨主题边界与归属见文末「关联」。

## 一、两条申请路径

### 路径 A：海外直接申请（中国国内 → 日本）

1. 在中国完成：评价试验（如本国设考场）或赴日/赴第三国受验 + JFT-Basic/JLPT N4
2. 与日本雇主签订雇佣契约
3. 雇主向国土交通省申请「特定技能 1 号受入计划书」认定
4. 雇主（或行政书士）代理本人向地方出入国在留管理局申请**在留资格认定证明书（COE）**
5. COE 寄回国内 → 向日本驻华使领馆（指定代办机构）申请签证；单次签证费 **715 元**（2026-07-01 起，代办机构另收手续费）[Source: https://www.shanghai.cn.emb-japan.go.jp/itpr_ja/11_000001_00633.html, 2026]
6. 入境，领取在留卡

### 路径 B：国内移行（已持其他在留资格）

- 持技能实习（育成就劳）等资格者：完成同等技能·日语要件后，由雇主申请**在留资格变更许可**
- 2027 年育成就劳施行后，育成就劳 → 特定技能移行将成为主流通道（→ [06-育成就劳制度与新动向](06-trainee-labor.md)）

## 二、申请材料清单（1 号·卡车）

### 本人提供

| 材料 | 备注 |
|---|---|
| 在留资格认定证明书交付申请书 | 法务省指定格式 |
| 护照复印件、证件照 | 规格 4cm×3cm |
| 评价试验合格证明书 | ClassNK 发放 |
| 日语能力证明 | JFT-Basic 成绩单或 JLPT 合格证书 |
| 驾照复印件 | 外国驾照需附翻译（日本自动车联盟 JAF 等） |
| 履历书 | 记载学历、职历、驾驶经历 |
| 返纳保证书等承诺文件 | 指定格式 |

### 雇主提供

| 材料 | 备注 |
|---|---|
| 特定技能 1 号受入计划书认定证明 | 国土交通省发放 |
| 雇佣契约书复印件 | 明示工资、工时、与日本人同等待遇 |
| 支援计划书 + 支援实绩相关文件 | 本人实施或委托登录支援机关 |
| 公司登记事项证明书、损益计算书等 | 证明经营稳定性 |
| 雇用保险・社保加入证明 | 合规要件 |

## 三、在留管理与更新义务（落地后）

1. 在留卡随身携带；地址变更 14 日内报备市役所/入管
2. 每次在留期满前申请更新（1 年/6 个月/4 个月）
3. 无正当理由连续 3 个月不从事原业务 → 资格取消风险
4. 工资、考勤、社会保险记录需长期留存 → 作为 2 号移行与永住的**证据链**（→ [07-永住与长期在留规划](07-permanent-residence.md)）

## 四、常见拒签/不许可风险点

- 雇主受入计划书认定瑕疵（工资低于同业水平、违规前科）
- 日语能力证明与实际沟通能力差距过大（面谈/审查环节）
- 驾照翻译件不符合要求
- 支援体制不落实（无登录支援机关且企业自办能力不足）

## 五、办理机构

- 申请代理：行政书士（雇主任名义人申请义务，费用一般由雇主承担）
- 自助确认：地方出入国在留管理局及 ISA 官网
- 自动车运送业分野政策咨询：国土交通省综合政策局
