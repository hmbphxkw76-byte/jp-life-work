# <主题名称> 词汇导入模板（<topic-id>）

> **用法**：复制本文件到 `data/<topic-id>/imports/`，重命名为 `YYYY-MM-DD_<说明>.md`，按下表填写后执行 `import`，导入完成后原文件永久保留作为来源留痕。
> **格式契约**：6 列 `词条 / 别名 / 分类 / 标签 / 定义 / 来源`；别名与标签用半角分号 `;` 分隔；单元格内不得出现竖线与换行。
> **分类约束**：必须取自 `config/topics.json` 中该主题的 `categories` 受控词表。
> **幂等**：已存在的词条/别名会自动跳过并计数，可安全重跑。
