# 置信度分级标准（通用层：来源等级 × 时效 × 核验状态）

> **用途**：全库统一的**置信度分级基准**，替代原有纯定性的「事实 / 推断」标注方式。
> **三维度**：来源等级（S/A/B/C）× 时效（新 / 中 / 旧）× 核验状态（已核验 / 部分核验 / 待核实）。
> **分级码**：两位——首位为来源等级字母，末位为综合等级数字（1/2/3）。示例：`A1`、`A2`、`B1`。
> **单一事实源**：本文件为通用基准；`00-decision-hub/prompts/confidence-grade-standard.md` 仅保留 00 特有口径并引用本文件。

---

## 一、三维度定义

### 1.1 来源等级

| 等级 | 定义 | 典型来源 |
|---|---|---|
| S | 官方一手统计 / 政策原文，且直读原文 | 厚労省毎月勤労統計、ISA 统计、e-Gov 法令、総務省 |
| A | 官方一手但经转引，或权威行业机构直读 | 经 drivey.jp 转引的警察庁数据、jta.or.jp 直读、release.tdnet.info |
| B | 企业官网 / 采用站一手、地方自治体官网 | 求人企业官网、自治体官网、银行 / 运营商官网 |
| C | 聚合平台转载、媒体、手册估算 | 求人聚合转载、手册估算、比价门户 |

### 1.2 时效

| 等级 | 定义 |
|---|---|
| 新 | 数据时点距引用日 ≤ 6 个月，或制度为现行有效 |
| 中 | 数据时点距引用日 6–18 个月，或制度虽有效但临近改定 |
| 旧 | 数据时点距引用日 > 18 个月，或来源无版本日期 / 已废止 |

### 1.3 核验状态

| 等级 | 定义 |
|---|---|
| 已核验 | 已取得官方原文 / 直接可访问 URL，值与口径已确认 |
| 部分核验 | 框架 / 入口已确认，细则（金额 / 期限 / 书类）待补 |
| 待核实 | 仅有线索或转引，未取得官方原文；或标「⚠ 待核实 / ⚠ 待记录」 |

---

## 二、分级码合成规则

**分级码 = 来源等级字母 + 综合等级数字**。综合等级由「时效 + 核验状态」合成：

| 综合等级 | 判定规则 |
|---|---|
| 1 | 时效「新」且核验「已核验」 |
| 2 | 时效「新 / 中」且核验「部分核验」，或时效「中」且核验「已核验」 |
| 3 | 时效「旧」或核验「待核实」，或来源为「推断 / 手册估算」 |

**示例**：

| 场景 | 来源 | 时效 | 核验 | 分级 |
|---|---|---|---|---|
| 受入上限 22,100（2026-01-23 阁议，现行） | S | 新 | 已核验 | **S1** |
| 运输业月均工资 341,158 円（2026-09） | S | 新 | 已核验 | **S1** |
| 外免切替合格率（经 drivey.jp 转引） | A | 新 | 已核验 | **A1** |
| 求人抽样（聚合转载为主） | C | 新 | 部分核验 | **C2** |
| 生活成本 10.5–17.0 万円（手册估算） | C | 中 | 待核实 | **C3** |
| 自动驾驶 2027 年度前影响（分析推断） | C | 新 | 待核实 | **C3** |

---

## 三、使用规则

1. **标注位置**：五问结论、关键数字、判读句后附分级码，如「（S1）」「（A1）」。
2. **推断处理**：推断不写「事实」，标「推断」并按来源（分析）+ 核验（待核实）定级，通常 `C3`；若基于 S1 事实的强推断可标 `B2` 并注明依据。
3. **冲突口径**：多口径并列时，各口径分别定级，不合并、不取均值。
4. **替代关系**：本分级**替代**原有「事实 / 推断」纯定性标注；历史报告在增量复核时按本标准转换。
5. **决策汇总**：00 决策枢纽在登记册与报告中统一汇总展示五问结论的分级。
