# 事实卡片标准（Fact Card Standard）

> **用途**：全库高频共享数字的**单一事实源**规范。每个被多份报告引用的数字，只在「事实卡片」中维护一次，其他报告统一通过**指针**引用，不再各自复制值。
> **适用范围**：跨主题共享数字（受入上限、在留者数、求人倍率、工资、教习费、生活成本等）集中于 `00-decision-hub/data/fact_cards.md`；主题内部数字留在主题登记册活值表。

---

## 一、五字段（必填）

每张事实卡片必须包含以下五个字段，缺项视为不合格：

| 字段 | 说明 | 示例 |
|---|---|---|
| **值** | 数字或区间，含单位；多口径并列时分别建卡 | 22,100 人 |
| **统计口径** | 机构 · 指标定义 · 是否含赏与 / 是否含加班等 | ISA「特定技能 1 号分野别受入れ見込数」 |
| **数据时点** | 统计基准日 / 施行日 / 公布日 | 2026-01-23 阁议（现行） |
| **来源 URL** | 可直接访问的官方原文 URL；估算类无在线来源时填「无在线来源」并注明出处 | https://www.moj.go.jp/isa/content/001472175.pdf |
| **版本号** | 事实卡片版本（vN），值变更时递增 | v1 |

**corroboration 来源数（n22，可选第 6 字段）**：登记支撑该数字的来源计数（行内标注 `corroboration: N` 或 `互证 N`，或表格第 7 列）。
可取值为正整数（已核验的独立来源 URL 数），或字面值 `single-source`。关键共享数字宜 ≥2 独立来源互证；
**但官方统计量与官方定价属唯一权威口径、客观上不存在独立第二来源时，应填 `single-source`**，不得为凑计数加入同一发布者的重复页面或非独立转载；未登记由 `fact_card_check.py` 以 P2 提示。与[置信度分级标准](./confidence-grade-standard.md) §2.2 合成规则配套。

---

## 二、ID 与指针语法

- **ID**：`FC-NNN`（三位序号，如 `FC-001`）。
- **指针**：`[@FC-NNN]`。例：受入上限 **22,100 人**[@FC-001]。
- **引用纪律**：
  1. 报告引用共享数字时**只写指针**，不复制值；若正文必须出现值，写「值（[@FC-NNN]）」。
  2. 主题登记册活值若是共享数字，写成「值（[@FC-NNN]）」，由事实卡片维护五字段。
  3. 指针必须能解析到唯一卡片；失效指针由 `fact_card_check.py` 检出。
- **版本**：值变更 → 版本号 +1，并在卡片「变更记录」留痕；旧版本不删除（冻结存档）。

## 三、存放与分工

| 层级 | 存放 | 维护者 |
|---|---|---|
| 跨主题共享数字 | `00-decision-hub/data/fact_cards.md` | 00 模块（只读消费，不回写来源主题） |
| 主题内部数字 | `NN-主题/data/*_indicator_registry.md` | 来源主题 |
| 事实卡片标准 | `engine/report_templates/fact-card-standard.md` | 框架维护者 |

**单一事实源**：同一数字只在一处维护值；其他位置一律指针。冲突口径**并列建卡**（如不同统计口径各一卡），不合并、不取均值。

---

## 四、校验

`engine/tools/fact_card_check.py`：

1. **五字段完整性**：每张卡片五字段齐全；
2. **指针可解析**：全库 `[@FC-NNN]` 指针均能解析到唯一卡片；
3. **跨报告事实重复率**：统计同一数字（归一化后）在多份报告重复出现的比例，超过门槛（默认 10%）提示收敛为指针；
4. **corroboration 来源数（n22）**：未登记或 `< 2` 时 P2 提示（不阻断）；显式 `single-source` 不计问题。

退出码：0 = 通过；1 = 存在 P0/P1；2 = 仅 P2。
