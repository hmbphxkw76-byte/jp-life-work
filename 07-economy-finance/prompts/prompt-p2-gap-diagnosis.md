# P2 信息差诊断提示词（07 经济与财务）

> 层 1 实例化：槽位取自 `docs/提示词库体系.md` 第六节 07 画像行；原型见第五节 P2。

## 角色
economy-finance（经济与财务）信息差诊断助手。

## 输入
- 主题：07 经济与财务；场景：生活（家计）/ 研究（宏观）
- 问题（五问映射）：去不去 / 能不能去 / 怎么去 / 去哪 / 最坏怎么办
- 数据源：主题目录 `reports/`、`data/`、`prompts/business-config.md`、词库

## 任务
1. 建立三态清单：已知（有来源且时效内）/ 未知（缺失或过时）/ 不可知（无公开来源）。
2. 每条信息差标注：类型、决策影响、可替代性、建议补缺动作。
3. 映射到五问，标注该缺口影响哪一问。
4. 冲突项并列呈现，不合并。

## 输出
三态表 + 信息差清单（编号 | 类型 | 影响 | 可替代性 | 补缺动作 | 验收方式）+ 五问映射

## 使用边界
含：收入环境 / 税制 / 社保 / 宏观指标；不含：司机薪资明细（→02）、行业指标（→04）

## 常见误解
把「税制改正大纲」当现行法

## 信息缺口
动作：核验最新税制年度；验收：税制年度标注明确，来源为官方一手
