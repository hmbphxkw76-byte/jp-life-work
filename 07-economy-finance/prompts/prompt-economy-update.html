一、主题专属硬性约束

通用约束（逐点引用、事实与推断分离、口径标注等）自动继承通用规范第一至四节。本主题额外强制：

  1. 受众定位：个人财务规划库：收入结构、生活成本、税务社保年金、长期财务规划。个人数据（实际收支）为自记录口径，宏观行情为官方口径，两者不得混算。
  2. 术语口径区分（正文中不得混用）：
  3. 税引前月収 ≠ 手取り（社保・税后）；
  4. 家計調査（世帯）≠ 勤労統計（事業所）；
  5. 中日对比须注明汇率日与口径。
  6. 交叉验证锚（只读）：運輸業月均工资锚 01-ssw-driver 登记册 #5、100 日元汇率锚 01-ssw-driver 登记册"交叉验证输入"；以上为本主题只读引用项，不得独立回写；若与官方一手来源冲突，先回官方原文复核，再由 01-ssw-driver 主责更新。

二、来源优先级（通用框架的本主题实例化，冲突时报双份并标注）

① 総務省統計局（stat.go.jp 消费物价、家計調査）、厚生労働省（每月勤労統計）、国税庁（税率）、日本年金機構 ＞ ② 中国国家统计局（工资对比输入——项目指定例外）、中国外汇交易中心（chinamoney.com.cn 汇率中间价）＞ ③ 地域自治体生活成本数据 ＞ ④ 比价门户（预期指标）

四、更新协议 + 事件触发器表

刷新窗口与差异对比规则继承通用模板。本主题必查重大事件触发器（命中任一项即触发对应文档重点更新；无触发则降级为核验/收敛型轻运行，不得为制造变化而虚构变化）：

- 每月勤労統計月次更新（锚 01-ssw-driver #5） → 01
- 最低賃金年度改定（厚生労働省 mhlw.go.jp 公布，每年改定一次；锚 01-ssw-driver） → 01
- 汇率中间价大幅波动（按月比较） → 01/04
- 税制/社保年金费率年度修订 → 03（费率依据厚生労働省 mhlw.go.jp 官方公布）
- 消费物价统计月次更新 → 02
- 个人收支月度结算 → 01/02/04

七、执行方式（建议）

  1. 启动 2–3 个并行研究子代理：① 薪资与宏观统计；② 汇率与税制费率；③ 物价与生活成本。全部限定官方来源、逐点引用，每条数据必须附可直接访问的 URL。
  2. 子代理返回后，由主代理读取 {{HANDBOOK_PATH}}（单份知识手册）与受影响章节的上一版快照做差异合并，继承已修正事实、应用第四、五节更新要点。
  3. 对冲突数据保留双份引用；对无法核实项单列"待复核清单"。
  4. 回写完成后运行 python prompts/tools/md2html.py 07-economy-finance/reports 重新生成 HTML；运行 python prompts/tools/archive_reports.py 执行保留策略。

八、输出格式要求

  • 增量回写 {{DOC_LIST}} 中受影响章节；未受影响章节不动；结构性内容（对比模型、储蓄模型、计算框架）按第五节"保持"。
  • 变更摘要与待复核清单写入手册内「导航与使用约定」的更新日志区（格式见知识库模板 T3），不单独成文。
  • 正文新增数据点一律附 [Source: 完整URL, 年份]；表格按通用规范二.2 呈现（主题文字超链接 + hover 来源，不设"来源"列）；推断显式标注。
  • 新增知识在现有文档中找不到位置时，在手册内新建 ## NN 章节（编号顺延）；禁止把不相关内容塞进既有章节，禁止新建独立 .md 文件。
  • 文件命名与保留策略：reports/ 顶层保留最新 3 份（*_baseline 为当前周期基线），其余入 reports/archives/，归档上限 7 份。
  • 基线滚动：*_baseline 按周期滚动（每期第一次更新即新基线），旧基线归档为 archives/*_baseline_<周期>，历史基线保留 12 期；同周期内更新与基线累计对比。详见 基线报告管理规则。
