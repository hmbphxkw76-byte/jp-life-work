# 日本 · 经济与财务 · 首期基线报告提示词（职业就业调研型）

> **用途**：执行「日本 经济与财务 调研机制」的**机制建立**任务：产出首期基线（深度调研）报告与配套指标登记册，作为后续所有周期更新的对比锚与个人财务规划基础。
> **现状**：本业务线基线已于 2026-11 产出（[reports/{{YYYY-MM}}-<slug>.md](../reports/{{YYYY-MM}}-<slug>.md) + 同名 HTML，v1.0，合并整理版日期 2026-11-12）。**正常运行永不重跑基线提示词**；仅在①报告与登记册全部丢失（灾难恢复），或②经维护规范批准的九节结构重排时启动。
> **产出**：md 源稿 + 同目录自包含 HTML，落盘 `{{OUTPUT_PATH}}`；指标活值与研究边界档案回写 `{{REGISTRY_PATH}}`。
>
> **继承声明（四层体系）**：本文件 = [通用基座](../../engine/report_templates/prompt-generic-base.md) × [监测报告通用规范](../../engine/report_templates/monitoring-common-spec.md) × [基线报告类型模板（职业就业调研型）](../../engine/report_templates/employment-research/prompt-baseline-setup-template.md) × [业务专属配置](./business-config.md)。冲突时以本文件为准。

## 一、项目专属硬性约束

1. **受众与结论边界**：面向在日本从事货运司机工作的读者；允许框架性财务规划建议，不承诺收益；个人数据（自记录）与宏观行情（官方口径）不得混算；不给投资评级、不给 Go/No-Go 建议（见[业务配置第二节](./business-config.md)）。
2. **来源语言规则**：统计类须官方原文（日 / 中双语各归其源）；见[业务配置第五节](./business-config.md)。
3. **术语口径**：税引前月収 ≠ 手取り；家計調査 ≠ 勤労統計；最低賃金全国平均 ≠ 都道府県加权；运输業月均工资 ≠ 含赏与年收；中日对比须注明汇率日与口径。
4. **边界纪律**：岗位薪资细节链接 02、行业结构链接 04、自动化链接 05、数字化技能链接 06、管理岗链接 03、在留永住年收要件链接 08、法规框架链接 09、日语学习链接 11、资格教育链接 10；官方统计活值只读引用 01 登记册。
5. **个人记录纪律**：个人收支为自记录口径，只写结构与填写入口，不预填个人信息。

## 二、来源优先级

见[业务配置第五节](./business-config.md)：① 総務省統計局 / 厚生労働省 / 国税庁 / 日本年金機構 ＞ ② 中国国家统计局 / 中国外汇交易中心（项目指定例外） ＞ ③ 地域自治体生活成本数据 ＞ ④ 比价门户（预期指标）。每条数据附完整 URL，每格活值附 `[来源, 年份]`。

## 三、基线锚定与重启条件

- 基线报告一经产出即为对比锚：结构、口径裁决与已核实结论由后续周期更新完整继承。
- **正常运行不重跑**。重启仅限两种情形：①灾难恢复（报告与登记册全部丢失）；②九节结构经维护规范批准重排。重排须在[业务配置](./business-config.md)第十二节版本记录留痕，并同步评估周期更新提示词。
- 现状：首期基线保留现行结构（业务固化锚），结构映射见[业务配置第 3.2 节](./business-config.md)。

## 四、报告结构

九节固定骨架见[基线类型模板第三节](../../engine/report_templates/employment-research/prompt-baseline-setup-template.md)：

| 节 | 模块 |
|---|---|
| 1 | 核心结论（摘要） |
| 2 | 行业与政策发展趋势 |
| 3 | 人才供需与薪酬（核心模块） |
| 4 | 雇主与企业类型细分 |

- 已产出的 2026-11 基线：按[业务配置 3.2 节](./business-config.md)的映射表对应到现行结构，**不改写正文**。
- 若经批准重建：九节标题为固化锚，逐字继承，不得增删节或调整顺序。

## 五、追踪表与边界档案

按[业务配置第八节](./business-config.md)的 6 项追踪指标逐项核对并填写「是否更新」；运行后回写 `{{REGISTRY_PATH}}` 的核心指标与[研究边界档案](./business-config.md)（研究对象边界、收入分层、主体清单与入选标准、口径清单）。未核实项注明「待核实」，不补值、不外推；prompt 模板内不填活值。

## 六、执行方式（建议）

1. 并行启动 3 个研究子代理：① 薪资与宏观统计（厚労省 / 国税庁 / 総務省）；② 汇率与税制费率（中国外汇交易中心 / 厚労省 / 年金機構）；③ 物价与生活成本（総務省 / 地域自治体）。全部限定官方来源、逐点引用，每条数据附可直接访问的 URL。
2. 主代理合并差异，冲突口径保留双份引用，无法核实项单列「待复核清单」。
3. 运输業工资与汇率与 01-ssw-driver 最新报告 / 登记册交叉验证一致（只读锚，不回写）。

## 七、渲染与交付

- 交付格式：md + 同目录自包含 HTML（`python engine/tools/md2html.py`）；HTML 须通过 `python engine/tools/lint_reports.py`。
- 基线导航采用简化锚点目录，不强制 `.report-nav`。
- 落盘后将[业务配置第一节](./business-config.md)的 `{{BASELINE_REPORT_PATH}}` 指向本报告（重建场景）。

## 八、质量自检（通用清单之外的本主题专属项）

- [ ] 税引前月収 / 手取り未混用；家計調査 / 勤労統計未混用
- [ ] 最低賃金全国平均与都道府県加权口径已区分标注
- [ ] 中日对比均注明汇率日与口径
- [ ] 个人数据（自记录）与宏观行情（官方口径）未混算
- [ ] 追踪表 6 项均已核对并填写「是否更新」
- [ ] `{{REGISTRY_PATH}}` 已读已写：变更摘要与登记册一致；prompt 模板自身无硬编码活值
- [ ] HTML 通过 lint（标签配对）
