**核心监测问题**：

1. 运输業月均工资与最低賃金的最新水平及年度变动方向如何？
2. 100 日元汇率中间价的近期水平对日元计价收入与对华汇款意味着什么？
3. 单身司机的月度生活成本与可实现储蓄率处于什么区间？
4. 四大公的义务负担率与年金缴纳证据链是否完整、是否构成永住风险？
5. 10 年财务里程碑与世帯年收达标模拟的关键变量（配偶者就业收入）如何变化？

**初步结论**：

1. **收入基本盘已由官方与锚定活值共同确立**（事实）：运输業月均工资 341,158 円（2026-09，锚 01-ssw-driver #5）与最低賃金 1,177 円（2026 年度）均为可溯源活值，可作为收入维度基线。
2. **最低賃金处于年度上行通道**（事实 + 推断）：2025 年度 1,118 円/h 与 2026 年度 1,177 円并列，差值 59 円，与手册「年涨 40–60 円」经验法则一致。
3. **汇率与 CPI 尚不足以支撑中日对比结论**（事实）：汇率有 2026-11-10 活值（100 日元中间价 4.2355 元），但 CPI 待基线确立，购买力与汇款时点判断暂不成立。
4. **生活成本与储蓄率仅为规划估算**（事实）：10.5–17.0 万円/月与 35% / 45% 目标线为手册估算值，在个人收支结算（待记录）补齐前不得作为结论使用。
5. **税社负担结构清晰但缺活值**（事实）：四大公的义务比例明确，但年金 / 社保个人负担率待基线确立，净收入模型无法闭合。

## 二、行业与政策发展趋势

本节承载经济制度环境与「公的义务」政策面（business-config 3.2：03 章税务社保年金 → 本节 / 第七节）。

**收入制度的年度改定通道（事实）**：最低賃金每年 10 月改定，手册经验法则为年涨 40–60 円；2025 年度全国加权平均 1,118 円/h（手册）与 2026 年度全国平均 1,177 円（登记册）并列，差值 59 円，落在经验区间内。年度核对项：每年 10 月刷新最低賃金与本行业薪资行情；每年 3 月对照前年收入 vs 计划曲线偏差（手册 01）。

**税制与社保年金费率（事实，结构清晰、活值待补）**：

| 项目 | 负担 | 说明 |
|---|---|---|
| 所得税 | 5–45% 超累进 | 公司源泉征收，年末调正处理大部分 |
| 住民税 | 所得约 10% | 次年 6 月起从工资扣 |
| 健康保险（会社健保 / 协けん） | 约 5%（公司对半） | 加入职场保险，不要滞留国民健康保险 |
| 厚生年金 | 9.15%（公司对半，合计 18.3%） | **永住审查核心项** |

到手工资 ≈ 额面 −（所得税 + 住民税 + 社保个人负担）≈ 额面的 78–85%（手册估算，**待核验**）；登记册 #5「年金 / 社保个人负担率」待基线确立。

**红线（事实）**：住民税·社保滞纳 = 永住取消要件（3 年）+ 在留更新减分——零容忍（手册 03）；公的义务的缴纳记录同时是永住证据链资产。

## 七、就业落地路径建议（结论章）

> 本节为建议 / 推断层，与事实数据分离。

**10 年财务里程碑（手册 04）**：

| 时点 | 目标 |
|---|---|
| Y1 | 应急金 50 万円（3 个月生活费）+ 无负债 |
| Y3 | 应急金 100 万円 + 技能投资预算独立（资格 / 驾校） |
| Y5（2 号移行后） | 婚姻 / 家族计划评估；储蓄 400–600 万円 |
| Y6–8 | 家族来日成本（住房升级、语言学校、机票）：预留 150–250 万円 |
| Y10（永住申请） | 储蓄 800 万円+ / 世帯年收达标 / 无任何滞纳记录 |
| Y10+ | 住宅评估（永住者可申请全额房贷）· 子女教育基金 |

**世帯年收达标模拟（永住「年收水准」要件，手册假设）**：日本二人世帯平均年收约 650 万円量级（各年官方数据为准）。Y6 本人 430 万 → 单身期可过；Y8 本人 480 万 + 配偶者 200 万（Part→正社）= 680 万，达标窗口；Y10 本人 520 万 + 配偶者 260 万 = 780 万，稳。策略含义：**配偶者的就业收入是永住年收达标的关键变量**——2 号带家属后，支持配偶者日语学习与就业即是财务规划的一部分（推断）。

**大额决策清单与时机（建议）**：

| 决策 | 建议时机 | 要点 |
|---|---|---|
| 购车（家庭用车） | Y5 后 | 永住前可贷款但额度低；车检 / 保险成本计入 |
| 住宅购入 | 永住取得后 | 永住者房贷利率最优（フラット 35 等）；北海道等土地便宜但要绑定就业地 |
| 子女教育 | Y8 前 | 公立校免费 + 给食；大学阶段教育费 500 万+（国立自宅） |
| 保险组合 | Y3 | 生命保险克制：公司福利 + 健保已覆盖大部分，重点补死亡 / 工伤 |

**汇款建议（建议 / 推断）**：渠道 Wise / Revolut（汇率优）、银行电汇（sofh 银行·住信 SBI 网银对华有优惠线路）、家族汇款用「在住证明 + 用途」文件准备；频率建议按季度集中汇款摊薄手续费，10 万円以下汇款手续简化；汇率在 1 CNY ≈ 19–22 JPY 区间低位多汇（历史波动参考，不做投机）。

**落地后动作（手册 02，建议）**：第 1 个月银行开户（邮储 / 主要 mega bank 都接受在留卡开户）、办 My Number 卡；第 2 个月建立家用账本（Money Forward / freee 家计簿 app）；每半年对比本文件模型 vs 实际，修正偏差。

**年金与归档（手册 03，建议）**：厚生年金按工资比例自动扣——不停职就不断缴，风险最低；ねんきん定期便每年生日月前后寄达 / My Number Portal 可查，**每年存档一份** = 缴费证据；脱退一时金若最终不永住归国可申请（最多 5 年分），本规划走永住则长期复利留下更划算。归档清单：每年 1–2 月前年源泉征收票；每年ねんきん定期便、住民税决定通知书；My Number Portal 按年导出缴费记录 PDF。

**金融习惯（手册 04，建议）**：活期 + 定期组合（Net 系银行利率略高）；iDeCo / つみたてNISA 在留资格稳定（2 号）后再开启——永住前投资账户的处理要向税务士确认；信用卡按时还款积累信用信息（Y1 就开始）。

**年度复盘模板（手册 04）**：每年 1 月对照刷新——储蓄余额 / 世帯年收 / 公的义务记录（零瑕疵）/ 大额决策进度；每年 10 月刷新最低賃金与行情数据。

## 八、数据可靠性与局限说明

**核验程度分级**：

- **A 官方一手**：运输業月均工资（厚労省）、最低賃金（厚生労働省）、100 日元汇率（chinamoney.com.cn）、国税厅 / 厚生劳动省来源标注的统计。
- **B 权威转引**：本主题素材未含权威转引层数据。
- **C 平台抽样 / 估算**：卡车司机平均年收、月给区间、月度成本模型、储蓄模型、到手工资比例、世帯年收模拟（均为手册规划估算，**待核验**）。

**已知口径冲突（并列呈现，不合并、不取均值）**：

| 指标 | 并列口径 |
|---|---|
| 收入 | 税引前月収 ≠ 手取り（社保・税后） |
| 工资统计 | 家計調査（世帯）≠ 勤労統計（事業所） |
| 最低賃金 | 全国平均 ≠ 都道府県加权平均 |
| 司机收入 | 运输業月均工资（厚労省）≠ 卡车司机平均年收（含赏与） |
| 中日对比 | 100 日元中间价 ≠ 1 CNY 折算（汇率日不同） |

**未取得项**：CPI 综合指数（登记册 #4，待基线确立）、年金 / 社保个人负担率（#5，待基线确立）、个人月度收支结算（#6，待记录）；卡车司机平均年收、月给区间、到手工资比例、月度成本模型为手册估算，待核验。

**风险与不确定性**：手册中市场类数字（司机年收、月给、到手比例）无发布机构标注，核验前存在偏差风险；个人收支与 CPI 缺失使储蓄率与世帯年收模拟无法验证；永住年收要件与取消风险归 08-visa-immigration，本主题只提供财务证据链，不构成要件判断。
