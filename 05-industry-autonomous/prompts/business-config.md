## 二、受众定位

面向**计划或正在日本物流行业工作、关注自动化对岗位结构影响**的读者，兼具技术跟踪与职业落地视角。

### 3.2 技术分层口径

```
自动驾驶：L2（人监控·辅助）→ L3（条件下自动驾驶）→ L4（限定区域无人）
落地模式：中継输送（高速干线自动驾驶 + 换乘点人工接管 + 一般道人工驾驶）
新岗位：远隔监控员 / 换乘点运航管理者 / 编组调度
```

## 四、术语口径区分（表格与正文中不得混用）

- **SAE L0–L4**（注明出处版本）≠ 政府「レベル4」表述；等级口径须注明来源版本
- **「レベル4移動等支援ロボット」制度 ≠ 货车自动驾驶実证**（前者为步道/限定空间机器人，后者为公道货车运行）
- **幹線运送 ≠ 市内配送**的自动化替代节奏（推断标注）
- **远隔监控员 ≠ 换乘点运航管理者 ≠ 编组调度**（中継输送模式下的三类新岗位）
- **自动驾驶 ≠ 仓储自动化**（本页分两节，技术谱系不同）

## 十一、渲染与交付差异（相对通用规范的实例化）

- **导航基址**：年度刷新报告 `.nav-url` = `{{REPO_RAW_URL_BASE}}` + `/reports/{本期文件名}`；基线报告保留简化锚点导航，不强制 `.report-nav`。
- **报告结构**：基线按 3.3 声明映射；年度刷新按九节骨架（顶部九锚点导航）。
- **免责声明**：固定原文「本报告仅供参考，不构成投资建议或决策依据。」。**遗留项**：现有基线报告无免责声明节（正文不改，待下一期按模板重写时补齐）。
- **顶部导航**：**遗留项**：现有报告无 `.report-nav` 顶部导航（正文不改，待下一期按模板重写时补齐）。
- **HTML 生成**：迁移不重新生成 HTML（避免引入正文变化）；后续周期运行用 `src/prompts-tools/tools/md2html.py` 生成并过 `lint_reports.py`。
