> **现状**：本业务线基线已于 2026-11 产出（[reports/{{YYYY-MM}}-<slug>.md](../reports/{{YYYY-MM}}-<slug>.md) + 同名 HTML，v1.0）。**正常运行永不重跑基线提示词**；仅在①报告与登记册全部丢失（灾难恢复），或②经维护规范批准的九节结构重排时启动。

## 一、项目专属硬性约束

1. **中性立场**：不给投资评级、不出具 Go/No-Go 决策建议（边界归投资尽调型、可行性型）。
2. **结论边界**：趋势判断一律标「推断」并配反向声音（至少 2 条）；口径冲突并列呈现。
3. **受众定位**：见[业务配置第二节](./business-config.md)；报告须声明受众与视角。
4. **术语口径**：SAE L0–L4 与「レベル4移動等支援ロボット」制度不得混用；幹線运送与市内配送替代节奏不得混用；远隔监控员 / 换乘点运航管理者 / 编组调度不得混用。
5. **边界纪律**：产业规模与赛道归 04、技能岗位归 06、管理岗归 03、现场层归 02、在留制度归 08、法规条文归 09；本报告只写技术与制度面并交叉链接。

## 二、来源优先级

见[业务配置第五节](./business-config.md)：① 警察庁 / 国土交通省 / 経済産業省 ＞ ② SOZ / NEDO ＞ ③ JAMA / 车企与自动化厂商官网 ＞ ④ 国际研究 ＞ ⑤ 媒体（须回原文）。每条数据附完整 URL，每格活值附 `[来源, 年份]`。

## 三、基线锚定与重启条件

- 基线报告一经产出即为对比锚：结构、口径裁决与已核实结论由后续年度刷新完整继承。
- **正常运行不重跑**。重启仅限两种情形：①灾难恢复（报告与登记册全部丢失）；②九节结构经维护规范批准重排。重排须在[业务配置](./business-config.md)第十二节版本记录留痕，并同步评估年度刷新提示词。
- 现状：首期基线保留现行四章结构（业务固化锚），结构映射见[业务配置第 3.3 节](./business-config.md)。

## 五、追踪表与边界档案

按[业务配置第八节](./business-config.md)的四维度逐项核对并填写「是否更新」；运行后回写 `{{REGISTRY_PATH}}` 的核心指标与[研究边界档案](./business-config.md)（领域边界、技术分层、主体清单与入选标准、口径清单）。未核实项注明「待核实」，不补值、不外推；prompt 模板内不填活值。

## 六、执行方式（建议）

1. 并行启动 2–3 个研究子代理：① L4 许可与法规制度；② 政府路线图与车企量产时间表；③ 仓储自动化与无人配送实证 / 商用案例。全部限定日 / 英来源、逐点引用，每条数据附可直接访问的 URL。
2. 主代理合并差异，冲突口径保留双份引用，无法核实项单列「待复核清单」。
3. L4 政策进展与 01-ssw-driver 最新报告 / 登记册 #10 交叉验证一致（只读锚，不回写）。

## 七、渲染与交付

- 交付格式：md + 同目录自包含 HTML（`python src/prompts-tools/tools/md2html.py`）；HTML 须通过 `python src/prompts-tools/tools/lint_reports.py`（免责声明双条件）。
- 基线导航采用简化锚点目录，不强制 `.report-nav`。
- 落盘后将[业务配置第一节](./business-config.md)的 `{{BASELINE_REPORT_PATH}}` 指向本报告（重建场景）。
