七、执行方式（建议）

  1. 启动 2–3 个并行研究子代理：① L4 许可与法规；② 政府路线图与车企量产时间表；③ 仓储自动化商用案例。全部限定日/英来源、逐点引用，每条数据必须附可直接访问的 URL。
  2. 子代理返回后，由主代理读取 {{HANDBOOK_PATH}}（单份知识手册）与受影响章节当前版本做差异合并，继承已修正事实、应用第四、五节更新要点。
  3. 对冲突数据保留双份引用；对无法核实项单列"待复核清单"。
  4. 回写完成后运行 python prompts/tools/md2html.py 05-industry-autonomous/reports 重新生成 HTML；运行 python prompts/tools/archive_reports.py 执行保留策略。
