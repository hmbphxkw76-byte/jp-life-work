> **用途**：执行「日本 日语学习 就业调研机制」的**机制建立**任务：产出首期基线（深度调研）报告与配套指标登记册，作为后续所有周期更新的对比锚与制度基础。
> **现状**：本业务线基线已于 2026-11 产出（[reports/{{YYYY-MM}}-<slug>.md](../reports/{{YYYY-MM}}-<slug>.md) + 同名 HTML，v1.0，数据基准 2026-11-12）。**正常运行永不重跑基线提示词**；仅在①报告与登记册全部丢失（灾难恢复），或②经维护规范批准的九节结构重排时启动。
> **产出**：md 源稿 + 同目录自包含 HTML，落盘 `{{OUTPUT_PATH}}`；指标活值与研究边界档案回写 `{{REGISTRY_PATH}}`。
>
> **继承声明（四层体系）**：本文件 = [通用基座](../../src/report_templates/prompt-generic-base.md) × [监测报告通用规范](../../src/report_templates/monitoring-common-spec.md) × [基线报告类型模板（职业就业调研型）](../../src/report_templates/employment-research/prompt-baseline-setup-template.md) × [业务专属配置](./business-config.md)。冲突时以本文件为准。

## 一、项目专属硬性约束

1. **受众与结论边界**：面向拟通过特定技能（SSW）签证赴日从事货运司机工作、需要分阶段日语学习规划的读者；不承诺考试必过；个人进度数据为自记录个案，标注记录日期（见[业务配置第二节](./business-config.md)）。
2. **来源语言规则**：考试制度类须日 / 英官方原文；学习方法类不限（经验标注为经验）。
3. **术语口径**：JLPT（N 级制）≠ JFT-Basic（A 级制）；特定技能 1 号卡车路径门槛（N4 / JFT-Basic A2）≠ 出租车 / 巴士路径门槛（N3）≠ 管理岗 / 2 号门槛（N2）。
4. **边界纪律**：在留制度侧的考试要求链接 08、现场日语链接 02、管理岗日语链接 03、资格 / 学历路径链接 10；本报告只写学习路线 + 备考 + 进度。
5. **内容边界**：考试日程 / 费用 / 考位等制度类数字以 01-ssw-driver 登记册 #3 为只读锚，本主题不独立改值或回写。

## 二、来源优先级

见[业务配置第五节](./business-config.md)：① JLPT 官方 / JFT-Basic 官方 ＞ ② 国際交流基金 / 日本語能力試験公式資料 ＞ ③ 出版社 / 教材官网 ＞ ④ 学习门户与社区经验（标注为经验）。每条数据附完整 URL，每格活值附 `[来源, 年份]`。

## 三、基线锚定与重启条件

- 基线报告一经产出即为对比锚：结构、口径裁决与已核实结论由后续周期更新完整继承。
- **正常运行不重跑**。重启仅限两种情形：①灾难恢复（报告与登记册全部丢失）；②九节结构经维护规范批准重排。重排须在[业务配置](./business-config.md)第十二节版本记录留痕，并同步评估周期更新提示词。
- 现状：首期基线保留现行结构（业务固化锚），结构映射见[业务配置第 3.2 节](./business-config.md)。

## 五、追踪表与边界档案

按[业务配置第八节](./business-config.md)的 4 项追踪指标逐项核对并填写「是否更新」；运行后回写 `{{REGISTRY_PATH}}` 的核心指标与[研究边界档案](./business-config.md)（领域边界、考试分层、主体清单与入选标准、口径清单）。未核实项注明「待核实」，不补值、不外推；prompt 模板内不填活值。

## 六、执行方式（建议）

1. 并行启动 1–2 个研究子代理：① JLPT / JFT-Basic 考试报名与考场信息；② 教材版本与资源可用性。全部限定日 / 英来源、逐点引用，每条数据附可直接访问的 URL。
2. 主代理合并差异，冲突口径保留双份引用，无法核实项单列「待复核清单」。
3. 与 01-ssw-driver 登记册 #3 交叉验证考试日程 / 费用 / 考位（只读锚，不回写）。

## 七、渲染与交付

- 交付格式：md + 同目录自包含 HTML（`python src/prompts-tools/tools/md2html.py`）；HTML 须通过 `python src/prompts-tools/tools/lint_reports.py`。
- 基线导航采用简化锚点目录，不强制 `.report-nav`。
- 落盘后将[业务配置第一节](./business-config.md)的 `{{BASELINE_REPORT_PATH}}` 指向本报告（重建场景）。
