## 研究边界档案（基线首建，周期运行复核）

### 研究对象边界

- **含**：运输 / 仓储公司内的管理岗（运行管理者 / 运行管理辅助者 / 配车 / 仓库现场リーダー / 安全管理者 / 保管・仓库管理 / 事务所营业）。
- **不含**：载客（出租车 / 巴士）、技能实习（→ 08-visa-immigration）；行业结构与 2024 年問題（→ 04-industry-logistics）；自动驾驶技术制度面（→ 05-industry-autonomous）；技术数字化技能（→ 06-industry-technology）。

### 岗位分层

- 运行管理辅助者 → 运行管理者 → 配车 / 现场リーダー → 主任 / 系长 → 安全管理者。
