1. **管理岗过渡的主线是内部升格（路径 A）**（建议 / 推断）：公司已认识你、资格与实绩连续、雇主支持 2 号移行；路径 B 转职过渡存在 2 号移行中断风险，须在转职前确认新公司做受入计划书变更。

5. **成果档案是晋升与 2 号移行 / 永住审查的共用材料**（建议 / 推断）：KPI 月度表、STAR 卡与晋升面谈材料包同时服务内部晋升、转职简历与在留审查。

## 五、岗位技能要求

**目标岗位地图**（手册 01，信息核对日期 2026-11-11；来源：运行管理者试验中心 [Source: https://www.unkan.or.jp/about.html, 2026]）：

| 岗位 | 职责 | 法定资格 | 入口难度 |
|---|---|---|---|
| **运行管理者（運行管理者）** | 点呼、运行指示、驾驶者管理、运行记录审查——每 15 台车 1 名，公司必置 | 运行管理实务 1 年以上**或**基础讲习修了 → 通过运行管理者试验 | ★★ 最现实的第一个台阶 |
| 运行管理辅助者 | 协助运行管理者 | 基础讲习修了即可 | ★ 无门槛，先干起来 |
| 配车（调度）担当 | 排班、路线、客户调整 | 无法定资格，靠业务能力 | ★★ |
| 仓库现场リーダー | 班组管理、作业效率、人才培养 | 无法定资格 | ★★ |
| 安全管理者 | 安全体制构建、事故分析、教育培训 | 实务经验年数 + 選任時研修（中型以上车辆企业另设安全管理相关职务） | ★★★ |
| 保管/仓库管理（WMS 操作） | 库存管理、入出库流程、系统操作 | 无，WMS 系统经验是硬通货 | ★★★ 对接阶段 4 |
| 事务所/运输营业 | 计费、传票、客户对应 | 无 | ★★ |

**业务知识体系（手册 02）**：

- 仓储运营：入出库流程（受入→検収→入庫→保管→ピッキング→検品→出庫→配送）、FIFO 与在庫回転率、误出库率与件 / 人 / 时、3PL 受託契約与 KPI 契约（SLA）。
- 运输管理：运行管理法制（点呼、运行指示書、运行记录、驾驶时间规制→ 02-career-driver）、配车逻辑、成本结构（固定费 vs 变动费、原価率）、异常运营。
- 安全管理（管理者视角）：ヒヤリハット收集与再现性分析、PDCA 对策立案、月次安全委员会、安全统括管理者 / 安全管理者职责分工。
- 系统与数据基础：Excel VLOOKUP / 透视表、WMS / TMS 概念认知、手工台账起步的数据整理习惯。

**核心 KPI 口径（各自独立，不得混用）**：纳期遵守率（准点率）≠ 装载率 ≠ 空驶率 ≠ 每车日件数；管理活动月度记录为过程口径，活动数量 ≠ 业务结果（business-config 第四节、第十节）。

**管理岗日语与沟通（手册 03，前提 N3 达成）**：

- 四大场景武器库：会议（发言开场 / 报告 / 提案 / 質問）、报告（日報・月報固定模板）、邮件（件名 / 定型句 / 期限 / 结尾）、现场指示（对象 / 内容 / 期限 / 确认 + 复述文化 + 指差呼称）。
- 敬语最小必需集：对上 = 尊敬语、对己 = 谦让语；现场用错的成本低于不敢用的成本——先敢说再修正。
- 训练节奏：每天日報 3 行；每周会议发言 1 次 + 議事録 1 份；每月月報 1 份 + 邮件改写 2 封；每半年对照四大场景自评并记入成果档案。

## 六、行业认可的职业资质与证书

**法定资格路径（事实）**：运行管理者试验受验资格 = 运行管理实务 1 年以上**或**基础讲习修了；试验合格只给入场券，公司是否选任取决于信任与空缺（手册 01，来源：运行管理者试验中心，2026，A 级）。

**术语口径（不得混用）**：

| 口径 | 说明 |
|---|---|
| 运行管理者（選任）≠ 运行管理辅助者 | 前者有法定资格，后者讲习修了即可 |
| 讲习修了 ≠ 试验合格 ≠ 选任 | 三阶段，不可互称 |
| 管理岗（管理職）≠ 现场リーダー（班長） | 职责与法定资格不同 |
| 「技能講習」≠「特別教育」 | 资格制度术语分别标注 |

**费用与日程**：基础讲习「数千円，周末 1 日课程为主」（手册 04，**待核验**）；运行管理者试验费用与具体日程以试验中心官方公布为准。资格日程与费用的主责为 10-education-qualification（[../10-education-qualification/reports/2026-11-education-qualification.md](../../10-education-qualification/reports/2026-11-education-qualification.md)），本主题只读引用、不独立改值；登记册 #2「管理者讲习 / 安全管理责者讲习日程」待基线确立。

**证书归档**：每张证书扫描归档，进入成果档案（手册 05），作为晋升面谈与 2 号移行 / 永住审查材料的组成部分。

## 七、就业落地路径建议（结论章）

> 本节为建议 / 推断层，与前三节的事实数据分离。

**三条过渡路径（手册 01）**：

| 路径 | 内容 | 评估 |
|---|---|---|
| A 内部升格（推荐主线） | 司机 → 运行管理辅助（讲习修了）→ 运行管理者试验合格 → 配车 / 现场リーダー → 主任 / 系长 | 公司已认识你、资格与实绩连续、雇主支持 2 号移行 |
| B 转职过渡 | 2–3 年司机经验 + N3 → 转职到仓储 / 3PL 公司的现场管理 / 配车岗 | 仓库系岗位对日语口语要求低于纯管理，KPI 可量化；风险：在留资格变更需新雇主配合、2 号移行中断风险 |
| C 学历 / 资格加持（叠加项，非主线） | 夜校 / 通信制专门学校（物流・供应链课程）、ロジスティクス検定（L 検）、フォークリフト讲习 | 只在路径 A/B 需要差异化时启用 |

**决策时点表（手册 01，建议）**：入职即观察（本公司是否有辅助者→运行管理者晋升先例）→ 第 12 个月（启动基础讲习报名）→ 第 24 个月（运行管理者试验受验；N3 达成）→ 第 36 个月（竞聘配车 / リーダー；2 号移行申请同步）→ 第 48–60 个月（主任级 + N2；评估内部转 WMS / 事务方向）。

**48 个月分年计划（手册 04，主线）**：

| 年 | 主题 | 月投入（业余） | 年内里程碑 |
|---|---|---|---|
| 第 1 年 | 站稳 + 摸清组织 | 8h/月 | 基础讲习修了证 + 运行管理业务观察笔记 1 份 |
| 第 2 年 | 资格 + 知识体系 | 12h/月 | N3 合格 + 运行管理者试验受验（力争合格） |
| 第 3 年 | 岗位落地 + 2 号移行 | 12h/月 | 2 号移行完成 + 管理辅助岗位在任 + 带人经验 |
| 第 4 年 | 主任级 + N2 | 12h/月 | N2 合格 + 晋升面谈材料组装 + 阶段 4 评估启动 |

总目标：运行管理者试验合格 + 公司内管理辅助岗位在任 + JLPT N2 合格 + 特定技能 2 号身份稳定 + 手持 3 年可量化管理辅助成果档案（建议）。

**每周节奏模板（手册 04，建议）**：周一–五 日语 30min（N2 线）+ 日報 / 邮件练习 15min（45min/天）；周三晚业务知识 1h；周六资格学习 2h；周日 N2 主线 + 当周复盘 2h。原则：**工作日总投入 ≤ 1h/天**——司机疲劳期硬撑学习反而两头塌，宁可以「最低维持量」（30min）保住连续性。

**失败预案（手册 04，建议）**：

| 情形 | 预案 |
|---|---|
| 运行管理者试验不合格 | 半年后再考（可无限重考）；期间继续辅助岗积累 |
| 公司不提供轮岗 | 第 3 年转职评估（路径 B） |
| N2 两次未过 | 接受 N3 状态进入主任竞聘（N2 非法定门槛），N2 改为长期目标 |
| 2 号移行要件不满足 | 用 1 号剩余年数续驾驶 + 提前考 2 号试验；必要时咨询行政书士 |

**成果档案（手册 05，建议）**：管理活动月度记录表（发言 / 議事録 / 带人、改善提案、采用结果；原始运营数字引用司机手册同月记录，避免两处各写一套）；STAR 成果卡（年度目标至少 4 张，示例数字「误出库率 0.3%→0.05%」为**示例、非事实**）；晋升面谈材料包（第 4 年 Q2 组装）；外部评价背书（表彰状 / 感谢状扫描、客户好评书面确认、研修修了证）。

**风险提示（事实＋推断）**：资格≠岗位；管理岗仍属特定技能框架内时业务范围受限——从「驾驶」扩展到「辅助管理」需确认雇主在受入计划书中的业务记载；若走 2 号，2 号业务本质仍是驾驶，真正的管理岗跳转可能需在留资格变更（如技术·人文·国际业务，需学历或 10 年实务），提前与行政书士咨询（→ [../08-visa-immigration/reports/2026-11-visa-immigration.md](../../08-visa-immigration/reports/2026-11-visa-immigration.md)）。
