## 一、核心结论（摘要）

**主题定义**：运输 / 仓储公司内管理岗（运行管理者 / 运行管理辅助者 / 配车 / 仓库现场リーダー / 安全管理者 / 保管・仓库管理 / 事务所营业）的岗位地图与路径评估、业务知识体系、管理岗日语与沟通、48 个月分年学习计划、成果档案与晋升材料。（未标注 / 待补来源，详见第九节）

**监测范围（含）**：管理岗地图与路径评估；业务知识体系（仓储运营、运输管理 KPI、安全管理、系统与数据基础）；管理岗日语与沟通（会议 / 报告 / 邮件 / 现场指示、敬语最小集）；管理岗过渡学习计划（48 个月分年计划、周节奏、失败预案）；成果档案与晋升材料（KPI 月度表、STAR 成果卡、晋升面谈材料包）。（未标注 / 待补来源，详见第九节）

**监测范围（不含）**：制度规则与在留资格细节（→ 08-visa-immigration）；行业结构与 2024 年問題（→ 04-industry-logistics）；自动驾驶技术路线（→ 05-industry-autonomous）；技术数字化技能（→ 06-industry-technology）；法规条文解读（→ 09-politics-law）；收入环境与地域差（→ 07-economy-finance）；日语学习计划与考试选择（→ 11-language-japanese）；资格与教育投资（→ 10-education-qualification）；现场层执行细节（→ 02-career-driver）；官方统计活值（→ 01-ssw-driver 主责，本主题只读引用）。（来源：ISA（出入国在留管理庁），详见第九节）

**核心监测问题**：

1. 目标企业的管理岗采用条件与职级结构如何？
2. 运行管理者试验与讲习的日程、费用与合格路径是什么？
3. 管理岗求人薪资口径（含 / 不含手当）处于什么水平？
4. 从司机到管理岗的过渡路径与决策时点如何安排？
5. 个人晋升档案（KPI / STAR 卡）如何支撑晋升与资格切换（1 号→技人国 / 永住）？（未标注 / 待补来源，详见第九节）

**初步结论**：

1. **管理岗过渡的主线是内部升格（路径 A）**（建议 / 推断）：公司已认识你、资格与实绩连续、雇主支持长期留任与资格切换（**自动车运送业无特定技能 2 号**，见 08）；路径 B 转职过渡存在资格切换中断风险，须在转职前确认新公司做受入计划书变更。
2. **本主题尚处知识整理期**（事实）：登记册 4 项指标中 #1 #2 #3 为「待基线确立」、#4 为「待记录」；但**运行管理者试验的构造（CBT、30 问、合格基准、受验资格、试验地）已于本版从官方页面核实**，可作路径评估的硬锚。
3. **资格≠岗位，在留资格联动是主要制度约束**（事实＋推断）：运行管理者试验合格只给入场券，公司是否选任取决于信任与空缺；管理岗跳转可能需在留资格变更（如技术·人文·国际业务，需学历或 10 年实务）。
4. **48 个月计划与周节奏以「最低维持量」保连续性**（建议）：工作日总投入 ≤1h/天，避免司机疲劳期两头塌。
5. **成果档案是晋升与资格切换 / 永住审查的共用材料**（建议 / 推断）：KPI 月度表、STAR 卡与晋升面谈材料包同时服务内部晋升、转职简历与在留审查。

## 二、行业与政策发展趋势

本节只写管理岗监测面可核验的制度与环境信号；行业结构、自动化产业面、法规条文分别归 04-industry-logistics、05-industry-autonomous、09-politics-law，本主题不重复展开。（未标注 / 待补来源，详见第九节）

**法定需求侧信号（事实）**：运行管理者按「営業所ごとに車両数に応じた人数」设置，公司必置，是最现实的第一个管理台阶；运行管理辅助者无法定资格，基础讲习修了即可（运行管理者试验中心，2026，A 级；[运行管理者试验中心](https://www.unkan.or.jp/about.html)）。

**资格制度三阶段（事实）**：运行管理实务 1 年以上**或**基础讲习修了 → 通过运行管理者试验（CBT・30 问・60% 基准）→ 公司选任；**讲习修了 ≠ 试验合格 ≠ 选任**，三者不可互称（business-config 第四节）。安全管理者需实务经验年数 + 選任時研修（中型以上车辆企业另设安全管理相关职务）。（未标注 / 待补来源，详见第九节）

**2026-11 资格制度澄清（新增，事实）**：运行管理者試験为 CBT，货物 / 旅客各 30 题，分野配点为货物自動車運送事業法 8、道路運送車両法 4、道路交通法 5、労働基准法 6、実務知識 7；合格需同时满足总得点 60% 以上与分野別最低正解数。[Source: https://www.unkan.or.jp/outline/cbt_new.html, 2026]

**2024 年問題的政策传导（触发器观察方向）**：运賃适正化、M&A 等对策可能改变管理岗职责与配车 / 运行管理的工作方式，属 business-config 第七节的触发器（命中 → 01 / 02 章）；截至 2026-11-17 无触发器命中、无可报变化，不虚构变化。（来源：国土交通省，详见第九节）

**业务知识体系（手册 02）**：

- 仓储运营：入出库流程（受入→検収→入庫→保管→ピッキング→検品→出庫→配送）、FIFO 与在庫回転率、误出库率与件 / 人 / 时、3PL 受託契約与 KPI 契约（SLA）。
- 运输管理：运行管理法制（点呼、运行指示書、运行记录、驾驶时间规制→ 02-career-driver）、配车逻辑、成本结构（固定费 vs 变动费、原価率）、异常运营。
- 安全管理（管理者视角）：ヒヤリハット收集与再现性分析、PDCA 对策立案、月次安全委员会、安全统括管理者 / 安全管理者职责分工。
- 系统与数据基础：Excel VLOOKUP / 透视表、WMS / TMS 概念认知、手工台账起步的数据整理习惯。（未标注 / 待补来源，详见第九节）

**核心 KPI 口径（各自独立，不得混用）**：纳期遵守率（准点率）≠ 装载率 ≠ 空驶率 ≠ 每车日件数；管理活动月度记录为过程口径，活动数量 ≠ 业务结果（business-config 第四节、第十节）。

**管理岗日语与沟通（手册 03，前提 N3 达成）**：

- 四大场景武器库：会议（发言开场 / 报告 / 提案 / 質問）、报告（日報・月報固定模板）、邮件（件名 / 定型句 / 期限 / 结尾）、现场指示（对象 / 内容 / 期限 / 确认 + 复述文化 + 指差呼称）。
- 敬语最小必需集：对上 = 尊敬语、对己 = 谦让语；现场用错的成本低于不敢用的成本——先敢说再修正。
- 训练节奏：每天日報 3 行；每周会议发言 1 次 + 議事録 1 份；每月月報 1 份 + 邮件改写 2 封；每半年对照四大场景自评并记入成果档案。（未标注 / 待补来源，详见第九节）

## 六、行业认可的职业资质与证书

**法定资格路径（事实）**：运行管理者试验受验资格 = 运行管理实务 1 年以上**或**基础讲习修了；试验为 CBT・30 问・60% 基准（2026-11 澄清）；试验合格只给入场券，公司是否选任取决于信任与空缺（手册 01，来源：运行管理者试验中心，2026，A 级）。[Source: https://www.unkan.or.jp/about.html, 2026]

**术语口径（不得混用）**：

| 口径 | 说明 |
|---|---|
| 运行管理者（選任）≠ 运行管理辅助者 | 前者有法定资格，后者讲习修了即可 |
| 讲习修了 ≠ 试验合格 ≠ 选任 | 三阶段，不可互称 |
| 管理岗（管理職）≠ 现场リーダー（班長） | 职责与法定资格不同 |
| 「技能講習」≠「特別教育」 | 资格制度术语分别标注 |

**费用与日程**：基础讲习「数千円，周末 1 日课程为主」（手册 04，**待核验**）；运行管理者试验费用与具体日程以试验中心官方公布为准——官方申请页金额为变量占位符（未显示），**需核实原文**。资格日程与费用的主责为 10-education-qualification（[10-education-qualification](../../10-education-qualification/reports/2026-11-education-qualification.md)），本主题只读引用、不独立改值；登记册 #2「管理者讲习 / 安全管理责者讲习日程」待基线确立。

**证书归档**：每张证书扫描归档，进入成果档案（手册 05），作为晋升面谈与资格切换 / 永住审查材料的组成部分。

## 七、就业落地路径建议（结论章）

| 年 | 主题 | 月投入（业余） | 年内里程碑 |
|---|---|---|---|
| 第 1 年 | 站稳 + 摸清组织 | 8h/月 | 基础讲习修了证 + 运行管理业务观察笔记 1 份（未标注 / 待补来源，详见第九节） |

**每周节奏模板（手册 04，建议）**：周一–五 日语 30min（N2 线）+ 日報 / 邮件练习 15min（45min/天）；周三晚业务知识 1h；周六资格学习 2h；周日 N2 主线 + 当周复盘 2h。原则：**工作日总投入 ≤ 1h/天**——司机疲劳期硬撑学习反而两头塌，宁可以「最低维持量」（30min）保住连续性。

**失败预案（手册 04，建议）**：

| 情形 | 预案 |
|---|---|
| 运行管理者试验不合格 | 半年后再考（可无限重考）；期间继续辅助岗积累 |
| 公司不提供轮岗 | 第 3 年转职评估（路径 B）（未标注 / 待补来源，详见第九节） |
| N2 两次未过 | 接受 N3 状态进入主任竞聘（N2 非法定门槛），N2 改为长期目标（未标注 / 待补来源，详见第九节） |

**成果档案（手册 05，建议）**：管理活动月度记录表（发言 / 議事録 / 带人、改善提案、采用结果；原始运营数字引用司机手册同月记录，避免两处各写一套）；STAR 成果卡（年度目标至少 4 张，示例数字「误出库率 0.3%→0.05%」为**示例、非事实**）；晋升面谈材料包（第 4 年 Q2 组装）；外部评价背书（表彰状 / 感谢状扫描、客户好评书面确认、研修修了证）。

**风险提示（事实＋推断）**：资格≠岗位；管理岗仍属特定技能框架内时业务范围受限——从「驾驶」扩展到「辅助管理」需确认雇主在受入计划书中的业务记载；本分野**无 2 号**，真正的管理岗跳转可能需在留资格变更（如技术·人文·国际业务，需学历或 10 年实务），提前与行政书士咨询（→ [08-visa-immigration](../../08-visa-immigration/reports/2026-11-visa-immigration.md)）。
