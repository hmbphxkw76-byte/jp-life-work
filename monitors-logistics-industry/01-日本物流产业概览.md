# 日本物流产业概览

> 信息核对日期：2026-11-11。定位：理解自己所处的行业坐标系——公司规模、细分赛道、政策走向都影响个人路线选择。

## 一、产业规模

| 指标 | 数值 | 来源 |
|---|---|---|
| 物流业界主要业种营业收合计 | 约 **28 兆日元** | 全日本货物流通促进协会（令和 2 年度） |
| 物流业从业人数 | 约 **229 万人** | 同上 |
| 道路货物运送业（ truck 部分）营业收 | 约 21.6 兆日元（2.6 万社调查） | 东京商工リサーチ 2021 |
| 卡车运送事业者数 | 约 **62,000 社** | トラック白书 |
| 结构 | **30 辆以下的中小事業者占 85%** | 同上 |

**结构性结论**：日本物流是"少数大手 + 海量零细"的二元结构。个人职业策略上——大手学制度、中小拿机会。

## 二、细分赛道

| 赛道 | 代表企业 | 特点 |
|---|---|---|
| 综合物流（3PL/国际） | NIPPON EXPRESS（日通）、センコー、日本ロジスティクス | 全案受托，管理岗/技术岗最多 |
| 宅配便 | ヤマト運輸、佐川急便（SGHD）、日本郵便 | EC 驱动，分拣中心自动化程度最高 |
| 路线货运/干线 | 福山通运、西濃運輸、名鉄運輸 | 干线+区域，司机培养体系成熟 |
| 冷链 | 各大手冷链部门 + 专业者（ニチレイロジ等） | 医药/生鲜高要求高附加值 |
| 仓储（保管業） | グローバルゲート、ロジクエスト等仓库特化企业 | 3PL 仓库多在地方立地 |

## 三、政策大方向（个人判断依据）

1. **物流 2024 年问题**：司机时间外规制 → 运力不足 → 运费上涨、荷主负担转嫁改革（荷待ち 2h 以内、附带作业时间规则、パレット标准化）
2. **省人化省力化**：自动驾驶卡车、仓库自动化、无人配送 → [03-自动化与技术趋势](03-自动化与技术趋势.md)
3. **地域物流再生**：人口稀疏地区配送维持 → 外国人材 + 共同配送
4. **外国人材受入扩大**：特定技能（自动车运送业 24,500 人/5 年）+ 2027 育成就劳 → [../monitors-visa-immigration/06-育成就劳制度与新动向](../monitors-visa-immigration/06-育成就劳制度与新动向.md)

## 四、对个人路线的含义

| 行业趋势 | 对本规划的影响 |
|---|---|
| 司机缺口 2030 年约 14 万人（推算） | 1 号入场窗口期内岗位供给充足 |
| 中小事業者 85% | 中小企业多但支援体制参差——选雇主看 2 号移行先例 |
| 自动化先从干线/仓库开始 | 先占"人机协作监督"类岗位（→ 阶段 4） |
| 荷主转嫁改革 | 作业环境改善趋势，行业长期形象回升 |
