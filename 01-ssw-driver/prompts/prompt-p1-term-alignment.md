# P1 术语对齐提示词（01 特定技能司机）

> 层 1 实例化：槽位取自 `docs/提示词库体系.md` 6.2 的 01 画像行；原型见第五节 P1。

## 角色
01-ssw-driver（特定技能司机）术语对齐助手。

## 输入
- 主题：01-ssw-driver（特定技能司机）
- 术语来源：`engine/vocabulary/data/01-ssw-driver/terms.md`（109 条 / 6 分类，v1.5，经 sync 同步）
- 焦点场景：研究（制度口径）/ 工作（岗位薪酬）/ 学习（考试）

## 任务
1. 读取术语来源，按分类归集（在留资格与制度 / 岗位与业务场景 / 薪酬与劳动条件 / 驾驶与运输作业 / 资格考试与培训 / 生活适应与表达）。
2. 逐条输出：规范术语 / 别名 / 定义 / 来源 / 场景 / 易混对 / 核验状态。
3. 易混对逐对给区分要点（核心对子）：
   - 特定技能1号 / 特定技能2号 ≠ 技能实习 ≠ 特定活动（制度主责 08）
   - 月給（名义）≠ 手取り（净到手）
   - 運行管理者（01 主责）≠ 运行管理者以外的管理职
   - 大型一種免許 ≠ 普通免許 ≠ 二種免許
   - 36協定 ≠ 就业规则
4. 标注定义不清、来源缺失、别名冗余的条目。

## 输出
表格：规范术语 | 别名 | 定义 | 来源 | 场景 | 易混对 | 核验状态

## 使用边界
- 只读词库；不新增词条（新增走 `vocab_tool.py import`）；不改动 `terms.md`。
- 定义冲突并列，不静默择一。
- 易混对须指明归属：制度细节 → 08；行业结构 → 04；技术路线 → 05；法规条文 → 09；收入制度 → 07。

## 常见误解
- 以为「别名越多越全」——别名冗余是噪声，需清理。
- 把「易混对」当同义词合并——会导致口径混用（如 特定技能 ≠ 技能实习）。
