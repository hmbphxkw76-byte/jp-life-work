# 日本 · 特定技能司机 · 周期更新提示词（职业就业调研型）

> **用途**：覆盖职业就业调研型**三档节拍**——月度核验轻运行 / 季度主更新 / 年度复盘，以及重大事件触发器命中时的模块升级。可直接复制，替换顶部变量后提交给 AI 执行。
> **产出**：季度 / 年度报告落盘 `{{OUTPUT_PATH}}`（`reports/{{YYYY-Qn}}_quarterly.md` 或 `reports/{{YYYY}}_annual.md` + 同名 HTML）；月度轻运行只更新登记册，不重写报告；事件触发插刷件 `reports/{{YYYY-MM-DD}}-主题.md`（命名不在标准正则内，validate 仅 WARN 不阻断，属预期）。
>
> **继承声明（四层体系）**：本文件 = [通用基座](../../src/report_templates/prompt-generic-base.md) × [监测报告通用规范](../../src/report_templates/monitoring-common-spec.md) × [周期更新类型模板（职业就业调研型）](../../src/report_templates/employment-research/prompt-update-template.md) × [业务专属配置](./business-config.md)。冲突时以本文件为准。

## 运行变量（每次运行前填写）

```
{{CURRENT_DATE}}         = 本次执行日期，格式 YYYY-MM-DD
{{CADENCE}}              = 月 / 季 / 年（按本次节拍填写）
{{PREVIOUS_REPORT_PATH}} = 上一期同周期报告路径（首期季度为空，仅锚定基线）
{{BASELINE_REPORT_PATH}} = reports/2026-11_baseline_report.md
{{REGISTRY_PATH}}        = data/ssw_driver_indicator_registry.md
{{OUTPUT_PATH}}          = reports/{{YYYY-Qn}}_quarterly.md 或 reports/{{YYYY}}_annual.md
{{REPORT_VERSION}}       = 本次版本号，格式 vYYYY.MM.DD
```

固定值（不填，读自业务配置第一节）：`{{REGION}}`、`{{TOPIC}}`、`{{FRESHNESS_PRIORITY}}`、`{{SOURCE_LANGUAGE_RULE}}`、`{{REPO_RAW_URL_BASE}}`。

**任务目标**：完成「核验 → 更新 → 建议 → 可靠性」闭环；按节拍实例化（见第一节）；继承已修正事实清单；无触发且窗口未到时不启动，不得虚构变化。

## 一、节拍与触发

三档节拍设计见[周期更新类型模板第一节](../../src/report_templates/employment-research/prompt-update-template.md)：

| 节拍 | 定位 | 触发条件 | 输出 |
|---|---|---|---|
| 月度 | 核验型轻运行：只核验登记册活值与触发器状态，不重写报告 | 常规月度窗口；**无触发不启动新报告**，仅在登记册标注「截至本次日期无更新」 | 登记册更新记录；命中触发器时升级为季度重点更新 |
| 季度 | 主更新节拍：全模块刷新 | 每季度窗口，或任一重大事件触发器命中 | 完整九节更新版报告（结构逐字继承基线） |
| 年度 | 复盘：预测对照 + 清单复审 + 路线图重排 | 每年固定窗口 | 年度版报告 + 登记册年度复盘留痕 |

业务触发器清单（`事件 → 受影响模块`）见[业务配置第七节](./business-config.md）：

```
- 出入国在留管理庁特定技能制度改定（分野扩缩、要件变更、在留期间上限调整）→ 模块一、五
- 「自動車運送業」分野技能試験 / 日本語試験新年度实施日程或大纲变更 → 模块一、五
- 国土交通省物流政策更新（「2024年問題」对策、运送事业者 M&A 支援、运賃适正化）→ 模块二、三
- 運輸業賃金統計 / 每月勤労統計新年版发布 → 模块二、三
- 自动驾驶制度进展（L4 级许可在留区域扩大、新実証项目、法改正）→ 模块三、四
- 在留外国人统计月报中特定技能在留者数据更新 → 模块二
- ISA 受入见込数・在留者数表换版 → 模块一、二
- 登录支援机关支援体制要件改正（2027-04-01 施行）倒计时 → 模块一、五
```

## 二、项目专属硬性约束

1. **受众与结论边界**：面向拟通过特定技能（SSW）签证赴日从事货运司机工作的读者；建议章标「建议 / 推断」，不承诺就业结果；不给投资评级、不给 Go/No-Go 建议。
2. **来源语言规则**：优先日文官方一手与英文权威；中文来源仅作线索，引用须回溯日 / 英原文（中国侧指定例外见[业务配置第五节](./business-config.md)）。
3. **口径纪律**：多口径并列不合并；特定技能 / 技能实习 / 特定活动不得混用；卡车 / 出租车 / 巴士运転者区分不得混用；受入上限采用 22,100 现行值；SPPI 与 WebKit、TDB 与 TSR 不得混算。
4. **边界纪律**：制度细节链接 08、薪资结构链接 02、行业结构链接 04、技术制度面链接 05、法规条文链接 09、收入环境链接 07；本主题只写指标 + 结论 + 链接。
5. **交叉验证锚**：本主题是制度类数字、运输业工资 / 求人 / 缺口、L4 进展、维权渠道结论、驾照费用、考试日程 / 费用 / 考位的主责方；02 / 05 / 07 / 08 / 09 / 10 / 11 只读引用本主题登记册与报告，不得独立回写。

## 三、各模块更新要点

按[业务配置第 3.2 节](./business-config.md)的结构映射逐模块实例化：

- **制度与签证（对应行业与政策发展趋势 / 就业落地路径）**：特定技能制度最新框架（在留期间、分野清单、「自動車運送業」分野要件：技能試験＋日本語試験科目、更新条件）；技能試験与日本語試験最新实施日程、海外考场开设状况；登录支援机关制度与费用行情；申请流程、在留资格认定周期与费用。
- **司机供需与薪酬（对应人才供需与薪酬，最高优先级）**：MLIT 物流関連統計与司机缺口推算；厚労省賃金統計中運輸業 / 郵便業月均工资；トラック運賃・旅客運賃指数；求人平台抽样（标注「月収」「賞与」「手当」口径）；保持净收入参考模型与「岗位 × 地域」分层表。
- **物流行业态势（对应行业与政策发展趋势 / 雇主与企业类型细分）**：「2024 年問題」最新影响数据（运力缺口、运賃上涨率、路线休止 / 倒産件数）；行业 M&A 与再编动向；主要物流企业司机待遇与雇佣外国人动向。
- **智能驾驶（对应行业与政策发展趋势，未来展望标「推断」）**：L4 级自动驾驶政策路线图最新进展（许可区域、実证项目、适用车型）；自动驾驶对司机岗位的替代 / 转型时间线评估（区分「幹線运送」与「市内配送」替代节奏）。
- **就业落地（对应就业落地路径建议，结论章）**：試験准备路径（技能試験参考书 / 题库、JFT-Basic vs JLPT 选择）；招募渠道核实；在留落地清单（在留卡、银行、手机、驾照换领 / 取得路径与费用）；风险提示与维权渠道（以厚労省体系为准）。

## 四、基线锚定与防回退

- 读取 `{{PREVIOUS_REPORT_PATH}}`（首期季度为空）与 `{{BASELINE_REPORT_PATH}}`，继承结构与全部已核实结论。
- 逐条继承「已修正事实清单」，产生修正后追加（格式见[通用基座第五节](../../src/report_templates/prompt-generic-base.md)）；严禁重新引入已被推翻的说法；无来源不得入清单。
- 已修正事实清单以最新版报告文首为单一事实源；登记册不重复维护。

## 五、追踪表与登记册联动

按[业务配置第八节](./business-config.md)的 14 项追踪指标逐项核对并填写「是否更新」；运行前从 `{{REGISTRY_PATH}}` 读取活值与研究边界档案 → 复核有效性 → 运行后回写。数据变更摘要至少覆盖全部 14 项；未核实项单列「待复核清单」。prompt 模板内不填活值。

## 六、执行方式（建议）

1. 按调研维度并行启动研究子代理（制度签证 / 薪酬供需 / 行业态势 / 智能驾驶 / 落地路径），全部限定日 / 英来源、逐点引用，每条数据附可直接访问的 URL。
2. 主代理读取 `{{PREVIOUS_REPORT_PATH}}` 与基线做差异合并，继承已修正事实清单，应用第三节更新要点。
3. 冲突数据保留双份引用；无法核实项单列「待复核清单」。
4. 回写报告与登记册后运行 `python src/prompts-tools/tools/md2html.py` 重新生成 HTML，并运行 `python src/prompts-tools/tools/lint_reports.py` 校验。

## 七、渲染与交付

- 交付格式：md + 同目录自包含 HTML；季度 / 年度报告含顶部九锚点导航（`.report-nav`），`.nav-url` = `{{REPO_RAW_URL_BASE}}` + `/reports/{本期文件名}`。
- HTML 须通过 `lint_reports.py` 免责声明双条件与标签配对校验。
- 基线报告常驻 `reports/` 顶层不归档；周期报告按保留策略执行（季度保留 8 期、年度保留 5 期，超出移入 `reports/archives/`）。

## 八、质量自检（通用清单之外的本主题专属项）

- [ ] 结构逐字继承基线（或经批准的九节骨架），无增删节、无顺序调整
- [ ] 已修正事实清单已继承并续写，无回退
- [ ] 特定技能 / 技能实习 / 特定活动 制度口径未混用；「自動車運送業」分野与其他运输岗位数据已区分
- [ ] 卡车 / 出租车 / 巴士运転者区分的日语要件未混用；受入上限采用 22,100 现行值
- [ ] 薪资表保留「岗位 × 地域」分层 + 手当口径标注；智能驾驶影响评估全部显式标注「推断」
- [ ] 全篇无直接转引的中文来源数据，中文线索均已回溯日 / 英原文
- [ ] 与 04-industry-logistics 最新报告 / 登记册交叉验证一致，未越界回写
- [ ] 追踪表 14 项均已核对并填写「是否更新」
- [ ] `{{REGISTRY_PATH}}` 已读已写，变更摘要与登记册一致
- [ ] 数据变更摘要与待复核清单已产出
- [ ] HTML 通过 lint（免责声明双条件 + 标签配对）
