## 一、项目专属硬性约束

1. **受众与结论边界**：面向拟通过特定技能（SSW）签证赴日从事货运司机工作的读者；允许框架性求职路径建议，不承诺就业结果、不保证薪资水平；不给投资评级、不给 Go/No-Go 建议（见[业务配置第二节](./business-config.md)）。
2. **来源语言规则**：优先日文官方一手与英文权威；中文来源仅作线索，引用须回溯日 / 英原文（中国侧指定例外见[业务配置第五节](./business-config.md)）。
3. **术语口径**：特定技能（SSW）/ 技能实习 / 特定活动不得混用；普通货运司机与「自動車運送業」分野司机不得混用；卡车 / 出租车 / 巴士运転者区分不得混用；受入上限现行值为 22,100（旧 24,500 已废止）。
4. **边界纪律**：制度细节链接 08、薪资结构链接 02、行业结构链接 04、技术制度面链接 05；本报告只写指标 + 结论 + 链接，不复制知识手册段落。
5. **内容边界**：自动驾驶只保留指标 #10 与一句结论，产业面归 04、技术与制度面归 05。

## 二、来源优先级

见[业务配置第五节](./business-config.md)：① 日本政府官方一手 ＞ ② 国际权威组织 ＞ ③ 行业专业机构 ＞ ④ 平台 / 门户抽样 ＞ ⑤ 日英主流媒体（须回原文）。每条数据附完整 URL，每格活值附 `[来源, 年份]`。

## 三、基线锚定与重启条件

- 基线报告一经产出即为对比锚：结构、口径裁决与已核实结论由后续周期更新完整继承。
- **正常运行不重跑**。重启仅限两种情形：①灾难恢复（报告与登记册全部丢失）；②九节结构经维护规范批准重排。重排须在[业务配置](./business-config.md)第十二节版本记录留痕，并同步评估周期更新提示词。
- 现状：首期基线保留现行结构（业务固化锚），结构映射见[业务配置第 3.2 节](./business-config.md)。

## 五、追踪表与边界档案

按[业务配置第八节](./business-config.md)的 14 项追踪指标逐项核对并填写「是否更新」；运行后回写 `{{REGISTRY_PATH}}` 的核心指标与[研究边界档案](./business-config.md)（研究对象边界、制度分野分层、主体清单与入选标准、口径清单）。未核实项注明「待核实」，不补值、不外推；prompt 模板内不填活值。

## 六、执行方式（建议）

1. 并行启动 4–5 个研究子代理：① 制度签证 + 试验路径；② 司机供需 + 薪资交叉验证 + 净收入模型；③ 物流行业态势 + 企业动态；④ 智能驾驶政策与岗位影响；⑤ 落地手续 + 风险与维权渠道。全部限定日 / 英来源、逐点引用，每条数据附可直接访问的 URL。
2. 主代理合并差异，冲突口径保留双份引用，无法核实项单列「待复核清单」。
3. 与 04-industry-logistics 最新报告 / 登记册交叉验证一致（只读锚，不回写）。
