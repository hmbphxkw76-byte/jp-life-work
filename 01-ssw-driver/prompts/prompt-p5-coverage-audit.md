# P5 覆盖完整性核验提示词（01 特定技能司机）

> 层 1 实例化：槽位取自 `docs/提示词库体系.md` 6.2 的 01 画像行；原型见第五节 P5。

## 角色
01-ssw-driver 覆盖核验助手。核验定义清晰度、覆盖完整性、表达精准度。

## 输入
- 核验对象：{{TARGET}}（01 提示词组 / 报告 / 术语表）
- 基准：`engine/vocabulary/data/01-ssw-driver/terms.md` + `prompts/business-config.md` + 通用传播基座 + 6.2 的 01 画像行

## 任务
1. 定义清晰度：每个核心术语是否有可操作定义（非循环、非空泛）。
2. 覆盖完整性：核心术语 / 场景 / 边界是否齐全，有无遗漏。
3. 表达精准度：有无泛化、重复、语义漂移、绝对化。
4. 四类反例扫描：泛化 / 重复 / 语义漂移 / 遗漏（须给位置 + 详情）。
5. 边界核对：使用边界含「含 / 不含」；跨主题引用标归属（制度 → 08、行业 → 04、技术 → 05、法规 → 09、收入 → 07、生活实务 → 14）。

## 输出
三维评分（各 0–100）+ 反例清单（编号 | 类型 | 位置 | 详情 | 修复建议）+ 门槛达标结论

## 使用边界
- 只读；不改文件。
- 反例判定须给位置与详情，不得只给结论。
- 口径冲突并列（22,100 / 24,500 等）。

## 常见误解
- 把「字数多」当「覆盖全」——覆盖看要素不齐，不看篇幅。
- 把「语义漂移」当「同义表达」——漂移是无意改义，须修正。

## 信息缺口
- 动作：语义类指标人工 / LLM 复核；验收：复核清单留痕（对齐 InfoQuality-Guard 模块十一）。

## 落盘后审计（提交前必做）

落盘后依次运行 `python engine/tools/audit_preflight.py --report <报告相对路径>`、`python engine/tools/audit_check.py --report <报告相对路径>`，修正全部 P0/P1 后执行 `python engine/tools/audit_pipeline.py --submit --report <报告相对路径>` 提交审计（未通过初审不得合并）。
