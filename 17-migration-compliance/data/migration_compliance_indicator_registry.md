## 研究边界档案（基线首建，周期运行复核）

### 研究对象边界

- **含**：拟赴日 / 已在日外国人的中介渠道甄别、资质核验、合同与费用审查、骗术识别、黑名单与官方公示、无资质法律后果与救济。
- **不含**：在留资格制度正文（→ 08）；行业监测 / 薪资 / 驾照（→ 01）；渠道矩阵与雇主生态正文（→ 02）；法规条文深度解读（→ 09）；赴日落地（→ 14）；退出 / 转型 / 回国（→ 16）。

### 三段分层

- **招募·渠道**：渠道矩阵、官方核验入口、费用口径与趋势（推断）。
- **资质·核验**：商务部名单、ISA 認定送出機関、OTIT 送出機関、登録支援機関、2026 年备案制。
- **合同·风险·后果**：合同逐条审查、骗术图谱、黑名单与官方公示、中日法律后果并列、救济窗口。

### 主体清单与入选标准

- **中国官方**：商务部 / 国家移民管理局 / 中国政府网 / 全国人大 / 地方商务主管部门。
- **日本官方**：出入国在留管理庁 / 法務省 / e-Gov / 厚生労働省 / 外国人技能実習機構 / ハローワーク / 地方自治体。
- **行业机构**：OTIT / JITCO / 行业团体。
- **入选标准**：官方发布页可回溯；每条附官方原文 URL 与版本日期。
