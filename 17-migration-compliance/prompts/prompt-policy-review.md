# 日本 劳务输出与中介合规 事件触发解读 / 年度台账复盘提示词（职业就业调研型）

> **用途**：事件触发单份解读（新政策 / 修订 / 配套细则出台后）、季度主更新与年度台账复盘统一入口。可直接复制，替换顶部变量后提交给 AI 执行。
> **产出**：单份解读件 `{{OUTPUT_PATH}}`（`reports/{{YYYY-MM}}-<slug>.md` + 同名 HTML）、季度更新版或年度台账复盘（`reports/{{YYYY-MM}}-<slug>.md` + 同名 HTML）。解读件命名不在标准正则内，validate 仅 WARN 不阻断，属预期。
>
> **继承声明（四层体系）**：本文件 = [通用基座](../../engine/report_templates/prompt-generic-base.md) × [监测报告通用规范](../../engine/report_templates/monitoring-common-spec.md) × [周期更新类型模板（职业就业调研型）](../../engine/report_templates/employment-research/prompt-update-template.md) × [业务专属配置](./business-config.md)。冲突时以本文件为准。

## 运行变量（每次运行前填写）

```
{{CURRENT_DATE}}         = 本次执行日期，格式 YYYY-MM-DD
{{TRIGGER_TYPE}}         = 本次触发类型（新政策 / 修订 / 细则 / 季度更新 / 年度台账复盘 / 个人情况变化）
{{PREVIOUS_REPORT_PATH}} = 上期解读 / 复盘路径（如无则空，仅锚定基线）
{{BASELINE_REPORT_PATH}} = reports/2026-11-migration-compliance.md
{{REGISTRY_PATH}}        = data/migration_compliance_indicator_registry.md
{{OUTPUT_PATH}}          = reports/{{YYYY-MM}}-<slug>.md
{{REPORT_VERSION}}       = 本次版本号，格式 vYYYY.MM.DD
```

固定值（不填，读自业务配置第一节）：`{{REGION}}`、`{{TOPIC}}`、`{{FRESHNESS_PRIORITY}}`、`{{SOURCE_LANGUAGE_RULE}}`、`{{REPO_RAW_URL_BASE}}`。

**任务目标**：完成「原文回溯 → 逐条解读 → 影响评估 → 台账更新」闭环；新政策先登记发布与生效日期、官方 URL 后才可进入解读；征求意见稿登记但标注「非最终文本，以正式发布为准」；无触发时不启动新解读，台账标注「截至 {{CURRENT_DATE}} 无更新」。

## 一、节拍与触发

节拍设计（三档）与更新协议见[周期更新类型模板（职业就业调研型）第一、二节](../../engine/report_templates/employment-research/prompt-update-template.md)。业务触发器清单（`事件 → 受影响模块`）见[业务配置第七节](./business-config.md）：

```
- 对外劳务合作管理条例修订 / 企业名单更新 → 渠道模块
- 841 号令 / 出境入境中介服务备案办法更新 → 中介合规模块
- 商务部对外劳务合作企业名单 / 年审公示更新 → 核验模块
- ISA 認定送出機関名单（各国別情報）更新 → 核验模块
- 技能実習法行政処分公表 / 失踪者数更新 → 黑名单模块
- 育成就労制度施行（2027-04-01）与運用要領改定 → 核验 / 后果模块
- 入管法改正（不法就労助長等罚则加重）施行 → 后果模块
- 特定技能運用要領 / 分野別要領別冊改定 → 渠道模块
- 官方咨询窗口与救济渠道变更 → 救济模块
- 个人情况变化 → 个人情况变化件
- 01-ssw-driver / 02-career-driver / 08-visa-immigration 最新报告「已修正事实清单」追加 → 对应文档回写
```

## 二、项目专属硬性约束

1. **官方原文铁律**：媒体 / 自媒体转述仅作线索；引用逐条附官方原文 URL 与版本日期。无官方依据的金额 / 期限 / 要件写「⚠ 待核实」。
2. **结论边界**：不构成法律意见或税务意见；应对建议标「建议」；歧义条款多解并列。
3. **术语口径**：送出機関 ≠ 認定送出機関；对外劳务合作 ≠ 劳务派遣；保証金 ≠ 違約金 ≠ 解約金；黑名单 ≠ 官方公示；技能実習 ≠ 特定技能 ≠ 育成就労；备案 ≠ 许可；受入計画 ≠ 支援計画。
4. **边界纪律**：在留资格制度正文归 08；行业监测 / 薪资 / 驾照归 01；渠道矩阵与雇主生态正文归 02；法规条文深度解读归 09；赴日落地归 14；退出 / 转型 / 回国归 16。
5. **交叉验证锚**：01-ssw-driver / 02-career-driver / 08-visa-immigration 最新报告与登记册只读核对；冲突回官方原文复核，由来源主题主责更新，本主题不得独立回写。

## 三、各模块要点

按[业务配置第 3.3 节](./business-config.md)的结构映射逐模块实例化：

- **招募·渠道**：渠道矩阵（只读吸收 02）、官方核验入口、费用口径与趋势（标「推断」）；
- **资质·核验**：商务部名单、ISA 認定送出機関、OTIT 送出機関、登録支援機関、2026 年备案制；
- **合同·风险·后果**：合同逐条审查、骗术图谱、黑名单与官方公示、中日法律后果并列、救济窗口。

> 若本期按九节骨架重排：九节标题逐字继承基线（或经批准的骨架），不得增删节或调整顺序；重排须在[业务配置](./business-config.md)版本记录留痕。

## 四、基线锚定与防回退

- 读取 `{{PREVIOUS_REPORT_PATH}}`（如无则空）与 `{{BASELINE_REPORT_PATH}}`，继承中日监管框架地图、核验路径与全部已核实结论。
- 逐条继承「已修正事实清单」（以来源主题最新报告文首为单一事实源），产生修正后追加（格式见[通用基座第五节](../../engine/report_templates/prompt-generic-base.md)）；严禁重新引入已被推翻的说法；无来源不得入清单。
- 上年趋势判断逐条复判，原文保留；不得删除或改写上年判断。

## 五、追踪表与登记册联动

按[业务配置第八节](./business-config.md)的 10+1 项追踪指标逐项核对并填写「是否更新」；运行前从 `{{REGISTRY_PATH}}` 读台账 → 增量登记 / 状态变更 → 运行后回写。政策变更摘要覆盖本期新增 / 修订 / 生效 / 废止清单及影响方向；未核实项单列「待复核清单」。prompt 模板内不填活值。

## 六、执行方式（建议）

1. 原文回溯先行：完成官方原文登记（URL、版本日期、文本完整性）后才启动逐条解读子代理。
2. 主代理读取 `{{BASELINE_REPORT_PATH}}` 做框架对齐，继承已修正事实清单，应用第三节要点。
3. 与现行制度冲突的解读须并列新旧对照（如技能実習 → 育成就労、620 号令 → 修订草案）；无法核实项单列「待复核清单」。
4. 回写报告与登记册后运行 `python engine/tools/md2html.py` 重新生成 HTML，并运行 `python engine/tools/lint_reports.py` 校验。

## 七、渲染与交付

- 交付格式：md + 同目录自包含 HTML；年度台账复盘报告含顶部九锚点导航（`.report-nav`），`.nav-url` = `{{REPO_RAW_URL_BASE}}` + `/reports/{本期文件名}`。
- HTML 须通过 `lint_reports.py` 标签配对校验。
- 基线报告常驻 `reports/` 顶层不归档；解读件按保留策略执行（年度复盘保留 5 期，超出移入 `reports/archives/`）。

## 八、质量自检（通用清单之外的本主题专属项）

- [ ] 全部引用回溯中日官方原文并附 URL；零媒体 / 自媒体转述直引（明确标注为线索的除外）
- [ ] 政策台账增量 / 状态变更已回写；prompt 模板无硬编码活值
- [ ] 中日制度对照完整（并列呈现，不合并、不取均值）；歧义条款多解并列
- [ ] 送出機関 / 認定送出機関、对外劳务合作 / 劳务派遣、保証金 / 違約金 / 解約金、黑名单 / 官方公示、技能実習 / 特定技能 / 育成就労、备案 / 许可未混用
- [ ] 无官方依据的金额 / 期限 / 要件已标「⚠ 待核实」
- [ ] 与 01-ssw-driver / 02-career-driver / 08-visa-immigration 最新报告 / 登记册交叉验证一致，未越界回写
- [ ] 建议章与事实分离；不构成法律意见 / 税务意见声明保留
- [ ] 追踪表 10+1 项均已核对并填写「是否更新」
- [ ] `{{REGISTRY_PATH}}` 已读已写，变更摘要与登记册一致
- [ ] 政策变更摘要 + 待复核清单已产出
- [ ] HTML 通过 lint（标签配对）
