三、当前现状梳理

3.1 落地制度基础

  • 在留卡与住民登记均为 14 日内；健康保険与年金随住民登记办理（事实）[出入国在留管理庁 / 総務省 / 厚生労働省]。
  • 国保自付通常 3 割；被用者同理但报销范围不同（事实）[厚生労働省]。

3.2 住房与租赁

  • 初期费用含敷金 / 礼金 / 仲介手数料 / 保证会社 / 更新料，合计可达 4–8 个月房租（事实）[国土交通省]。
  • 外国人常需保证会社；部分房东不接受外国人（推断，待核实）。

3.3 公共交通与通信

  • IC 卡覆盖绝大多数铁路与巴士；定期券为通勤主流（事实）[JR 東日本 / 国土交通省]。
  • 格安SIM 月租低于大手；光回线为住宅主流（事实）[総務省]。
  • ⚠ 具体月费行情待核实。

3.4 银行与支付

  • 开户通常需在留卡 + 住所证明 + 印鉴；部分银行要求在留 6 个月以上（事实 / 各银行不同）。
  • 邮局银行与部分地方银行对外国人较友好（推断）。

3.5 水电燃气

  • 电力 2016 / 燃气 2017 全面自由化（事实）[資源エネルギー庁]。
  • ⚠ 典型月费待核实。

四、初步结论

  1. 落地手续有时限、可执行（事实）：14 日内完成住民登记与保险加入是刚性要求。
  2. 住房是最大初期资金变量（事实）：4–8 个月房租的初期费用需提前准备。
  3. 通信与能源已市场化（事实）：可比较选择，但需按回线与方案具体核对。
  4. 银行开户是刚抵达时的常见卡点（推断）：在留期限门槛可能影响开户，建议用邮局银行过渡。
  5. 执行细节仍是最大信息差（事实）：本初析为框架级，具体费用与门槛待补。

日本 · 在日生活实务与行政手续 · 首期基线报告

版本：v1.0（首期基线）　数据基准日：2026-11-14 主题类型：职业就业调研型（employment-research）· 个人执行层 受众定位：本人（拟赴日 / 已在日特定技能司机） 来源规则：① 総務省 / 厚生労働省 / 国土交通省 / 内閣府 / デジタル庁 / e-Gov / 各自治体；② 银行 / 运营商 / 电力燃气公司官网；③ 平台抽样（C 级）

一、核心结论（摘要）

  1. 落地手续有明确时限（事实）：在留卡与住民登记均为抵达 / 迁入后 14 日内；健康保険与年金随住民登记一并办理。逾期会影响后续手续。
  2. 住房是最大初期费用（事实）：租房初期费用通常含敷金 + 礼金 + 仲介手数料 + 保证会社 + 更新料，合计可达 4–8 个月房租；外国人常需保证会社或在日保证人。
  3. 公共交通与通信已高度电子化（事实）：IC 卡覆盖绝大多数铁路与巴士，并可电子支付；格安SIM 显著低于大手运营商，但回线与品质不同。
  4. 银行开户存在在留期限门槛（推断）：部分银行要求在留 6 个月以上，刚抵达时可先用支持外国人的银行或邮局账户过渡。
  5. 水电燃气已自由化（事实）：电力（2016）与燃气（2017）全面自由化，可比较切换；开通需申请与的使用开始。
  6. 最大信息差在「执行细节」（事实）：本基线为初析级，通信费用 / 银行开户 / 自治体窗口的具体现行值标记「⚠ 待核实」，待次期或定居地确定后补齐。

二、落地制度基础（在留・住民・保险・年金）

2.1 在留卡与住民登记

  • 在留卡：抵达后 14 日内在机场 / 市区町村完成登记；在留卡为身份与在留资格的唯一凭证，需随身携带（事实）[出入国在留管理庁]。
  • 住民登记（転入届）：迁入新住所后 14 日内向新自治体申报；需护照 + 在留卡（或 COE）（事实）[総務省]。
  • 転出届：迁出前向原自治体申报并领取転出証明書（事实）[総務省]。

2.2 健康保険

  • 国民健康保険：面向非公司职员等居民，自付比例通常 3 割（小学生未満 2 割、70–74 岁因收入 1–2 割）（事实）[厚生労働省]。
  • 被用者健康保険：公司职员加入，自付通常 3 割，由公司与个人分担保费（事实）[厚生労働省]。
  • 高額療養費制度：医疗费超过自付上限时由公费承担差额（事实）[厚生労働省]。

2.3 年金

  • 20 岁以上 60 岁以下住民有加入义务；国民年金（基础年金）与厚生年金（公司职员）并行（事实）[日本年金機構]。
  • 离开日本时可申请脱退一时金（需满足条件，详见 07）[日本年金機構]。

三、住房与租赁

  • 费用结构（事实）[国土交通省]：
  • 敷金（押金，退还时结算）：0–2 个月；
  • 礼金（谢礼，不退还）：0–2 个月；
  • 仲介手数料：约 1 个月（含消费税）；
  • 保证会社：首次约 0.5–1 个月（外国人常需）；
  • 更新料：契约更新时约 1 个月（通常 2 年一次）。
  • 契约类型：普通赁贷借（可更新）/ 定期赁贷借（期满返还）；更新料与解约预告期需在契约中确认。
  • 外国人常见障碍：保证人（在日保证人）或保证会社；部分房东 / 管理会社不接受外国人（推断，需平台抽样核实）。
  • 搬家：需办理転出 / 転入、地址变更（银行、手机、驾照等）、水电燃气解约与开通。
  • 垃圾：按自治体分类、时间与地点投放（事实）[環境省]。

四、公共交通

  • 电车：JR、私铁、地下铁构成城市公共交通主干；定期券为通勤 / 通学主流（事实）[国土交通省]。
  • 巴士：路线巴士作为铁路接驳；部分地域巴士与电车共用 IC 卡。
  • IC 卡：Suica、PASMO 等可乘车与电子支付，多数区间互通（事实）[JR 東日本]。
  • 乗換案内：查询换乘路线、时刻与费用的应用（事实）。
  • ⚠ 待核实：典型通勤区间的定期券月费行情（需按定居地具体区间查询）。

五、通信与网络

  • 携帯契约：大手运营商（docomo / au / softbank）自有一回线；契约通常需在留卡、银行账户与住所证明（事实）[各运营商]。
  • 格安SIM：租用大手回路的低价服务（MVNO），月租通常显著低于大手；回线与品质不同，不可直接比价（事实）[総務省]。
  • 光回線：光纤到户宽带，住宅主流方案；常与手机契约捆绑（事实）[総務省]。
  • ⚠ 待核实：大手 / 格安SIM / 光回线的具体现行月费（需按回线与方案查询）。

六、银行与支付

  • 银行口座开设：通常需在留卡 + 住民票 / 住所证明 + 印鉴；部分银行要求在留 6 个月以上（事实 / 各银行口径不同）。
  • 外国人友好渠道：邮局银行（ゆうちょ銀行）、部分地方银行与网络银行对外国人较友好（推断）。
  • 支付：信用卡、电子マネー（Suica / PayPay 等）、银行振込并行（事实）。
  • 送金：国际送金（归国 / 向国内汇款）可通过银行或专业送金服务；汇率与手续费差异大（事实）。
  • ⚠ 待核实：各银行现行在留期限门槛与所需书类。

七、水电燃气与基础设施

  • 上下水道：由自治体管理，需办理使用开始 / 停止手续（事实）[国土交通省]。
  • 電気：2016 年全面自由化，可从各电力公司选择（事实）[資源エネルギー庁]。
  • ガス：2017 年全面自由化，可从各燃气公司选择（事实）[資源エネルギー庁]。
  • 开通 / 解约：搬家时需办理旧地址解约与新地址开通，通常通过网络或电话申请。
  • ⚠ 待核实：典型家庭月费（因家族人数、地域、使用量而异）。
