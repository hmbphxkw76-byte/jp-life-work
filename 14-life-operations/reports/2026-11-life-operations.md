## 一、核心结论（摘要）

**核心判断**（每条含数据、口径与来源）：

1. **落地手续有明确时限**（事实）：在留卡于入国时交付，抵达后 14 日内向市区町村登记住所；住民登记于迁入后 14 日内提交；健康保険与年金随住民登记一并办理，逾期会影响后续手续。[出入国在留管理庁 / 総務省 / 厚生労働省]
2. **住房是最大初期费用**（事实）：租房初期费用通常含敷金 + 礼金 + 仲介手数料 + 保证会社 + 更新料，合计可达 **4–7 个月**房租（与 3.2 表内各项上限合计一致）；外国人常需保证会社或在日保证人。[国土交通省]
3. **公共交通与通信已高度电子化**（事实）：IC 卡覆盖绝大多数铁路与巴士，并可电子支付；格安 SIM 显著低于大手运营商，但回线与品质不同，不可直接比价。[総務省 / JR 東日本]
4. **银行开户存在在留期限门槛**（推断）：部分银行要求在留 **6 个月以上**，刚抵达时可先用支持外国人的银行或邮局账户过渡。[各银行官网]
5. **水电燃气已自由化**（事实）：电力（2016）与燃气（2017）全面自由化，可比较切换；开通需申请与使用开始。[資源エネルギー庁]
6. **最大信息差在「执行细节」**（事实）：本基线为初析级，通信费用 / 银行开户 / 自治体窗口 / 定期券行情的具体现行值标记「⚠ 待核实」，待次期或定居地确定后补齐。

## 二、行业与政策发展趋势

### 2.1 落地制度框架（在留・住民・保险・年金）

- **在留卡**：入国时交付（中长期在留者）；在留卡为身份与在留资格的唯一凭证，需随身携带。抵达后 14 日内须向市区町村办理住所登记（与在留卡交付为两个不同时点）。[出入国在留管理庁]
- **住民登记（転入届）**：迁入新住所后 14 日内向新自治体申报；需护照 + 在留卡（或 COE）。迁出前向原自治体申报并领取転出証明書。[総務省]
- **健康保険**：国民健康保険面向非公司职员等居民，自付比例通常 3 割（小学生未満 2 割、70–74 岁因收入 **2 割**，現役並み所得 3 割）；被用者健康保険面向公司职员，自付通常 3 割，由公司与个人分担保费；高額療養費制度对超上限部分由公费承担差额。[厚生労働省]
- **年金**：20 岁以上 60 岁以下住民有加入义务；国民年金（基础年金）与厚生年金（公司职员）并行；离开日本时可申请脱退一时金（需满足条件，详见 [07-economy-finance](../../07-economy-finance/reports/2026-11-economy-finance.md)）。[日本年金機構]

### 2.2 市场化与自由化进程

- **电力**：2016 年全面自由化，可从各电力公司选择。[資源エネルギー庁]
- **燃气**：2017 年全面自由化，可从各燃气公司选择。[資源エネルギー庁]
- **通信**：大手运营商（docomo / au / softbank）自有一回线；格安 SIM（MVNO）租用大手回路，月租通常显著低于大手，但回线与品质不同，不可直接比价；光回线为住宅主流方案，常与手机契约捆绑。[総務省]
- **交通**：JR、私铁、地下铁构成城市公共交通主干；定期券为通勤 / 通学主流；IC 卡（Suica、PASMO 等）可乘车与电子支付，多数区间互通。[国土交通省 / JR 東日本]

### 2.3 政策与趋势观察（触发器）

在留 / 住民 / 保险制度改定（要件、时限、费用）→ 模块二；租房相关法规变更（契约、敷金礼金、保证人）→ 模块三；公共交通 IC 卡 / 定期券规则变更 → 模块四；通信运营商资费 / 制度变更 → 模块五；银行开户 / 外汇 / 送金规则变更 → 模块六；水电燃气开通 / 费用变更 → 模块七；个人定居地确定 / 赴日 → 模块八（90 天清单）。无触发器命中且窗口未到时**不启动**。

| 30 日内 | 银行口座、手机 / 网络 | 1 个月 |
| 30–90 日 | 住房签约、水电燃气开通 | 1–3 个月 |
| 90 日内 | 驾照转换 / 在留资格变更 | 视驾照进度（→ 10 / 01） |

### 7.2 住房执行路径（建议）

1. 先算初期费用：敷金 + 礼金 + 仲介手数料 + 保证会社 + 更新料（区间见 3.2），按 4–7 个月房租准备现金。
2. 无保证人时优先询保证会社方案；用国交省「外国人入住円滑化ガイドライン」与业者对话（→ [12-culture-life](../../12-culture-life/reports/2026-11-culture-life.md) 7.3）。
3. 公营选项：UR 賃貸住宅对外国籍开放，收入基准见登记册 / 12 报告；市営 / 県営住宅走抽选。
4. 签约时序：在留卡 → 住民票 → 印章 → 银行口座 → 口座振替绑定房租与水电气。

### 7.3 公共交通执行路径（建议）

- 通勤 / 通学优先办定期券；IC 卡（Suica / PASMO 等）覆盖乘车与电子支付，多数区间互通。
- 换乘查询用乗換案内应用（时刻与费用）。
- ⚠ 典型通勤区间定期券月费待核实（需按定居地具体区间查询）。

### 7.4 通信与网络执行路径（建议）

- 刚抵达可先办格安 SIM（在留卡 + 支付手段）；光回线初装常有等待期，搬家前先确认可否「事前转移」。
- 大手 / 格安 / 光回线具体月费待核实；不可直接比价（回线与品质不同）。

### 7.5 银行与支付执行路径（建议）

- 开户通常需：在留卡 + 住民票 / 住所证明 + 印鉴；部分银行要求在留 6 个月以上（各银行口径不同，待核实）。
- 推断：邮局银行（ゆうちょ銀行）、部分地方银行与网络银行对外国人较友好，可作过渡。
- 支付：信用卡、电子マネー（Suica / PayPay 等）、银行振込并行；送金走银行或专业送金服务，汇率与手续费差异大。

### 7.6 水电燃气执行路径（建议）

- 水道：向所在地水道局 / 役所做使用开始申报（入住前可办）。
- 电气：向电力公司申込，一般入住当日合闸供电、事后补手续（一般惯例，推断待复核）。
- 燃气：都市ガス需预约上门开栓（推断待复核）；プロパンガス为区域供应商。
- 搬家时办理旧地址解约与新地址开通，通常通过网络或电话申请。

### 7.7 多语言窗口与个人记录（建议）

- 定居地确定后先查本地自治体多语言窗口（清单待补），并回填登记册 #10。
- 90 天清单按 7.1 顺序执行并逐项记录，个人填写状态回写登记册 #9。

3. 个人定居地未定，地域差异（如东京 vs 地方）无法收敛。
