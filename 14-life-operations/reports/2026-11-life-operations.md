## 一、核心结论（摘要）

**核心判断**（每条含数据、口径与来源）：

1. **落地手续有明确时限**（事实）：在留卡于入国时交付，**住居地を定めた日から 14 日以内**向市区町村办理住所登记（入管法上「住居地の届出」）；住民登记于**住所を定めた日から 14 日以内**提交転入届；健康保険与年金随住民登记一并办理。来源：ISA 新規入国者向けガイダンス [Source: https://www.moj.go.jp/isa/support/guidance/index.html, 2026]；総務省 [Source: https://www.soumu.go.jp/main_sosiki/jichi_gyousei/c-gyousei/zairyu/move-in_move-out.html, 2026]。
2. **住房是最大初期费用**（事实）：租房初期费用通常含敷金 + 礼金 + 仲介手数料 + 保证会社 + 更新料，合计可达 **2.5–7 个月**房租（各项下限合计 2.5、上限合计 7；区间口径，因地域 / 物件而异）。来源：国土交通省 / 平台抽样 C 级。
3. **公共交通与通信已高度电子化**（事实）：IC 卡覆盖绝大多数铁路与巴士，并可电子支付；格安 SIM 显著低于大手运营商，但回线与品质不同，不可直接比价。来源：総務省 / JR 東日本。
4. **银行开户存在在留期限门槛**（推断）：部分银行对在留期限有要求，刚抵达时可先用支持外国人的银行或邮局账户过渡。来源：各银行官网。
5. **水电燃气已自由化**（事实）：电力（2016）与燃气（2017）全面自由化，可比较切换；开通需申请与使用开始。来源：資源エネルギー庁 [Source: https://www.enecho.meti.go.jp/category/electricity_and_gas/gas/, 2026]。
6. **2026 年制度更新（新增）**：**2026 年度起国民健康保険料加入「子ども・子育て支援金分」**（与医疗分并征）；**令和 8 年 6 月 14 日以后交付的在留カード，1 歳以上 16 歳未満也须提交顔写真**；**マイナンバーカード有效期間为在留期間満了日**（高度専門職 2 号・永住者・特別永住者除外）；**総務省多言語通訳コールセンター 050-1720-0849**（令和 8-04-01〜令和 9-03-31、12 言語）。来源：厚生労働省 / 総務省 / ISA [Source: https://www.soumu.go.jp/main_sosiki/jichi_gyousei/c-gyousei/zairyu/, 2026]。
7. **最大信息差仍在「执行细节」**（事实）：通信费用 / 银行开户 / 自治体窗口 / 定期券行情的具体现行值待次期或定居地确定后补齐。

## 二、行业与政策发展趋势

### 2.1 落地制度框架（在留・住民・保险・年金）

- **在留卡**：入国时交付（中长期在留者）；在留卡为身份与在留资格的唯一凭证，需随身携带。**住居地を定めた日から 14 日以内**须向市区町村办理**住居地の届出**（与在留卡交付为两个不同时点）；持「在留カード後日交付」护照者以护照办理。来源：ISA 新規入国者向けガイダンス [Source: https://www.moj.go.jp/isa/support/guidance/index.html, 2026]。
- **住民登记（転入届）**：**住所を定めた日から 14 日以内**向新自治体申报；需护照 + 在留卡（或 COE）。迁出前向原自治体申报并领取**転出証明書**；同一市区町村内搬家办**転居届**。来源：総務省 [Source: https://www.soumu.go.jp/main_sosiki/jichi_gyousei/c-gyousei/zairyu/move-in_move-out.html, 2026]。
- **健康保険**：国民健康保険面向非公司职员等居民，自付比例通常 **3 割**（**70–74 岁 2 割 / 現役並み所得 3 割**；**75 岁以上后期高龄者 1 割 / 2 割 / 3 割按所得分层**，2 割自令和 3 年度起仅适用所得上位约 30%）；被用者健康保険面向公司职员，自付通常 3 割，由公司与个人分担保费；高額療養費制度对超上限部分由公费承担差额。**2026 年度起国保料加征「子ども・子育て支援金分」**。来源：厚生労働省 [Source: https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/iryouhoken/index.html, 2026]；高齢者医療制度 [Source: https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/iryouhoken/koukikourei/index.html, 2026]。
- **年金**：20 岁以上 60 岁以下住民有加入义务；国民年金（基础年金）与厚生年金（公司职员）并行；离开日本时可申请脱退一时金（需满足条件，详见 [07-economy-finance](../../07-economy-finance/reports/2026-11-economy-finance.md)）。来源：日本年金機構 [Source: https://www.nenkin.go.jp/, 2026]。
- **マイナンバーカード（2026 更新）**：交付申请免费（本人责再发行除外）；**外国人住民的有效期間为在留期間満了日等**（高度専門職第 2 号・永住者・特別永住者除外）；**令和 8 年 6 月 14 日以后交付的在留カード，1 歳以上 16 歳未満也须提交顔写真**。来源：総務省 [Source: https://www.soumu.go.jp/main_sosiki/jichi_gyousei/c-gyousei/zairyu/, 2026]；ISA [Source: https://www.moj.go.jp/isa/support/guidance/index.html, 2026]。

### 2.2 市场化与自由化进程

- **电力**：2016 年全面自由化，可从各电力公司选择；資源エネルギー庁公表**登録小売電気事業者一覧**。来源：資源エネルギー庁 [Source: https://www.enecho.meti.go.jp/category/electricity_and_gas/gas/, 2026]。
- **燃气**：2017 年全面自由化（都市ガス小売全面自由化），可从各燃气公司选择；有**スイッチング申込件数**统计。来源：同上。
- **通信**：大手运营商（docomo / au / softbank）自有一回线；格安 SIM（MVNO）租用大手回路，月租通常显著低于大手，但回线与品质不同，不可直接比价；光回线为住宅主流方案，常与手机契约捆绑。来源：総務省 [Source: https://www.soumu.go.jp/johotsusintokei/, 2026]。
- **交通**：JR、私铁、地下铁构成城市公共交通主干；定期券为通勤 / 通学主流；IC 卡（Suica、PASMO 等）可乘车与电子支付，多数区间互通。来源：国土交通省 / JR 東日本。

### 7.1 行政手续 90 天清单（执行顺序）

### 7.2 住房执行路径（建议）

1. 先算初期费用：敷金 + 礼金 + 仲介手数料 + 保证会社 + 更新料（区间见 3.2），按 2.5–7 个月房租准备现金。
2. 无保证人时优先询保证会社方案；用国交省**「外国人入住円滑化」**相关指引与业者对话（→ [12-culture-life](../../12-culture-life/reports/2026-11-culture-life.md) 7.3）。
3. 公营选项：UR 賃貸住宅对外国籍开放，收入基准见登记册 / 12 报告；市営 / 県営住宅走抽选。
4. 签约时序：在留卡 → 住民票 → 印章 → 银行口座 → 口座振替绑定房租与水电气。
5. 管理业者须有**国家注册**（200 户以上），可要求交付**重要事项説明書**与**契约书面**作为凭证。

### 7.3 公共交通执行路径（建议）

- 通勤 / 通学优先办定期券；IC 卡（Suica / PASMO 等）覆盖乘车与电子支付，多数区间互通。
- 换乘查询用乗換案内应用（时刻与费用）。
### 7.4 通信与网络执行路径（建议）

- 刚抵达可先办格安 SIM（在留卡 + 支付手段）；光回线初装常有等待期，搬家前先确认可否「事前转移」。
- 大手 / 格安 / 光回线月费因回线与品质而异，不可直接比价。

### 7.5 银行与支付执行路径（建议）

- 开户通常需：在留卡 + 住民票 / 住所证明 + 印鉴。
- 推断：邮局银行（ゆうちょ銀行）、部分地方银行与网络银行对外国人较友好，可作过渡。
- 支付：信用卡、电子マネー（Suica / PayPay 等）、银行振込并行；送金走银行或专业送金服务，汇率与手续费差异大。（来源：各银行官网 / 专业送金服务）

### 7.6 水电燃气执行路径（建议）

- 水道：向所在地水道局 / 役所做使用开始申报（入住前可办）。
- 电气：向电力公司申込，可比较**登録小売电气事業者**后切换。
- 燃气：都市ガス需预约上门开栓（推断待复核）；プロパンガス为区域供应商。
- 搬家时办理旧地址解约与新地址开通，通常通过网络或电话申请。

### 7.7 多语言窗口与个人记录（建议）

- 定居地确定后先查本地自治体多语言窗口，并回填登记册 #10；**総務省多言語通訳コールセンター 050-1720-0849**（令和 8-04-01〜令和 9-03-31、12 言語：日 / 英 / 中 / 韩 / 西 / 葡 / 越 / 泰 / 印尼 / 他加禄 / 尼泊尔 / 缅甸）可作窗口通译支援。
- 90 天清单按 7.1 顺序执行并逐项记录，个人填写状态回写登记册 #9。
