> **现状**：本业务线基线已于 2026-11 产出（[reports/2026-11_baseline_report.md](../reports/2026-11_baseline_report.md) + 同名 HTML，v1.0，数据基准 2026-11-14）。**正常运行永不重跑基线提示词**；仅在①报告与登记册全部丢失，或②经维护规范批准的结构重排时启动。

## 一、项目专属硬性约束

1. **受众与结论边界**：面向本人；输出「步骤 → 书类 → 费用 → 耗时 → 外国人可否 → 常见坑」；不给硬性 Go/No-Go；事实与推断分离。
2. **来源语言规则**：日文官方一手优先；运营商 / 金融機関官网次之；中文来源仅作线索。
3. **边界纪律**：制度规则转 08、税务转 07、语言转 11、文化转 12、地域选择转 13；本主题不复制知识手册段落。
4. **缺失标记**：未核实项写「⚠ 待核实」，不补值、不外推。

## 二、来源优先级

见[业务配置第五节](./business-config.md)。每条数据附完整 URL，每格活值附 `[来源, 年份]`。

## 三、报告结构

本主题专属结构（见[业务配置第 3.2 节](./business-config.md)映射）：核心结论 / 落地制度基础 / 住房与租赁 / 公共交通 / 通信与网络 / 银行与支付 / 水电燃气与基础设施 / 行政手续 90 天清单 / 数据可靠性与局限说明 / 参考来源清单。

## 四、追踪表与边界档案

按[业务配置第八节](./business-config.md)的 10 项追踪指标逐项核对并填写「是否更新」；运行后回写 `{{REGISTRY_PATH}}` 的核心指标与[研究边界档案](./business-config.md)。

## 五、执行方式（建议）

1. 并行启动 4–5 个研究子代理：① 在留 / 住民 / 保险 / 年金；② 住房与租赁；③ 公共交通 / 通信；④ 银行 / 水电燃气；⑤ 90 天清单与多语言窗口。全部限定日 / 官方来源、逐点引用。
2. 主代理合并差异，冲突口径保留双份引用，无法核实项单列「⚠ 待核实」。
