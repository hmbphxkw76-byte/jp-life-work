## 研究边界档案（基线首建，周期运行复核）

### 研究对象边界

- **含**：在日外国人（以特定技能司机为参照）的退出、转型、回国执行层。
- **不含**：税制 / 年金制度正文（→ 07）；永住 / 归化 / 资格取消制度正文（→ 08）；赴日落地与住房 / 保险加入（→ 14）；求职与转职知识手册（→ 02）；法规条文深度解读（→ 09）。

### 三段分层

- **退出**：退職、雇用保険、健康保険任意継続、被用者保険退出、在留资格状态、住民与住所。
- **转型**：在留資格変更、特定活動、其他就労资格、転職边界、语言 / 资格补强、2 号限制。
- **回国**：年金脱退执行、帰国前確定申告、在留卡、再入国、退室、通信 / 银行 / 车辆。

### 主体清单与入选标准

- **官方机构**：出入国在留管理庁 / 法務省 / e-Gov / 厚生労働省 / 日本年金機構 / ハローワーク / 国税庁 / 総務省 / 地方自治体。
- **执行机构**：银行 / 运营商 / 运输 / 车辆相关机构官网，仅作流程参考。
- **入选标准**：官方发布页可回溯；每条附官方原文 URL 与版本日期。

## 维护约定

- 活值统一维护于本登记册；prompt 模板内不填活值。
- 台账修改采用增量方式：保留历史值，不覆盖。
- 报告层补充与台账更新严格区分。
- 无官方依据的金额 / 期限 / 要件统一写「⚠ 待核实」，不补值、不外推。
