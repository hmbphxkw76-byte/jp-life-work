一、核心结论（摘要）

核心判断（编号条目）：

  1. 退出、转型、回国是三件不同的事（事实）：退職是劳动关系终止，在留資格変更 / 取消是资格状态变化，回国是离境与结算——三者不可互相替代。
  2. 退出阶段的关键是「资格状态 + 保险衔接」（推断）：退職本身不会自动取消在留资格，但长期不从事原业务、未转换资格或未办理保险退出，会分别触发不同风险。
  3. 转型阶段的关键是「新资格要件 + 业务限制」（推断）：能否继续留在日本，取决于新雇主、新资格、语言 / 资格条件与特定技能 2 号限制。
  4. 回国阶段的关键是「钱、身份、生活三条线并行」（推断）：年金脱退、确定申告、住民税、在留卡与再入国、退室与车辆 / 通信 / 银行账户应在离境前完成。
  5. 本基线已完成官方回填（事实）：12+1 项中 10 项「已核验」、3 项「部分核验」，均附官方深链 URL 与版本日期；残留项已写明阻塞原因（详见第八节）。

三段路径关键判断：退出决定「资格与保险状态」；转型决定「能否继续留日」；回国决定「离境前钱、身份与生活如何结算」。

条件化建议：见第六节（建议章），与事实分离；本主题不预设个人 Go / No-Go。

关键待核验项：健康保険任意継続専用ページ深链、厚生年金脱退一時金书类与窓口、退室解約预告期与通信 / 银行账户关闭条件、退職时賃金支払期限（24 条）深链（详见第八节待复核清单）。

四、退出与转型政策逐条解读

4.1 退職与労働条件终止

  • 退職是劳动者与雇主之间劳动关系的终止，依合意、解雇或定年发生；退去強制是入管法上的强制离境，二者不得混用（事实）。
  • 解雇予告：原則 30 日以上前、未満は平均賃金の日数分の解雇予告手当（労働基準法20条・21条）；労働条件は書面明示（15条）、退職に係る違約金・損害賠償額の予定は禁止（16条）、療養中＋30 日の解雇は制限（19条）（事实）[厚生労働省東京労働局]。
  • 残留下放し：退職時の賃金支払期限（労働基準法24条）・退職手続の具体書类与窗口，须按厚生労働省与雇主规则核验（⚠ 待核实，公式深链未取得）。
  • 来源：厚生労働省東京労働局 知っておくべき日本の労働関係法令等；e-Gov 労働基準法。

4.2 雇用保険 / 失業給付

  • 退職后符合受给资格者可申请失业给付（基本手当）；受给资格决定窓口は平日 8:30–16:00（事实）[ハローワーク]。
  • 必要书类：離職票・雇用保険被保険者証・本人確認書類・写真・振込先口座等（事実）[厚生労働省 Q&A]。
  • 残留下放し：受给资格・受给期间・手続期限の具体日数，须按ハローワーク Q&A 全文核验（⚠ 待核实）。
  • 来源：厚生労働省 Q&A（基本手当）；ハローワーク。

4.3 健康保険任意継続

  • 被用者保险退职后满足条件者可申请任意继续；该制度是被用者保险继续，不是国民健康保険加入（事实）[日本年金機構]。
  • 残留下放し：申请期限、继续期间、保险料与必要书类——日本年金機構 / 協会けんぽ的任意継続専用ページ深链未取得，媒体线索（退職翌日 20 日以内申請・本人全額負担・2025 改正）不採択（⚠ 部分核验）。
  • 来源：日本年金機構 年金の制度・手続き。

4.4 国民健康保険 / 被用者保険退出

  • 被用者保险は退職の日（翌日资格丧失）、退职后须向市区町村办理住民异动与国民健康保険加入；住民基本台帳の異動は14 日以内（事实）[総務省]。
  • 3 か月超在留で勤務先の公的健康保険に加入しない者は国保加入義務（事実）[厚生労働省]。
  • 来源：厚生労働省 医療保険；総務省 外国人住民に係る住民基本台帳制度。

4.5 在留资格状态（取消 / 変更 / 特定活動）

  • 在留資格取消 ≠ 在留資格変更（事实）：取消は入管法22条の4、原活動を継続して3か月以上行わないと取消事由（正当な理由除く）；变更是入管法20条、事由発生から在留期間満了日以前に申請。
  • 特定活動 ≠ 技能実習（事实）：特定活動は告示で個別規定（例：継続就職活動）。
  • 退職本身不等于在留资格取消；但长期不从事原业务、未转换资格或未按规则变更，会分别触发不同风险（推断）。
  • 来源：出入国在留管理庁 在留資格の取消し；在留資格変更許可申請；特定活動（継続就職活動）；制度正文只读引用 08-visa-immigration。

4.6 特定技能 1 号业务限制与 2 号路径

  • 特定技能 1 号有业务限制与在留上限；特定技能 2 号仅 11 分野，自动车运送业无 2 号（事实，引用 08 最新口径）。
  • 受入上限（自动车运送业）22,100 人（2026-01-23 閣議、至 2029-03 末）；ssw.go.jp 中文页仍显示 24,500，属未同步线索（口径冲突，不取均值）。
  • 来源：出入国在留管理庁 特定技能2号の対象分野の追加；特定技能制度；08-visa-immigration。

4.7 転職与资格外活动边界

  • 転職须在许可范围内（同资格内は 14 日以内届出、资格が変わる場合は変更許可）；资格外活动须另获许可（入管法19条2項）（事实）[出入国在留管理庁]。
  • 资格外活動の包括許可は 1 週 28 時間以内；個別許可は活動ごとに審査（事实）。
  • 来源：出入国在留管理庁 資格外活動許可について；資格外活動許可申請。

4.8 年金・社保后续纳付义务（退出后）与长期资格接口

  • 永住許可ガイドライン（令和8-10-01改定）は「公租公课の支付」を明確に消極評価要素とし、過去の滞納も審査対象、同一生计の家族も審査（事实）[出入国在留管理庁]。
  • 入管法22条の2（公租公课履行）は 2027-04-01 施行（事实）。
  • 金额计算口径只读引用 07-economy-finance；本主题只写申请执行。
  • 来源：永住許可ガイドライン（令和8-10-01改定）；永住者取消ガイドライン。

4.9 厚生年金脱退一时金（执行）

  • 日本年金機構は「Withdrawal Payment（脱退一時金）」を公式案内（事实）。请求は出国後2年以内（朝日 2026-11 报道、要公式回溯）。
  • 残留下放し：请求书类・提出窓口・金额计算——公式深链未取得；厚生労働省が受给条件・算定の見直しを検討中（⚠ 部分核验）。
  • 来源：日本年金機構 Withdrawal Payment；金额口径引用 07-economy-finance。

4.10 帰国前確定申告与住民税 / 所得税

  • 所得税の確定申告は翌年 2/16–3/15。退職所得は分離課税（(収入金額－退職所得控除額)×1/2）。国外転出時課税制度の様式（確定申告書・第三表・対象資産明細書）が国税庁にある（事实）[国税庁]。
  • 残留下放し：帰国前申告の具体的期限・納税管理人届出書の公式深链未取得（⚠ 部分核验）。
  • 来源：国税庁 No.1420 退職所得；No.2240 申告分離課税制度；国外転出時課税制度関係の各種様式；No.2022 準確定申告（申告期限の根拠）。

4.11 在留卡返还 / 再入国許可 / みなし再入国

  • 在留カード返納：失効日から14 日以内（出国（再入国許可除く）時は出入国港で直ちに返納）。再入国許可：入管法26条、有効期間は最長5年（特別永住者6年）。みなし再入国：出国の日から1年以内に再入国すれば許可不要（事实）[出入国在留管理庁]。
  • 来源：在留カード等の返納；再入国許可申請。

4.12 退室 / 解約 / 车辆 / 通信 / 银行账户

  • 车辆：自動車保有関係手続は国土交通省「ワンストップサービス（OSS）」で変更登録・抹消登録・税・手数料を一括完了（事实）[国土交通省]。
  • 残留下放し：退室の解約予告期・通信・銀行口座の关闭条件は各機構 / 契約の公式深链未取得（⚠ 部分核验）。
  • 来源：国土交通省 自動車保有関係手続きはワンストップサービス。

六、退出·转型·回国行动建议（建议章）

本章为「建议」，与事实分离；重大决策须咨询执业法律 / 税务专业人士。

6.1 退出阶段建议

  1. 先确认资格状态：退職前确认在留资格、受入计划、受雇规则与更新时点；若退職后拟留日，尽早判断在留資格変更 / 特定活動（建议）。
  2. 再确认保险：被用者保险退职后，尽快确认健康保険任意継続与国民健康保険切换（任意継続要件须以日本年金機構 / 協会けんぽ官方页为准）（建议）。
  3. 保留书类：退職証明、雇用保険受给资格者证、社会保险料纳付证明、纳税证明（建议）。

6.2 转型阶段建议

  1. 先找新雇主 / 新资格：再申请在留資格変更；不要先退職后长期滞留（建议）。
  2. 确认业务限制：特定技能 1 号业务限制与 2 号分野限制须逐项核对（自动车运送业无 2 号）（建议）。
  3. 语言 / 资格补强：按新资格要件准备日语与资格证明（建议）。

6.3 回国阶段建议

  1. 离境前 1–3 个月：确认年金脱退、确定申告（翌年 2/16–3/15）、住民税、転出届、在留卡与再入国（建议）。
  2. 离境前 2–4 周：完成退室、通信 / 银行 / 车辆解约或处置（车辆走国土交通省 OSS）（建议）。
  3. 离境后：确认日本国内是否仍有纳税、年金或保险后续义务；永住 / 归化审查会看「公租公课」履行与过去滞納（建议）。
