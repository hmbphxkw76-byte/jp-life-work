一、核心结论（摘要）

核心判断（编号条目）：

  1. 退出、转型、回国是三件不同的事（事实）：退職是劳动关系终止，在留資格変更 / 取消是资格状态变化，回国是离境与结算——三者不可互相替代。
  2. 退出阶段的关键是「资格状态 + 保险衔接」（推断）：退職本身不会自动取消在留资格，但长期不从事原业务、未转换资格或未办理保险退出，会分别触发不同风险。
  3. 转型阶段的关键是「新资格要件 + 业务限制」（推断）：能否继续留在日本，取决于新雇主、新资格、语言 / 资格条件与特定技能 2 号限制。
  4. 回国阶段的关键是「钱、身份、生活三条线并行」（推断）：年金脱退、确定申告、住民税、在留卡与再入国、退室与车辆 / 通信 / 银行账户应在离境前完成。
  5. 本基线为初析级（事实）：本主题只研究执行层；税制、年金计算与资格取消制度正文分别引用 07-economy-finance / 08-visa-immigration，不重复展开；具体金额 / 期限 / 要件统一标「⚠ 待核实」。

三段路径关键判断：退出决定「资格与保险状态」；转型决定「能否继续留日」；回国决定「离境前钱、身份与生活如何结算」。

条件化建议：见第六节（建议章），与事实分离；本主题不预设个人 Go / No-Go。

关键待核验项：健康保険任意継続期限与保险料、厚生年金脱退书类与窗口、在留資格取消 / 変更 / 特定活動申请时点、帰国前確定申告期限、退室解約预告期（详见第八节待复核清单）。

四、退出与转型政策逐条解读

4.1 退職与労働条件终止

  • 退職是劳动者与雇主之间劳动关系的终止，依合意、解雇或定年发生；退去強制是入管法上的强制离境，二者不得混用（事实）。
  • 退職后需确认：退職日与最终出勤日、退職金、雇用保険受给资格、健康保険处理、在留资格状态（推断）。
  • ⚠ 待核实：退職手続的具体书类、预告期、窗口与外国人专属口径，须按厚生労働省与雇主规则核验。
  • 来源：厚生労働省 / e-Gov。

4.2 雇用保険 / 失業給付

  • 退職后符合受给资格者可申请失业给付（事实）[ハローワーク]。
  • ⚠ 待核实：受给期间、手続期限、必要书类、再就业活动要求。
  • 来源：ハローワーク https://www.mhlw.go.jp/stf/hellowork/。

4.3 健康保険任意継続

  • 被用者保险退职后满足条件者可申请任意继续；该制度是被用者保险继续，不是国民健康保険加入（事实）[日本年金機構]。
  • ⚠ 待核实：申请期限、继续期间、保险料与必要书类。
  • 来源：日本年金機構 https://www.nenkin.go.jp/。

4.4 国民健康保険 / 被用者保険退出

  • 被用者保险退职后须办理退出，并转入住民保险或任意继续（推断）[厚生労働省]。
  • ⚠ 待核实：各自治体窗口、书类与切换时点。
  • 来源：厚生労働省 https://www.mhlw.go.jp/ / 地方自治体。

4.5 在留资格状态（取消 / 変更 / 特定活動）

  • 在留資格取消 ≠ 在留資格変更（事实）：取消是资格丧失；变更是资格切换。
  • 特定活動 ≠ 技能実習（事实）：特定活動是告示指定的个别活动；技能実習是独立的在留资格。
  • 退職本身不等于在留资格取消；但长期不从事原业务、未转换资格或未按规则变更，会分别触发不同风险（推断）。
  • ⚠ 待核实：退職后资格取消、変更、特定活動的具体申请时点、必要书类与审查基准。
  • 来源：出入国在留管理庁 https://www.moj.go.jp/isa/；制度正文只读引用 08-visa-immigration。

4.6 特定技能 1 号业务限制与 2 号路径

  • 特定技能 1 号有业务限制与在留上限；特定技能 2 号仅适用限定分野，自动车运送业无 2 号（事实，引用 08 最新口径）。
  • ⚠ 待核实：最新分野清单与变更适用时间，按 08-visa-immigration 最新报告核验。

4.7 転職与资格外活动边界

  • 転職须在许可范围内；资格外活动须另获许可（推断）[出入国在留管理庁]。
  • ⚠ 待核实：个别许可与时间上限。

4.8 年金・社保后续纳付义务（退出后）

  • 脱退后仍可能有住民税・年金后续纳付义务；对永住 / 归化的影响须结合 08 最新口径（⚠ 待核实）。
  • 金额计算口径只读引用 07-economy-finance；本主题只写申请执行。
  • 来源：日本年金機構 / 08-visa-immigration。

六、退出·转型·回国行动建议（建议章）

本章为「建议」，与事实分离；重大决策须咨询执业法律 / 税务专业人士。

6.1 退出阶段建议

  1. 先确认资格状态：退職前确认在留资格、受入计划、受雇规则与更新时点（建议）。
  2. 再确认保险：被用者保险退职后，尽快确认健康保険任意継続与国民健康保険切换（建议）。
  3. 保留书类：退職証明、雇用保険受给资格者证、社会保险料纳付证明、纳税证明（建议）。

6.2 转型阶段建议

  1. 先找新雇主 / 新资格：再申请在留資格変更；不要先退職后长期滞留（建议）。
  2. 确认业务限制：特定技能 1 号业务限制与 2 号分野限制须逐项核对（建议）。
  3. 语言 / 资格补强：按新资格要件准备日语与资格证明（建议）。

6.3 回国阶段建议

  1. 离境前 1–3 个月：确认年金脱退、确定申告、住民税、転出届、在留卡与再入国（建议）。
  2. 离境前 2–4 周：完成退室、通信 / 银行 / 车辆解约或处置（建议）。
  3. 离境后：确认日本国内是否仍有纳税、年金或保险后续义务（建议）。

  • A 级（官方一手）：出入国在留管理庁 / 法務省 / e-Gov；厚生労働省 / 日本年金機構 / ハローワーク；国税庁 / 総務省 / 地方自治体。
  • B 级（机构官网）：银行 / 运营商 / 运输 / 车辆相关机构。
  • C 级（平台抽样）：本主题登记册无此类指标。

8.2 主要局限

  1. 执行层研究：本主题不展开税制、年金计算与资格取消制度正文，相关结论引用 07 / 08。
  2. 初析级：具体金额、期限、要件与窗口多数标「⚠ 待核实」，待事件触发或年度复盘补齐。
  3. 个案差异大：资格、收入、家属、资产、离境时点不同，建议必须条件化。

8.3 待复核清单（次期优先，逐项附复核入口）

  1. 健康保険任意継続申请期限、继续期间、保险料与必要书类——复核入口：日本年金機構 https://www.nenkin.go.jp/。
  2. 厚生年金脱退一时金书类清单、申请窗口与复核入口——复核入口：日本年金機構 https://www.nenkin.go.jp/。
  3. 在留資格取消・変更・特定活動的具体申请时点与审查基准——复核入口：出入国在留管理庁 https://www.moj.go.jp/isa/；正文引用 08-visa-immigration。
  4. 退職手続书类、预告期、窗口——复核入口：厚生労働省 https://www.mhlw.go.jp/ / e-Gov。
  5. 雇用保険受给期间与书类——复核入口：ハローワーク https://www.mhlw.go.jp/stf/hellowork/。
  6. 帰国前確定申告申报期限、分离课税与届出书类——复核入口：国税庁 https://www.nta.go.jp/ / 総務省 https://www.soumu.go.jp/。
  7. 在留卡 / 再入国許可 / みなし再入国条件——复核入口：出入国在留管理庁 https://www.moj.go.jp/isa/。
  8. 退室・解約・车辆・通信・银行账户解约预告期与关闭条件——复核入口：国土交通省 https://www.mlit.go.jp/ / 各机构官网 / 地方自治体。
