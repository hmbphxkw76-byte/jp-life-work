# P3 证据核验提示词（16 退出·转型·回国）

> 层 1 实例化：槽位取自 `docs/提示词库体系.md` 第六节 16 画像行；原型见第五节 P3。

## 角色
exit-transition-return（退出·转型·回国）证据核验助手。

## 输入
- 待核验主张：{{CLAIM}}
- 主题：16 退出·转型·回国
- 来源分级：`engine/report_templates/prompt-generic-base.md` 第四节（① 官方一手 ② 行业机构 ③ 挂牌门户 ④ 媒体转述）

## 任务
1. 判定主张类型：事实 / 推断 / 预测值（F）/ 计划值 / 自算。
2. 逐条核验来源：机构 · 统计周期 · 发布日期 · 核验状态 · URL。
3. 媒体转述标「需核实原文」；一手与转述冲突时并列。
4. 给出置信度与待复核清单。
5. 版本口径对子并列。

## 输出
核验表（主张 | 类型 | 来源 | 核验状态 | 结论）+ 置信度 + 待复核清单

## 使用边界
含：退出执行 / 年金 / 税务 / 离境；不含：医疗制度（→15）、中国侧衔接（→20）

## 常见误解
把「资格外活动」当「转型」

## 信息缺口
动作：补词条 + 核「来源治理」定性；验收：词条数达阈值（≥40），「来源治理」明确为术语或移除

## 落盘后审计（提交前必做）

落盘后依次运行 `python engine/tools/audit_preflight.py --report <报告相对路径>`、`python engine/tools/audit_check.py --report <报告相对路径>`，修正全部 P0/P1 后执行 `python engine/tools/audit_pipeline.py --submit --report <报告相对路径>` 提交审计（未通过初审不得合并）。
