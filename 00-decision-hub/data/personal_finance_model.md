# 赴日决策 · 个人财务模型（净储蓄率 / 回本周期）

> **用途**：00 模块的**财务测算单一事实源**。整合 01 收入、07 生活成本、14 初期费用、10 教习费、17 中介费五大模块登记册活值，自动计算「净储蓄率」与「回本周期」。
> **纪律**：只读引用各主题登记册活值，不独立改值；每个输入可追溯到「主题 + 指标号 + 版本」；缺失标「⚠ 待补」，不补值、不外推。
> **生成**：`engine/tools/personal_finance_model.py`（确定性，无 mtime）。

**敏感性**：回本周期对「生活成本」与「初期费用」最敏感；若实际房租高于代表值 62,500 円，初期费用与回本周期同步上升。

## 四、局限

1. 收入采用行业月均现金给与（含加班、全职务），**非个人 Offer 值**；实际以个人确定收入为准。
2. 生活成本为手册估算（07 / 手册 02），**待个人收支结算记录后校准**。
3. 初期费用未含机票、签证费、生活用品与储备金；中介费未含中国侧服务费。
4. 本模型为规划估算，不构成投资 / 税务建议。
