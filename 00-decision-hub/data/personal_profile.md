# 赴日决策 · 个人参数档案（结构化）

> **用途**：五问判定的**个人参数单一事实源**。六维度（资金 / 家属 / 时间窗 / 日语能力 / 驾照类别 / 定居地）全部参数在此登记，其他报告与登记册**只引用本文件**，不复制参数值。
> **纪律**：① 每个参数含「当前值 / 判定 / 依据 / 来源类型 / 核验状态 / 更新时间 / 追溯 ID」，**可追溯、可验证**；② 个人记录与主题事实**分离**——个人记录标「个人记录」，主题事实标来源主题与报告期；③ 缺失不补值、不外推，标「待定 / 待记录」；④ 五问输出统一为「**是 / 否 / 待定 + 对应依据**」。
> **配套**：业务参数见 [../prompts/business-config.md](../prompts/business-config.md)；五问指标状态见 [decision_hub_registry.md](./decision_hub_registry.md)；财务测算见 [personal_finance_model.md](./personal_finance_model.md)。

## 三、五问统一判定（是 / 否 / 待定 + 依据）

> 本表是五问输出的**统一格式基准**。任何报告、登记册、一页纸引用五问结论时，必须给出「是 / 否 / 待定」之一与对应依据，不得只写定性描述。

## 四、追溯与可验证规则

1. **追溯 ID**：每个参数有唯一 `PF-NN`；引用时写 `（PF-NN）`，便于回溯到本文件与来源主题。
2. **来源类型**：分「个人记录」「主题事实」「派生」三类；主题事实须注明来源主题与报告期 / 登记册版本。
3. **核验状态**：`已核验 / 部分 / ⚠ 待核实 / ⚠ 待记录`；个人记录类缺值统一「⚠ 待记录」，不补值。
4. **变更留痕**：参数值变更只改本文件，并在「版本记录」登记；下游报告通过指针引用，不复制值。
5. **与登记册关系**：本文件是个人参数单一事实源；[decision_hub_registry.md](./decision_hub_registry.md) 只保存引用位置与收敛状态。
