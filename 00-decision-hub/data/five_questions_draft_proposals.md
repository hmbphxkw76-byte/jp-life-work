## 一、总体建议

**不建议现在给出整体 Go / No-Go。** 五问中两问的事实面已基本具备判定条件（Q1 收入面、Q2 门槛面），
但结论被三个个人参数卡住：**可用资金 / 时间窗（PF-01、PF-02）**、**驾照类别与日语水平（PF-11、PF-13）**、
**目标定居地（PF-16）**。此外 Q3 存在一项**结构性事实障碍**（见下），须先澄清。

建议顺序：先补 PF-01 / 02 / 11 / 13 / 16 → 再复评五问 → 最后才谈 Go / No-Go。

## 三、需决策者提供的输入（阻塞项清单）

1. **PF-01 可用资金** + **PF-02 赴日时间窗** → 决定 Q1 回本周期与 Q3 路径选择；
2. **PF-11 中国驾照类别** + **PF-13 日语水平** + **PF-14 可参加考试** → 决定 Q2 可行性（当前最大不确定性）；
3. **PF-16 目标定居地** → 决定 Q4 全部下游比较（住房 / 防灾 / 自治体服务）；
4. **PF-05 是否接受中介渠道** → 决定 Q3 的风险敞口与成本；
5. **Q3 路径澄清**：在中国未被列入 ISA 認定送出機関名单、育成就労 MOC 不含中国的现状下，
   本人的可行在留资格路径需专项核实（候选：企业直接受入 + 特定活动、或先取得其他在留资格后变更）。
