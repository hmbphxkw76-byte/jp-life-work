一、执行摘要：结论先行

第一句结论：在日本，防灾与安全的关键是「国家预警 → 自治体通知 → 个人接收」三层打通；本基线的信号矩阵为 绿灯 4 / 黄灯 2 / 灰灯 4，方向为「体制可用、个人接收层待登记」。

支撑论据（3 条编号）：

  1. 避难行动有明确分级口径（事实）：发布避难指示（警戒レベル 4）时全员避难、不等レベル 5；土砂 / 洪水危险区域实况看キキクル（気象庁，2026-11-14 核验）。
  2. 外语情报渠道已成型但未个人化（事实 + 推断）：観光庁监修 Safety tips 提供 15 语种推送、気象庁多言語ページ含简体中文；但防災メール / 防灾行政无线为自治体层级，须在定居地登记住址时一并申请（観光庁 Safety tips，2026）。
  3. 应急电话口径清晰但分诊因地区而异（事实）：警察 110、消防・救急 119、災害用伝言ダイヤル 171、救急安心センター #7119（令和 6 年 11 月为 36 地域；现行消防庁页面为 42 地域，已更新，以现行页面为准）；未开设地区拨 #8000（儿童急救）或 119（消防庁 消防白書，2024）。

先行信号综述：绿灯 4（気象厅预警体系、避难分级、Safety tips、应急电话）；黄灯 2（自治体避難所与配信渠道、救急安心センター覆盖）；灰灯 4（犯罪统计数值、领事保护机制、避難所清单、备蓄补助）。

二、持续监测机制设计

数据流与传导路径：

数据源层（気象庁 / 消防庁 / 防災庁 / 警察庁 / 外務省 / 自治体）
  → 指标台账层（本登记册 12+1 项活值）

  → 决策输出层（个人接收登记 / 避难行动 / 事件触发解读）

三级监测节拍：

节拍 目的 核心指标 输出物

传导链（每条含先行变量 / 中间变量 / 典型时滞 / 验证指标）：

  1. 气象现象（台风 / 大雨 / 地震）→ 気象庁警報・警戒レベル → 自治体避難指示 → 个人避难行动（时滞：分钟至小时；验证指标：避难所开放与安否）。
  2. 自治体防灾计划改定 → 避難所 / 防災メール 渠道变化 → 个人接收登记（时滞：计划改定后一次性；验证指标：登记完成率）。
  3. 犯罪统计 / 特殊诈欺手口更新 → 生活安全提醒 → 防诈行为（时滞：年度 / 半年度；验证指标：警察厅统计与窗口提醒）。

类型机制适配：本业务线为个人安全与防灾决策支持，非市场定价监测；市场指标监测型的 K/RL 阈值信号、供给情景重算、五态合成等机制不适用，改以追踪表 + 触发器 + 监测日历承载监测职能。

四、首期基线数据（2026-11-14）

4.1 防灾体制

  • 自治体防灾计划与避難所：自治体基于防灾计划指定避難所与避难场所，并以防災行政无线 / 防災メール配信。⚠ 具体避難所清单・开放条件因自治体而异。
  • ハザードマップ与风险地图：国交省・気象庁・自治体提供洪水・土砂等风险地图，用于确认现住地与通勤圈风险。⚠ 具体图幅与查询入口因自治体而异。
  • 来源：総務省消防庁 https://www.fdma.go.jp/ / 国土交通省 https://www.mlit.go.jp/ / 地方自治体。

4.2 避难与情报

  • 警戒レベル与避难行动（事实）：发布避难指示（警戒レベル 4）时全员避难、不等レベル 5；土砂 / 洪水危险区域实况看キキクル。
  • 来源：気象庁 https://www.jma.go.jp/jma/kishou/know/bosai/warning.html；キキクル https://www.jma.go.jp/bosai/risk/。
  • 多语言情报（事实）：Safety tips 提供 15 语种紧急地震速报・海啸・特別警報推送与行动流程图、沟通卡；気象庁多言語ページ含简体中文。
  • 来源：観光庁 https://www.mlit.go.jp/kankocho/seisaku_seido/kihonkeikaku/jizoku_kankochi/anzenkakuho/inbound/tool.html；気象庁多言語 https://www.data.jma.go.jp/multi/yoho/index.html?lang=cn_zs。
  • 自治体配信与情報難民（事实）：防災メール / LINE 公式账号 / 防灾行政无线因自治体而异，须在役所住民课登记住址时一并申请；総務省「情報難民ゼロ」项目培训災害時外国人支援情報コーディネーター。
  • 来源：総務省 https://www.soumu.go.jp/menu_seisaku/chiho/02gyosei05_03000060.html。

4.3 治安与人身

  • 警察庁犯罪统计与特殊诈欺：警察庁发布犯罪统计；⚠ 最新年度数值・特殊诈欺手口清单待核实。
  • 一般防诈口径（一般化观察）：自称役所 / 警察要求提供账号 = 诈骗；跨境「孩子的电话」类诈骗亦须同步提醒国内家人。
  • 来源：警察庁 https://www.npa.go.jp/；防诈正文与个案见 12-culture-life。

4.4 领事保护

  • 外務省海外安全与在外公館：外務省发布海外安全情报，在外公館提供护照・遗失・紧急协助。⚠ 具体机制与申请口径待核实。
  • 来源：外務省 https://www.mofa.go.jp/。

九、风险、局限与监测盲区

风险（条目式）：

  • 台风 / 大雨 / 地震 / 海啸等大规模灾害的突发性与网络可达性风险；
  • 外语情报个人接收层未登记导致「情報難民」化；
  • 特殊诈欺与跨境诈骗；
  • 海外安全事件与护照遗失。

本机制的局限：

  1. 数据缺口：自治体避難所清单、最新犯罪统计数值、领事保护具体机制未取得；
  2. 发布时滞：部分统计年度发布，实时性有限；
  3. 口径不可比：都道府県 / 市町村口径与「非常用」表述差异；
  4. 阈值未回测：S01–S06 为初期默认参数，未经年度回测；
  5. 非实时：本主题为月度核验，不替代官方实时预警；
  6. 个人差异：定居地、通勤路线、家庭构成不同，接收清单须个案化。
