## 一、执行摘要：结论先行

**第一句结论**：在日本，防灾与安全的关键是「**国家预警 → 自治体通知 → 个人接收**」三层打通；本基线的信号矩阵为 **绿灯 4 / 黄灯 2 / 灰灯 4**，方向为「体制可用、个人接收层待登记」。**本期（2026-11-17）核验到国家预警层口径改版**——令和8年5月29日「新たな防災気象情報」运用开始，信息名称直接标注警戒レベル数字——灯色计数无翻转，但判读口径须按新版执行。

**支撑论据**（3 条编号）：

1. **避难行动有明确分级口径，且已于令和8年改版**（事实）：河川氾濫・大雨・土砂災害・高潮 4 现象的信息名称加注警戒レベル数字（如「レベル4氾濫危険警報」），并新设危険警報；发布避难指示（警戒レベル 4）时全员避难、不等レベル 5（[気象庁 新たな防災気象情報](https://www.jma.go.jp/jma/kishou/know/bosai/keiho-update2026/index.html)，2026-05-29 運用開始；[防災庁 避難情報ガイドライン](https://www.bousai.go.jp/oukyu/hinanjouhou/r3_hinanjouhou_guideline/)，令和8年3月改定）。

## 二、持续监测机制设计

**数据流与传导路径**：

```text
数据源层（気象庁 / 消防庁 / 防災庁 / 警察庁 / 外務省 / 自治体）
  → 指标台账层（本登记册 12+1 项活值）
  → 信号规则层（S01–S06）
  → 决策输出层（个人接收登记 / 避难行动 / 事件触发解读）
```

**三级监测节拍**：

| 节拍 | 目的 | 核心指标 | 输出物 |
|---|---|---|---|
| 月度 | 核验与判定 | 全部 12 项 | 登记册更新记录；命中触发器升级为事件触发 |
| 季度 | 全维度复核 | 防灾 / 情报 / 治安 / 领事 / 联络 | 完整更新版报告（八节骨架） |
| 年度 | 复盘与阈值回测 | 全部 + 口径清单 | 年度台账复盘 |

**传导链**（每条含先行变量 / 中间变量 / 典型时滞 / 验证指标）：

1. 气象现象（台风 / 大雨 / 地震）→ 気象庁警報・警戒レベル（**令和8年改版后名称含数字**）→ 自治体避難指示 → 个人避难行动（时滞：分钟至小时；验证指标：避难所开放与安否）。
2. 自治体防灾计划改定 → 避難所 / 防災メール 渠道变化 → 个人接收登记（时滞：计划改定后一次性；验证指标：登记完成率）。
3. 犯罪统计 / 特殊诈欺手口更新 → 生活安全提醒 → 防诈行为（时滞：年度 / 半年度；验证指标：警察厅统计与窗口提醒）。
4. 大规模灾害（如 2026-07-28 熊本地震、2026-08 千叶豪雨、2026-11-08 静冈地震）→ 防災庁現地視察・被害状況公表 → 体制与渠道复核（时滞：灾后数日至数周；验证指标：官方被害状況报告与対応记录）。

**类型机制适配**：本业务线为个人安全与防灾决策支持，非市场定价监测；市场指标监测型的 K/RL 阈值信号、供给情景重算、五态合成等机制不适用，改以追踪表 + 触发器 + 监测日历承载监测职能。

## 四、首期基线数据（2026-11-14）

### 4.1 防灾体制

- **自治体防灾计划与避難所**：自治体基于防灾计划指定避難所与避难场所，并以防災行政无线 / 防災メール配信。⚠ 具体避難所清单・开放条件因自治体而异。
- **ハザードマップ与风险地图**：国交省・気象庁・自治体提供洪水・土砂等风险地图，用于确认现住地与通勤圈风险；大雨时以「キキクル」（大雨警報・洪水警報の危険度分布）与国交省「川の防災情報」确认河川水位。⚠ 具体图幅与查询入口因自治体而异。
- **中央防灾体制**：防災庁于 2026-11-02 由内閣府防灾改组发足，为中央防灾司令塔；令和8年熊本地震（2026-07-28）、令和8年8月千葉豪雨、令和8年台風第25号等近期灾害的被害状況与対応由防災庁公表。
- 来源：総務省消防庁 [https://www.fdma.go.jp/](https://www.fdma.go.jp/) / 防災庁 [https://www.bousai.go.jp](https://www.bousai.go.jp) / 国土交通省 [https://www.mlit.go.jp/](https://www.mlit.go.jp/) / 地方自治体。

### 4.2 避难与情报

- **警戒レベル与避难行动**（事实）：河川氾濫・大雨・土砂災害・高潮 4 现象的信息名称加注警戒レベル数字（如「レベル4氾濫危険警報」），令和8年5月29日運用開始；发布避难指示（警戒レベル 4）时全员避难、不等レベル 5；避難指示未发令但相当于レベル 4 / レベル 3 的防災気象情報发表时，须用キキクル与河川水位信息自行判断避难。
  - 来源：気象庁 [新たな防災気象情報](https://www.jma.go.jp/jma/kishou/know/bosai/keiho-update2026/index.html)；[警報・注意報](https://www.jma.go.jp/jma/kishou/know/bosai/warning.html)；キキクル [https://www.jma.go.jp/bosai/risk/](https://www.jma.go.jp/bosai/risk/)；防災庁 [避難情報ガイドライン](https://www.bousai.go.jp/oukyu/hinanjouhou/r3_hinanjouhou_guideline/)。
- **多语言情报**（事实）：Safety tips 提供 15 语种紧急地震速报・海啸・特別警報推送与行动流程图、沟通卡；気象庁多言語ページ含简体中文。
  - 来源：観光庁 [https://www.mlit.go.jp/kankocho/seisaku_seido/kihonkeikaku/jizoku_kankochi/anzenkakuho/inbound/tool.html](https://www.mlit.go.jp/kankocho/seisaku_seido/kihonkeikaku/jizoku_kankochi/anzenkakuho/inbound/tool.html)；気象庁多言語 [https://www.data.jma.go.jp/multi/yoho/index.html?lang=cn_zs](https://www.data.jma.go.jp/multi/yoho/index.html?lang=cn_zs)。
- **自治体配信与情報難民**（事实）：防災メール / LINE 公式账号 / 防灾行政无线因自治体而异，须在役所住民课登记住址时一并申请；総務省「情報難民ゼロ」项目培训災害時外国人支援情報コーディネーター。
  - 来源：総務省 [https://www.soumu.go.jp/menu_seisaku/chiho/02gyosei05_03000060.html](https://www.soumu.go.jp/menu_seisaku/chiho/02gyosei05_03000060.html)。
- **官方入门与训练**（事实）：内閣府「防災の手引き」令和8年10月更新，覆盖事前备え・警戒レベル・避难时机与各灾害行动；気象庁每年 6 月与 11 月实施紧急地震速报全国训练，11 月场次面向民间企业等更广对象并联动全国シェイクアウト训练。
  - 来源：内閣府 [防災の手引き](https://www.kantei.go.jp/jp/headline/bousai/index.html)；気象庁 [緊急地震速報を活用した訓練](https://www.data.jma.go.jp/svd/eew/data/nc/kunren/kunren.html)。

## 九、风险、局限与监测盲区

**风险（条目式）**：

1. **数据缺口**：自治体避難所清单、最新犯罪统计数值、领事保护具体机制未取得；
2. **发布时滞**：部分统计年度发布，实时性有限；
3. **口径不可比**：都道府県 / 市町村口径与「非常用」表述差异；令和8年改版后旧名称口径不可再套用；
4. **阈值未回测**：S01–S06 为初期默认参数，未经年度回测；
5. **非实时**：本主题为月度核验，不替代官方实时预警；
6. **个人差异**：定居地、通勤路线、家庭构成不同，接收清单须个案化。
