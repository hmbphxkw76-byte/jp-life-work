## 研究边界档案（基线首建，周期运行复核）

### 研究对象边界

- **含**：在日外国人（以特定技能司机为参照）的防灾体制理解、避难与外语情报、治安与人身、领事保护、应急联络。
- **不含**：就医与急救医疗口径（→ 15）；在留风险、取消・退去与灾害时外国人支援政策环境（→ 08 / 09）；地域防灾渠道正文（→ 13）；多文化共生政策正文（→ 12）；家族带同与育儿（→ 18）。

### 五维分层

- **防灾体制**：自治体防灾计划、避難所、防灾行政无线。
- **避难与情报**：避难行动、防災メール、外语情报、情報難民。
- **治安与人身**：犯罪统计、特殊诈欺、生活安全窗口。
- **领事保护**：海外安全、护照与遗失、在外公館。
- **应急联络**：110 / 119 / 171 / #7119 / Visitor Hotline。

### 主体清单与入选标准

- **官方机构**：総務省消防庁 / 気象庁 / 内閣府・防災庁 / 外務省 / 警察庁 / 地方自治体。
- **执行 / 辅助机构**：観光庁 / JNTO / NHK WORLD-JAPAN / 地域国際化協会 / 各运营商（仅执行流程）。
- **入选标准**：官方发布页可回溯；每条附官方原文 URL 与版本日期。
