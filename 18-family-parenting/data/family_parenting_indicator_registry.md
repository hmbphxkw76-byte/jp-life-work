## 研究边界档案（基线首建，周期运行复核）

### 研究对象边界

- **含**：在日外国人（以特定技能司机为参照）的家族带同、配偶就劳与扶养、生育育儿、子女教育、婚姻家庭事件、继承与终末、定住者路径的执行层。
- **不含**：永住・归化・在留资格制度正文（→ 08）；税制 / 年金 / 扶养控除正文（→ 07）；学制与就学手续正文（→ 10）；分娩就医与保险正文（→ 15）；住民与行政 90 天清单（→ 14）；法规条文深度解读（→ 09）；防灾・安全・治安（→ 19）。

### 四段分层

- **带同**：家族滞在、扶养人资格、收入证明、资格外活動許可。
- **养育**：出産育児一時金、児童手当、母子 / 父子家庭支援、保育 / 教育、日本語指導。
- **家庭事件**：国際結婚、婚姻届、離婚・親権・戸籍、相続、終末。
- **长期**：定住者路径、世帯年収、永住接口（只读引用 08）。

### 主体清单与入选标准

- **官方机构**：出入国在留管理庁 / 法務省 / e-Gov / 厚生労働省 / 内閣府 / 文部科学省 / 日本年金機構 / 総務省 / 地方自治体 / 家庭裁判所。
- **执行机构**：自治体多语言窗口、地域国際化協会、保育 / 教育机构官网，仅作流程参考。
- **入选标准**：官方发布页可回溯；每条附官方原文 URL 与版本日期。
