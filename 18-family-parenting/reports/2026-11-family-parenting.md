## 一、核心结论（摘要）

**核心判断**（编号条目）：

1. **家族带同的关键是「扶养人资格 + 证明清单」，不是「年收数值」**（事实）：家族滞在要求扶养人属于特定就劳资格 / 留学等持有者的配偶或子；特定技能 1 号原则上不可带家属。官方**无公开年收门槛数值**，只要求提交扶养者职业·收入证明（在職証明書等＋住民税课税〔或非课税〕证明书＋纳税证明书）。
2. **配偶就劳的关键是「包括许可 1 周 28 小时」与「个别许可」的分界**（事实）：家族滞在配偶的资格外活動許可，包括许可以 1 周 28 小时以内为限；个别许可涵盖稼働时间不明确活动等，要件之一为从事期间不超过在留期间过半。
3. **养育阶段的关键是「给付 + 保育 / 教育」两套制度并行**（推断）：出産育児一時金（一次性）、児童手当（按月）、母子 / 父子家庭支援各属不同制度；保育所・認定こども園・幼稚園三者主管与年龄口径不同，须按自治体与家庭需求匹配。
4. **子女教育的关键是「无就学义务但希望者无偿接收」与「日本語指導缺口」**（事实）：外国人子女无就学义务，但希望就读公立义务教育诸学校者依国际人权规约等与日本人儿童同样无偿接收；令和 7 年调查仍 11.4%（9,699 人）未受任何形式日本語指導。
5. **本基线为初析级**（事实）：本主题只研究执行层；永住・归化・在留资格制度正文引用 [08-visa-immigration](../../08-visa-immigration/reports/2026-11-visa-immigration.md)，学制与就学手续正文引用 [10-education-qualification](../../10-education-qualification/reports/2026-11-education-qualification.md)，分娩就医与保险正文引用 [15-health-wellbeing](../../15-health-wellbeing/reports/2026-11-health-wellbeing.md)；具体金额 / 期限 / 要件统一标「⚠ 待核实」。

**四段路径关键判断**：带同决定「谁能来、怎么证明」；养育决定「生养教钱如何衔接」；家庭事件决定「婚离继如何办理」；长期决定「家庭如何留在日本」。

**条件化建议**：见第七节（建议章），与事实分离；本主题不预设个人 Go / No-Go。

**关键待核验项**：出産育児一時金金额 / 期限 / 书类；児童手当与児童扶養手当最新年度口径；保育所 / 認定こども園 / 幼稚園利用料与入所要件；国際結婚・離婚・相続具体书类与窗口（详见第八节待复核清单）。

## 三、家庭经济·扶养与支援（核心模块）

### 3.1 家族滞在扶养与「年收门槛」的实务口径 + 证明清单

- **扶养人资格范围**（事实）：教授、芸術、宗教、報道、高度専門職、経営・管理、法律・会計業務、医療、研究、教育、技術・人文知識・国際業務、企業内転勤、介護、興行、技能、**特定技能 2 号**、文化活動、**留学**等在留资格者扶养的**配偶者或子**；**特定技能 1 号原则上不可带家属**（官方中文站表述「无法申请家人陪同」）。
  - 来源：出入国在留管理庁「家族滞在」[https://www.moj.go.jp/isa/applications/status/dependent](https://www.moj.go.jp/isa/applications/status/dependent)；特定技能中文站 [https://www.ssw.go.jp/cn/about/visa/](https://www.ssw.go.jp/cn/about/visa/)。
- **年收门槛 = 实务口径 + 证明清单**（事实 + 推断）：ISA 官方**无公开年收数值基准**，审查以「能否持续扶养全家」的实质判断为导向；申请时须提交以下证明清单：

| 证明项 | 内容 | 口径 |
|---|---|---|
| 身分关系证明 | 户籍誊本 / 婚姻届受理证明书 / 结婚证明书（复印件）/ 出生证明书（复印件）任一 | 外文须附日文翻译 |
| 扶养者身份 | 在留卡或护照复印件 | — |
| 扶养者职业·收入证明 | **在職証明書等** | 职业与雇佣状态 |
| 纳税证明 | **住民税课税（或非课税）证明书＋纳税证明书**（一年间总所得与纳税状况） | 收入与履行公的义务的证据 |
| 共通 | 申请书、照片、返信用信封 | 已在国内的家属走「在留资格变更许可」 |

- **口径警示**：「以提交证明为足」与「实务扶养能力审查」两种解读并列保留；精确年收数值 ⚠ 待核实。
- 来源：出入国在留管理庁 [https://www.moj.go.jp/isa/applications/status/dependent](https://www.moj.go.jp/isa/applications/status/dependent)。

### 3.2 配偶就劳（资格外活動許可）

| 许可类型 | 适用情形 | 要点 |
|---|---|---|
| 包括许可 | 1 周 28 小时以内的报偿活动 | 仅需申请书 |
| 个别许可 | 包括许可范围外：稼働时间不明确的事业（个人事业主等）、业务委托・承包契约等 | 附活动内容说明文书；要件之一为从事期间不超过在留期间过半 |

- 一般原则要件：不妨碍本属在留资格的活动、无法令违反与风俗关联活动、素行良好等。
- 超过 28 小时 / 周或实质成为全职就业的情形，可能被判定为在留目的实质变更，须改办在留资格变更许可（推断）。
- 来源：出入国在留管理庁 [https://www.moj.go.jp/isa/applications/procedures/nyuukokukanri07_00004.html](https://www.moj.go.jp/isa/applications/procedures/nyuukokukanri07_00004.html)；一般原则 [https://www.moj.go.jp/isa/applications/procedures/nyuukokukanri07_00045.html](https://www.moj.go.jp/isa/applications/procedures/nyuukokukanri07_00045.html)。

### 3.3 出産育児一時金

- 加入健康保险者分娩时可申请**一次性给付**；与「産科医療给付金」等并行为母婴保障口径（推断）。
- ⚠ **待核实**：最新年度金额、申请期限、必要书类、领取方法（保险者经由 vs 直接给医疗机构）。
- 来源：厚生労働省 [https://www.mhlw.go.jp/](https://www.mhlw.go.jp/)；就医与保险正文只读引用 [15-health-wellbeing](../../15-health-wellbeing/reports/2026-11-health-wellbeing.md)。

### 3.4 児童手当

- 对监护儿童者**按月给付**；所得限制与年龄区间按年度改定；申请窗口为市区町村（推断）。
- ⚠ **待核实**：令和 8 年度金额、所得限制、年龄区间、申请与认定口径。
- 来源：内閣府 [https://www.cao.go.jp/](https://www.cao.go.jp/) / 地方自治体。

### 3.5 母子 / 父子家庭支援

- 児童扶養手当、生活保護、母子福祉資金等制度并存，分别对应单亲、低收入与困难家庭（推断）。
- ⚠ **待核实**：各制度要件、金额、申请窗口与认定基准。
- 来源：厚生労働省 [https://www.mhlw.go.jp/](https://www.mhlw.go.jp/) / 地方自治体。

## 四、家庭形态与服务主体细分

### 4.1 家庭形态与服务主体

| 家庭形态 | 关键制度接口 | 主责窗口 |
|---|---|---|
| 扶养配偶 | 家族滞在、资格外活動許可 | 出入国在留管理庁 / 自治体 |
| 子女（学前） | 保育所・認定こども園・幼稚園 | 厚生労働省 / 文部科学省 / 自治体 |
| 子女（学龄） | 就学・転校・日本語指導 | 文部科学省 / 自治体教育委员会 |
| 单亲家庭 | 児童扶養手当・生活保護・母子支援 | 厚生労働省 / 自治体 |
| 国际婚姻 | 婚姻届・在留资格变更 | 自治体 / 出入国在留管理庁 |
| 继承 / 终末 | 相続・遺言・埋葬 | 法務省 / 家庭裁判所 / 自治体 |

### 4.2 保育所・認定こども園・幼稚園

- **保育所（保育園）**：福祉设施，以需要保育的儿童为对象，主管为厚生労働省 / 自治体。
- **認定こども園**：教育与保育一体的设施，兼具幼稚園与保育所功能。
- **幼稚園**：学校教育法上的学校，3 岁以上为对象，主管为文部科学省 / 自治体。
- ⚠ **待核实**：各形态利用料、入所要件、待機児童口径因自治体而异。
- 来源：厚生労働省 [https://www.mhlw.go.jp/](https://www.mhlw.go.jp/) / 文部科学省 [https://www.mext.go.jp/](https://www.mext.go.jp/)。

### 4.3 学校与入学 / 転校 / 日本語指導

- **就学政策**（事实）：对外国人子女**无就学义务**，但希望就读公立义务教育诸学校者，依据国际人权规约等与日本人儿童同样**无偿接收**；就学手续时的居住地确认使用在留卡或特别永住者证明书，无提示时也可用可信书类柔性处理。
  - 来源：文科省「公立小·中就学案内」[https://www.mext.go.jp/a_menu/shotou/shugaku/detail/1422256.htm](https://www.mext.go.jp/a_menu/shotou/shugaku/detail/1422256.htm)；「就学手续」[https://www.mext.go.jp/a_menu/shotou/clarinet/004/1323374.htm](https://www.mext.go.jp/a_menu/shotou/clarinet/004/1323374.htm)；「就学促進指针」（令和 8-08-28 改订）[https://www.mext.go.jp/a_menu/shotou/clarinet/004/1415154_00018.html](https://www.mext.go.jp/a_menu/shotou/clarinet/004/1415154_00018.html)。
- **日本語指導体制**（事实，令和 7 年调查，2026-05-25 公表）：公立学校日本語指導必要児童生徒 **84,759 人**（较前次 +22.6%）；含国公私立 **88,045 人**，其中外国籍 73,313 人；受「特别照顾指导」者 88.6%，**仍有 11.4%（9,699 人）未受任何形式指导**；支援人力：日本語指導補助者 8,706 人、母語支援員 7,301 人（全国），自治体间体制差异大。
  - 来源：文科省「日本語指導受入状況调查」[https://www.mext.go.jp/content/20260525-mxt_kokoku-000007294_00.pdf](https://www.mext.go.jp/content/20260525-mxt_kokoku-000007294_00.pdf)。
- **就学现状**（事实，令和 7 年 5 月 1 日时点，2026-05-25 公表）：学龄相当外国人儿童住基登载数 177,726 人，义务教育诸学校在籍 150,786 人（85.0%）；不就学可能性合计 9,153 人。
  - 来源：文科省「外国人子女就学状況调查」[https://www.mext.go.jp/content/20260525-mxt_kokoku-000049969_02.pdf](https://www.mext.go.jp/content/20260525-mxt_kokoku-000049969_02.pdf)。
- ⚠ **待核实**：転校（編入学・転入学）时点、学分换算、高中入试日语门槛、各自治体指定校与窗口口径——按 [10-education-qualification](../../10-education-qualification/reports/2026-11-education-qualification.md) 手册 03 章与驻地教育委员会最新页核验。

### 4.4 婚姻家庭事件主体

- **国際結婚 / 婚姻届**：婚姻届向市区町村提交；国际结婚须满足双方本国法成立要件并备身分关系书类（外文附日文翻译）。⚠ 具体书类清单与受理口径待核实。
- **離婚・親権**：离婚方式（協議・調停・裁判）与親権・面会交流・養育費安排分别判断。⚠ 要件与家庭裁判所手続待核实。
- **相続 / 終末**：继承为法定承继、遗嘱为意定安排。⚠ 具体要件与窗口待核实。
- 来源：法務省 [https://www.moj.go.jp/](https://www.moj.go.jp/) / 家庭裁判所 [https://www.courts.go.jp/](https://www.courts.go.jp/) / 地方自治体。

## 五、家庭事件办理的能力要求

- **书类与翻译**：身分关系书类（户籍誊本 / 婚姻届受理证明 / 结婚证明 / 出生证明）与外文日文翻译是家族滞在、婚姻、继承的共同基础；提前备齐并留档。
- **语言**：市役所 / 教育委员会窗口以日语为主；多语言窗口与翻译支援因自治体而异，用「自治体名 + 多文化共生 + 相談窓口」检索。
- **资格外活動**：配偶就业前先确认许可类型与时间上限，避免实质全职就业触发在留目的变更。
- **跨窗口协同**：在留（ISA）・住民（自治体）・就学（教育委员会）・给付（自治体）分属不同窗口，须按事件顺序衔接。
- 来源：出入国在留管理庁 / 地方自治体 / 地域国際化協会（执行流程）。

## 七、家庭落地路径建议（结论章）

> 本章为「建议」，与事实分离；重大决策须咨询执业法律 / 税务专业人士。

### 7.1 带同前（建议）

1. **先确认扶养人资格**：确认本人持可带家属的在留资格（特定技能 1 号原则上不可；2 号 / 技人国等可）。
2. **备齐证明清单**：在职证明、住民税课税（非课税）证明书、纳税证明、身分关系书类与日译。
3. **留档证据链**：工资明细、社保记录、纳税证明长期留存，既是家族滞在证明也是永住证据链。

### 7.2 养育期（建议）

1. **生育**：确认健康保险加入状态与出産育児一時金申请路径（⚠ 金额与期限以官方最新页为准）。
2. **保育**：定居地确定后向役所确认保育所・認定こども園・幼稚園入要项与利用料。
3. **教育**：转入驻地时办住民票 → 教育委员会确认指定校与入学手续；不要假设「附近学校有日语老师」，先确认日本語指導教室 / 抽离指导与母语支援员配置。

### 7.3 家庭事件（建议）

1. **结婚 / 离婚**：婚姻届、离婚方式与親権安排分别确认；国际结婚提前备身分关系书类与日译。
2. **继承**：法定承继与遗嘱安排分开处理；必要时咨询弁護士 / 司法書士。

### 7.4 时间线（建议）

| 阶段 | 时点 | 事项 |
|---|---|---|
| 带同前 | 决定带同前 3–6 个月 | 扶养人资格、证明清单、身分辨识书类 |
| 带同时 | 在留资格变更 / COE 时 | 家族滞在、扶养证明、同步更新 |
| 生育 | 妊娠・出産前后 | 出産育児一時金、母子手帳、保险 |
| 保育 | 入所前 6–12 个月 | 保育所・認定こども園・幼稚園入要项 |
| 入学 / 転校 | 转入驻地时 | 住民票 → 教育委员会 → 指定校 |
| 长期 | 永住申请前 | 世帯年収、扶养控除、年金接口（→ 08 / 07） |
