# 日本 家族·育儿·人生事件 周期更新与事件触发提示词（职业就业调研型）

> **用途**：运行期统一入口，覆盖月度核验轻运行 / 季度主更新 / 年度复盘 / 事件触发解读四种节拍。以官方一手来源为依据、以上一期报告与首期基线为对比锚，完成「核验 → 更新 → 建议 → 可靠性」闭环。
> **产出**：季度 / 年度更新报告落盘 `{{OUTPUT_PATH}}`（`reports/{{YYYY-MM}}-<slug>.md`）；事件触发解读件 `reports/{{YYYY-MM}}-<slug>.md`（命名不在标准正则内时 `validate.py` 仅 WARN 不阻断，属预期）。
>
> **继承声明（四层体系）**：本文件 = [通用基座](../../engine/report_templates/prompt-generic-base.md) × [监测报告通用规范](../../engine/report_templates/monitoring-common-spec.md) × [周期更新类型模板（职业就业调研型）](../../engine/report_templates/employment-research/prompt-update-template.md) × [业务专属配置](./business-config.md)。冲突时以本文件为准。

## 运行变量（每次运行前填写）

```
{{CURRENT_DATE}}         = 本次执行日期，格式 YYYY-MM-DD
{{CYCLE}}                = 月度核验 / 季度更新 / 年度复盘 / 事件触发
{{TRIGGER_TYPE}}         = 事件触发时填（新政策 / 修订 / 细则 / 统计发布 / 个人情况变化）
{{PREVIOUS_REPORT_PATH}} = 上期报告路径（如无则空，仅锚定基线）
{{BASELINE_REPORT_PATH}} = reports/{{YYYY-MM}}-<slug>.md
{{REGISTRY_PATH}}        = data/family_parenting_indicator_registry.md
{{OUTPUT_PATH}}          = reports/{{YYYY-MM}}-<slug>.md
{{REPORT_VERSION}}       = 本次版本号，格式 vYYYY.MM.DD
```

固定值（不填，读自业务配置第一节）：`{{REGION}}`、`{{TOPIC}}`、`{{FRESHNESS_PRIORITY}}`、`{{SOURCE_LANGUAGE_RULE}}`、`{{REPO_RAW_URL_BASE}}`。

**任务目标**：完成「核验 → 更新 → 建议 → 可靠性」闭环；新政策先登记发布与生效日期、官方 URL 后才可进入解读；征求意见稿登记但标注「非最终文本，以正式发布为准」；无触发时不启动新解读，台账标注「截至 {{CURRENT_DATE}} 无更新」。

## 一、节拍与触发

三档节拍 + 事件触发见[周期更新类型模板第一节](../../engine/report_templates/employment-research/prompt-update-template.md)。业务触发器清单（`事件 → 受影响模块`）见[业务配置第七节](./business-config.md）：

```
- 家族滞在 扶养人资格 / 扶养审查口径变化 → 带同模块
- 资格外活動許可 周 28 小时 / 个别许可要件变化 → 带同模块
- 出産育児一時金 金额・期限・书类变化 → 养育模块
- 児童手当 / 児童扶養手当 变化 → 养育模块
- 保育所・認定こども園・幼稚園 制度 / 利用料变化 → 养育模块
- 文科省 外国人子女就学 / 日本語指導 政策与统计发布 → 养育模块
- 国際結婚 / 離婚・親権 / 相続 法规与手续变化 → 家庭事件模块
- 定住者 / 特定活動 衔接要件变化 → 长期模块
- 世帯年収 / 扶养控除 / 第 3 号被保险者口径变化 → 家庭经济模块
- 08 / 10 / 15 / 07 最新报告「已修正事实清单」追加 → 对应文档回写
```

## 二、项目专属硬性约束

1. **官方原文铁律**：媒体转述仅作线索；引用逐条附官方原文 URL 与版本日期。
2. **结论边界**：不构成法律意见或税务意见；应对建议标「建议」；歧义条款多解并列。
3. **术语口径**：家族滞在 ≠ 特定技能 1 号带同；扶养要件 ≠ 收入证明口径；包括许可 ≠ 个别许可；保育所 ≠ 認定こども園 ≠ 幼稚園；出産育児一時金 ≠ 児童手当 ≠ 児童扶養手当；定住者 ≠ 永住者。
4. **边界纪律**：永住・归化・在留资格制度正文归 08；学制与就学手续正文归 10；分娩就医与保险正文归 15；税制 / 年金 / 扶养控除正文归 07；住民与行政 90 天清单归 14；法规条文深度解读归 09。
5. **交叉验证锚**：08 / 10 / 15 / 07 最新报告 / 登记册只读核对；冲突回官方原文复核，由来源主题主责更新，本主题不得独立回写。

## 三、各模块要点

按[业务配置第 3.2 节](./business-config.md)的结构映射逐模块实例化：

- **带同**：家族滞在扶养人资格、在留期间与扶养人联动、扶养者职业·收入证明清单、资格外活動許可（周 28 小时 / 个别许可）；
- **养育**：出産育児一時金、児童手当、母子 / 父子家庭支援、保育所・認定こども園・幼稚園、入学 / 転校 / 日本語指導；
- **家庭事件**：国際結婚、婚姻届、離婚・親権・戸籍、相続、終末；
- **长期**：定住者路径、世帯年収、永住接口（只读引用 08）。

> 若本期按九节骨架重排：九节标题逐字继承基线（或经批准的骨架），不得增删节或调整顺序；重排须在[业务配置](./business-config.md)版本记录留痕。

## 四、基线锚定与防回退

- 读取 `{{PREVIOUS_REPORT_PATH}}`（如无则空）与 `{{BASELINE_REPORT_PATH}}`，继承结构、口径裁决与全部已核实结论。
- 逐条继承「已修正事实清单」（以来源主题最新报告文首为单一事实源），产生修正后追加（格式见[通用基座第五节](../../engine/report_templates/prompt-generic-base.md)）；严禁重新引入已被推翻的说法；无来源不得入清单。
- 上年趋势判断逐条复判，原文保留；不得删除或改写上年判断。

## 五、追踪表与登记册联动

按[业务配置第八节](./business-config.md)的 12+1 项追踪指标逐项核对并填写「是否更新」；运行前从 `{{REGISTRY_PATH}}` 读台账 → 增量登记 / 状态变更 → 运行后回写。产出数据变更摘要（覆盖全部追踪项）与待复核清单；未核实项单列「待复核清单」。prompt 模板内不填活值。

## 六、执行方式（建议）

1. 原文回溯先行：完成官方原文登记（URL、版本日期、文本完整性）后才启动逐条解读子代理。
2. 主代理读取 `{{BASELINE_REPORT_PATH}}` 做框架对齐，继承已修正事实清单，应用第三节要点。
3. 与现行制度冲突的解读须并列新旧对照；无法核实项单列「待复核清单」。
4. 回写报告与登记册；如需 HTML，运行 `python engine/tools/md2html.py` 重新生成并运行 `python engine/tools/lint_reports.py` 校验。

## 七、渲染与交付

- 交付格式：md 源稿；季度 / 年度报告含顶部九锚点导航（`.report-nav`），`.nav-url` = `{{REPO_RAW_URL_BASE}}` + `/reports/{本期文件名}`。
- HTML 须通过 `lint_reports.py` 标签配对校验。
- 基线报告常驻 `reports/` 顶层不归档；解读件按保留策略执行（年度复盘保留 5 期，超出移入 `reports/archives/`）。

## 八、质量自检（通用清单之外的本主题专属项）

- [ ] 全部引用回溯官方原文并附 URL；零媒体转述直引
- [ ] 政策台账增量 / 状态变更已回写；prompt 模板无硬编码活值
- [ ] 新旧制度对照完整；歧义条款多解并列
- [ ] 家族滞在 / 带同、包括许可 / 个别许可、保育所 / 認定こども園 / 幼稚園、出産育児一時金 / 児童手当 / 児童扶養手当、定住者 / 永住者未混用
- [ ] 与 08 / 10 / 15 / 07 最新报告 / 登记册交叉验证一致，未越界回写
- [ ] 建议章与事实分离；不构成法律意见 / 税务意见声明保留
- [ ] 追踪表 12+1 项均已核对并填写「是否更新」
- [ ] `{{REGISTRY_PATH}}` 已读已写，变更摘要与登记册一致
- [ ] 数据变更摘要 + 待复核清单已产出

## 落盘后审计（提交前必做）

落盘后依次运行 `python engine/tools/audit_preflight.py --report <报告相对路径>`、`python engine/tools/audit_check.py --report <报告相对路径>`，修正全部 P0/P1 后执行 `python engine/tools/audit_pipeline.py --submit --report <报告相对路径>` 提交审计（未通过初审不得合并）。
