## 研究边界档案（基线首建，周期运行复核）

### 研究对象边界

- **含**：中国侧行前（护照、户籍、档案、社保、居住证、健康证、无犯罪记录、公证认证、翻译件）与归国衔接（驾照转回、学历认证、档案转递、社保接续、户籍恢复），以及横切（领事保护）。
- **不含**：日本侧离日执行（→ 16）；在留资格 / 永住 / 归化 / 再入国制度正文（→ 08）；对外劳务合作与中介合规（→ 17）；赴日落地与住房 / 保险（→ 14）；日本驾照 / 学历（→ 10 / 01）；法规条文深度解读（→ 09）。

### 两段分层

- **行前（中国侧）**：护照、户籍、档案、社保、居住证、健康证、无犯罪记录、公证认证、翻译件。
- **归国（回国后衔接）**：驾照转回、学历认证、档案转递、社保接续、户籍恢复。
- **横切**：领事保护 / 使领馆联络口径 / 海外公民登记。

### 主体清单与入选标准

- **中央机构**：外交部（含驻外使领馆） / 国家移民管理局 / 公安部 / 商务部 / 教育部留学服务中心 / 人社部 / 国家卫健委 / 司法部 / 国务院。
- **地方机构**：省级人民政府、公安派出所、公共就业和人才服务机构、社保经办机构、公证机构、翻译机构。
- **入选标准**：官方发布页可回溯；每条附官方原文 URL 与版本日期。

## 维护约定

- 活值统一维护于本登记册；prompt 模板内不填活值。
- 台账修改采用增量方式：保留历史值，不覆盖。
- 报告层补充与台账更新严格区分。
- 无官方依据的金额 / 期限 / 要件统一写「⚠ 待核实」，不补值、不外推。
