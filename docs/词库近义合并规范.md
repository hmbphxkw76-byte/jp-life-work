# 词库近义 / 近重复合并规范

> 版本：v1.0（2026-11-18，P2-6）。适用：`engine/vocabulary/data/*/terms.md`。
> 配套工具：`engine/vocabulary/script/vocab_near_check.py`（扫描）、`vocab_tool.py`（校验 / 导出）。

## 一、目的

词库在持续导入中会产生**近义 / 近重复**词条（如 `送金` 与 `国際送金`），
造成检索命中分散、别名冗余与口径漂移。本规范定义「疑似对」的判定口径、
合并流程与闭环判据，使去重从「事后人工清理」变为「可复扫的闭环」。

## 二、判定口径（可机读）

`vocab_near_check.py` 对**同主题内的规范词条**两两比较，命中任一即列为疑似：

- **包含关系**：一条是另一条的子串（长度 ≥ 2），如 `送金` ⊂ `国際送金`。

**不采用**编辑距离类规则：会把「大型 / 中型」「特定技能 1 号 / 2 号」这类
反义或并列对误报为近义，不符合「可合并」口径。别名不参与两两比较
（别名已归一到规范词条，别名两两比较属噪声）。

### 裁定口径（2026-11-18 补充）

包含关系**不等于**同义。人工裁定按下列子类归档，**一律不合并**：

| 子类 | 判据 | 例 |
|---|---|---|
| 保留·衍生概念（下位） | 长词 = 短词 + 泛化尾（費用/制度/申告/計画/基準/手続/資格/試験/白書/市場…） | `車検` / `車検費用`、`物流` / `物流成本` |
| 保留·限定变体 | 长词 = 限定前缀 + 短词（国際/特定/大型/中型/準…） | `中型免許` / `準中型免許` |
| 保留·包含关系（不同对象） | 短词位于长词中部/尾部，且非上述两类 | `大学` / `大学院`、`防災` / `防災庁` |

仅当两条**指同一对象且可互相替代**时才合并。首轮裁定（226 对）**未发现此类**，
详见 `反例与近义裁定清单-2026-11-18.md`。

## 三、合并流程（人工裁定）

1. **取清单**：运行 `python engine/vocabulary/script/vocab_near_check.py`，
   得到 `engine/vocabulary/data/near-dup-report.json`（疑似对列表）。
2. **逐对裁定**：对每对判定为「合并」/「保留」/「待查」：
   - 语义同一、仅表述差异 → 合并（保留信息量更大者为规范词条，另一条别名并入）；
   - 语义不同（包含但不同义，如 `車検` 与 `車検費用`）→ 保留，不合并；
   - 拿不准 → 标「待查」，登记到主题 `prompts/business-config.md` 的待裁定清单。
3. **执行合并**：编辑 `terms.md`（规范词条 + 别名），运行
   `python engine/vocabulary/script/vocab_tool.py verify`（重复 / 空值 / 分类 / ID 前缀 /
   条目数下限）与 `sync_vocab.py check`。
4. **刷新导出**：`vocab_tool.py export` + `vocab_tool.py index`，提交变更。
5. **复扫**：重新运行本工具，确认疑似对已减少（合并项消失）。

## 四、闭环判据

- `vocab_near_check.py` 退出码 0（无疑疑似）或 2（有疑似，需裁定）；退出码 1 为扫描失败（阻断）。
- 已裁定「保留」的对应在规范附录登记理由，避免反复扫描重复讨论。
- CI 词库校验（`validate.yml`）接入本工具，新增疑似对时给出告警。
