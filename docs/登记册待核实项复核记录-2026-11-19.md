## 六、来源粒度决策（2026-11-19）

针对「部分核验 → 具体官方页」的深化，经勘察后决策如下：

**结论：不做批量自动深化；只落地可核验的官方页。**

| 方案 | 评估 | 决策 |
|---|---|---|
| A 批量自动匹配（机构名 → 报告来源页） | 已证不可靠：报告用简体中文机构名（厚生劳动省/总务省/法务省），词条用日文，匹配大量失败；已加简→日归一，仍只有部分命中 | **弃用**（仅用于发现命中，不直接批量写盘） |
| B 逐条 web 搜索/抓取 | 检索结果嘈杂（多为非官方页、百度百科、微信公众号），官方细页命中率低、成本高 | **仅用于抽验**，不作批量来源 |
| C 仅落地可核验官方页 | 准确、可审计、零错配风险 | **采用** |
