# 在留法规框架

> 信息核对日期：2026-11-11。个人只需精通与自己在留资格直接相关的部分，其余建立索引即可。签证实务 → [../01-visa-immigration](../01-visa-immigration/00-index.md)。

## 一、与本项目相关的法律栈

| 法律 | 管什么 | 对个人的具体影响 |
|---|---|---|
| **出入国管理法（入管法）** | 在留资格、审查、取消、退去强制 | 特定技能要件、永住许可/取消、资格外活动禁止 |
| 職業安定法 | 求职·雇佣介绍 | Hello Work、转职规则 |
| 労働者派遣法 | 派遣劳动 | 司机派遣岗位的法律框架 |
| 貨物自動車運送事業法（货送法） | 运输事业许可与运行体制 | 运行管理者、点呼、运输规则 |
| 労働基準法+働き方改革法 | 工时·工资·解雇 | 时间外上限（→ [../03-career-driver/02](../03-career-driver/02-薪资结构与工时合规.md)） |
| 労働安全衛生法 | 安全管理 | 安全管理者、健康诊断 |
| 道路交通法 | 驾照·运行规则 | 驾照种类、L4 许可（→ [../06-autonomous-automation/02](../06-autonomous-automation/02-法规与许可制度.md)） |
| 自動車損害賠償保障法 | 车辆保险 | 自赔责强制保险 |

## 二、个人必须烂熟的条款（Top 5）

1. **资格外活动禁止**：特定技能 1 号只能从事受入计划书记载业务
2. **连续 3 个月不从事原业务 → 资格取消**
3. **月加班 100h 未满红线**（时间外+休日合计）
4. **住民税/社保滞纳 3 年 → 永住取消事由**
5. **在留卡 14 天地址变更义务**、离日 1 年再入国期限
