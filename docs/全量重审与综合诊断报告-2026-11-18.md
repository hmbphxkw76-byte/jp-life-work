### 2.1 G1 消除信息差

| 指标 | 现状 | 目标 | 差距 | 归因 |

| 主题/报告覆盖 | 21 主题 × 1 期 | 持续周期化 | 仅单期，无历史序列 | 周期体系刚落地（`3fbe546`），第二期未产出 |

| 失效链接 | index 20 / search-index 10 / search JSON 10 | 0 | 长期存在且被测试锁定 | 无引用存在性校验；手工 JSON |
| 术语对齐 | 无核验/置信度字段 | 可分级采信 | 全库不可溯源到 URL | schema 缺字段 |
| 信息差清单 | 2/21 报告；无机器可读清单 | 21/21 结构化 | 缺口不可见 | 模板未强制；无 artifact |

### 2.4 差距归因总览（根因五类）

1. **双轨/漂移**：文档双份（提示词 doc vs 文件）、注册表双份（21 vs 20）、类型计数（13 vs 12）、死链被测试锁定。
2. **载体缺失**：信息差清单、置信度、来源核验、URL 可达性、决策状态等均无机器可读载体。
3. **门禁左移不足**：auto_verify / preflight / registry / decision_log 未进 CI；语义质量无程序化子集。
4. **内容欠账**：新主题 14–20 词条少、无导出、核验项集中；报告单期。
5. **配置硬编码**：决策工具与 pending TOPICS 写死，扩展需改代码。
