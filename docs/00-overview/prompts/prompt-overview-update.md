## 一、主题定位与受众

本主题是全库导航层：维护五阶段路线图（准备入场 → 司机落地 → 管理岗过渡 → 技术扩展 → 长定居/永住）的状态视图与阅读入口。受众 = 项目作者本人。更新对象为路线图阶段完成度与跨主题索引，**不承载原始事实数据**（事实归属各编号主题）。

## 二、来源优先级实例化

本主题极少直接引用外部数据；引用时继承被链接主题的来源规则。内部链接优先：monitors-japan/ssw-driver-logistics/reports/ 最新版监测报告、各主题 00-index.md。

## 三、事件触发器表

```
- 任一 docs/{NN-topic}/ 主题完成一轮动态更新 → 文档 00-index/路线图状态同步
- monitors 监测报告发布新版本（版本号变化） → 路线图"行业态势"状态刷新
- 制度重大变化（特定技能/育成就劳改定） → 阶段 1/2 关键动作清单复核
```
