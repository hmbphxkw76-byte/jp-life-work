## 一、主题定位与受众

个人财务规划库：收入结构、生活成本、税务社保年金、长期财务规划。个人数据（实际收支）为自记录口径，宏观行情为官方口径，两者不得混算。

## 二、来源优先级实例化

① 総務省統計局（stat.go.jp 消费物价、家計調査）、厚生労働省（每月勤労統計）、国税庁（税率）、日本年金機構 ＞ ② 中国国家统计局（工资对比输入——项目指定例外）、中国外汇交易中心（chinamoney.com.cn 汇率中间价）＞ ③ 地域自治体生活成本数据 ＞ ④ 比价门户（预期指标）。

## 三、术语口径区分

税引前月収 ≠ 手取り（社保・税后）；家計調査（世帯）≠ 勤労統計（事業所）；中日对比须注明汇率日与口径。

## 四、事件触发器表

```

- 个人收支月度结算 → 01/02/04
```
