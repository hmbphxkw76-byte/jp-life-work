## 三、对齐验证标准

### 全局标准（所有主题统一）

1. **覆盖完整**：主题内所有「部分核验」门户条目 100% 处置（升级 / 保留 / 纠错），无遗漏。
2. **来源合规**：升级目标须为官方域名（`.go.jp`、省厅、官方机构、外国官方机构）；非政府机构无单页覆盖则保留门户。
3. **实取证据**：每条升级 URL 须经 `web_fetch` 成功且页面切题（记录页面标题）。
4. **不动标签**：不改核验状态、不改置信度。
5. **留痕**：`engine/vocabulary/data/<主题>/imports/2026-11-19_核验深化.md`（仅变更行）+ 证据包。
6. **自检**：`vocab_tool check --topic <主题>` 0 错误 / 0 警告；导出已重生成。
7. **闭环**：提交到本组分支；主会话合并后该主题全量门禁通过。

### 每主题闭口证据包（`docs/核验证据包-2026-11-19/<主题>.md`）

- **A 覆盖表**：`ID | 词条 | 处置(升级/保留/纠错) | 目标URL | 证据/理由`（主题内门户条目全量）；
- **B 升级证据**：目标 URL 的 `web_fetch` 成功记录 + 页面标题；
- **C 保留理由**：逐条（无单页覆盖 / 非政府机构 / 宽泛术语）；
- **D 纠错记录**：原 URL → 新 URL + 错配原因；
- **E 自检结论**：`vocab_tool check` 输出行；
- **F 提交短码与文件清单**。
