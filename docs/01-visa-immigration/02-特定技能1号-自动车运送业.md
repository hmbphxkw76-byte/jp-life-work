# 特定技能 1 号：自动车运送业分野（司机路线核心文件）

> 信息核对日期：2026-11-11。依据 ISA 官网「自動車運送業分野」页（2026-10-09 更新确认）及特定技能综合支援站点中文页。

## 一、业务范围

事业用（营业用）车辆的驾驶及相关业务：

1. 事业用汽车（**卡车**）驾驶及驾驶相关各类业务
2. 事业用汽车（**出租车**）驾驶及驾驶相关各类业务
3. 事业用汽车（**巴士**）驾驶及驾驶相关各类业务

职位说明书：https://www.moj.go.jp/isa/applications/ssw/10_00179.html

**本项目定位**：以卡车驾驶（配送司机/仓储运输）为主路径，门槛最低（N4 即可）。

## 二、接收上限

- 自动车运送业分野 5 年（2024 年 4 月～2029 年 3 月）接收上限：**24,500 人**
- 后续是否延长需跟踪国交省/ISA 公告 → 记入 [08-政策更新日志](08-政策更新日志.md)

## 三、人才基准（合格要件）

### 技能水平

| 岗位 | 要求 |
|---|---|
| 卡车 | 汽车运送业分野特定技能 1 号评价试验（卡车）+ **第一种驾驶执照** |
| 出租车 | 评价试验（出租车）+ **第二种驾驶执照** + 新任驾驶员研修 |
| 巴士 | 评价试验（巴士）+ **第二种驾驶执照** + 新任驾驶员研修 |

### 日语能力

| 岗位 | 要求 |
|---|---|
| 卡车 | JFT-Basic（国际交流基金日本语基础测试）或 JLPT **N4 以上** |
| 出租车 | JLPT **N3 以上** |
| 巴士 | JLPT **N3 以上** |

### 驾照注意事项（重要）

- 考试受验时只需持有有效的日本或外国驾照（含中国驾照，需通过外免切替或在国内考取）
- 在日本实际从事事业用驾驶，需把外国驾照**切换为日本驾照（外免切替）**或在日本重新考取
- 第一种驾照 AT 限定即可，但入行后视车种可能需要 MT 及限定解除
- 出租车/巴士需第二种驾照（难度更高），初期不建议作为第一跳板

## 四、受验资格（评价试验，ClassNK Portal）

依据 ClassNK 考试门户（https://sswt-portal.classnk.or.jp/area?tab=3）：

1. 受验日满 **17 岁**（印度尼西亚考场为 18 岁）
2. 持有有效的日本或外国取得的自动车驾驶执照
3. 无日本国籍
4. 在日本国内受验时，须持有在留资格
5. 退去强制令书等合规限制不适用者

### 考试构成（卡车）

- **知识试**：50 题笔试，**45 题以上正确**为合格（运转经历、知识、技能、视力等检查构成）
- **技能试**：考试场实技运转
- 语言支持：笔试提供多语种（含中文），报名与考场信息以 ClassNK Portal 为准

## 五、接受机关侧要件（就业前需确认雇主满足）

- 企业须持有国土交通省「特定技能受入计划书」的认定（分野主管：国交省）
- 雇佣契约需满足与日本人同等的工资待遇、遵守货物运输/劳动相关法规
- 企业需履行 1 号外国人生活支援义务（住宅、生活 Orientación、定期面谈等），可委托登录支援机关

## 六、申请流程概览

1. 通过评价试验 + 取得日语资格（本文件第三节）
2. 与雇主签订雇佣契约
3. 雇主向国土交通省申请「特定技能 1 号受入计划书」认定
4. 本人申请在留资格认定证明书（海外申请）或在留资格变更/更新（国内）
5. 领取签证/更新在留卡

详细材料清单 → [04-申请流程与材料](04-申请流程与材料.md)

## 七、在留期间与上限

- 每次在留期间：1 年/6 个月/4 个月
- 自动车运送业 1 号总在留上限：**5 年**
- 满 5 年前需规划 2 号移行（→ [05-特定技能2号与升级路径](05-特定技能2号与升级路径.md)）
