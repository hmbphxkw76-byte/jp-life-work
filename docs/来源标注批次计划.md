## 一、背景与目标

「语义目标完成度 36.7%（不阻断）」。

**目标**：制定 36.7% → 100% 的批次计划，逐报告补全来源标注，并留痕完成度。

**口径**：来源标注判定复用 `info_quality_check` 的 C-07 规则（URL / 「来源」字样 /
登记册指针 / 手册指针 / Markdown 链接；纯交叉引用括号不计；机构标签须同行存在 URL / 「来源」字样）。

- 不改动程序化门槛（20%）与 C-07 判定规则；只提升内容覆盖。

## 五、每期执行步骤

1. 逐报告核对事实单元（段落 + 表格行），补来源标注；无法核实的写「未标注 / 待补来源」，不伪造。
2. 走报告交付协议：`md2html.py` → `audit_preflight` → `audit_check` → `audit_pipeline --submit`。
3. 跑 `python engine/tools/info_quality_check.py --check`，记录来源标注覆盖率。
4. 回填完成度（见第六节）。

## 六、完成度回写口径

- **全库完成度** = `sourced_all / subs_all`，与 `info_quality_check --check` 的「来源标注覆盖率」同口径；
- **逐报告完成度** = 该报告 `sourced / subs`（`check_report` 口径）；
- 每期完成后：
  - 回填本文档「进度记录」表；
  - `assessment-ledger.md` 由 `info_quality_check --apply` 生成，作为留痕载体；
  - 台账 `pending-verification.json` 由 `pending_verification.py` 刷新（若涉及登记册核验项）。
