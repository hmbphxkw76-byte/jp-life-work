# 现场经验积累清单

> 对应阶段 2（积累现场经验）→ 阶段 3（可量化成果）。原则：**每项经验都留下可写进简历和审查材料的记录**。

## 一、四大现场能力域

### 1. 装卸与货物处理

- [ ] 7 种主要搬运姿势与腰保护（培训后自查）
- [ ] 托盘作业：叉车观察（资格另考：フォークリフト运転技能讲习）
- [ ] 冷链装卸：温度带知识（冷藏 0–10°C / 冷冻 −15°C 以下）与开门时间控制
- [ ] 破损率记录：月度破损件数归零记录

### 2. 调度与配车（转管理岗的种子技能）

- [ ] 理解配车表的构成：车型/司机的匹配逻辑
- [ ] 跟踪排班影响因素：运休、客户指定时间、法定驾驶时间
- [ ] 用日语读懂并口头确认运行指示書全部字段

### 3. 客户对接

- [ ] 搬入寒暄流程（「お世話になっております」→ 伝票确认 → 置き位置确认）
- [ ] 拒收/延迟的现场应对话术（不擅自承诺）
- [ ] 每月记录 1 个"客户好评"实例

### 4. 异常处理

- [ ] 完成 1 次以上的异常事件完整处理并写报告（事故未遂/货损/车辆故障/天气停运）
- [ ] 建立个人异常处理 checklist（报告对象→顺序→证据）

## 三、技能升级路径时间表（阶段 2 → 3）

| 入职后 | 目标 |
|---|---|
| 0–6 月 | 独立执行固定路线 + 安全实绩零瑕疵 |
| 6–12 月 | 多路线/多客户适配；开始帮带新人和实习司机 |
| 12–24 月 | 申请追加资格（フォークリフト/危険物乙4/けん引视需要）；JLPT N3 |
| 24 月+ | 争取进入配车/教育辅助角色；JLPT N2 启动 → 转入 [../monitors-career-logistics](../monitors-career-logistics/) |
