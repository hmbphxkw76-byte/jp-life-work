## 01 司机岗位全景

> 信息核对日期：2026-11-11。对应路线图阶段 2（司机岗位落地）。

### 一、岗位类型谱系

| 类型 | 车辆 | 特点 | 新人难度 |
|---|---|---|---|
| 路线配送（ルート配送） | 轻型～普通（2t 前后） | 固定客户、每日同路线，家庭配达/法人配达 | ★ 最适合入场 |
| 仓库内配送/场内运输 | 托盘车、2t | 仓库与厂区间短驳，节奏稳定 | ★ |
| 一般区域配送 | 普通～中型（2–4t） | 多点配送、要搬运装卸 | ★★ |
| 冷链配送（冷蔵/冷凍） | 冷藏冷冻车 | 生鲜/医药，时限严、温控管理责任重 | ★★ 薪资略高 |
| 中型·大型干线 | 中型(4–11t)/大型(11t+) | 长距离、夜间多、体力要求高 | ★★★ 薪资最高 |
| 特殊车辆 | 牵引（トレーラー）、罐车、危险品 | 需追加资格（けん引/危険物乙4 等） | ★★★★ |

**入场策略**：从特定技能 1 号（卡车）入境 → 先做路线配送/仓库关联岗位 → 1–2 年内视条件向中型/冷链/干线升级。

### 二、车种与驾照对应（2024 年新制度后）

| 车牌种类 | 对应车辆 | 备注 |
|---|---|---|
| 普通免许 | 总重 3.5t 未满（货物 2t 未满） | 2024-05 起新设**準中型**，普通范围收窄 |
| 準中型免许 | 总重 3.5–7.5t | 新制度下进入中型世界的第一张牌 |
| 中型免许 | 总重 7.5–11t | 需 21 岁+驾龄 2 年（取得時点） |
| 大型免许 | 11t 以上 | 需 21 岁+驾龄 3 年（取得時点） |
| 第二种免许 | 载客（出租/巴士） | 特定技能出租车/巴士路径才需要 |

- 特定技能 1 号考试：第一种驾照即可；AT 限定需在期限内解除或换 MT
- 外免切替（中国驾照）：普通免许可换；准中/中型需另考
- 职业驾驶资格=驾照 + 雇主实施的**事業用自動車運転者講習**（新任驾驶员讲习）

### 三、一天的工作流（典型路线配送）

```text
出勤 → 点呼（酒测/健康确认/运行指示） → 日常点検 → 出库
→ 配送循环（積込→搬入→伝票受领） ×N → 归库 → 后处理（伝票整理/清扫/充电加油）
→ 退勤（点呼确认）
```

- 点呼（てんこ）：每次出车前后的法定程序（酒测、健康、指示传达）——运行业务的中枢制度
- 日常点検：出车前检查项目 60+ 项，记录入点检表

### 四、分野内的职业深化方向（对应阶段 3）

| 方向 | 关键能力 |
|---|---|
| 冷链专家 | 温度管理记录、医药/生鲜 GSP 意识 |
| 干线/大型 | 长距离耐力、车检/油耗管理 |

## 02 薪资结构与工时合规

> 信息核对日期：2026-11-11。对应阶段 1（整理岗位条件）与阶段 2（记录实际条件）。

### 一、薪资水平（2026 年市场数据）

- 卡车司机平均年收：**约 430 万日元**（月收约 27 万 + 年间赏与约 106 万），高于全职业平均
- 求人市场示例：大型干线 月给 35–43 万；一般配送 月给 25–33 万；冷链/危险品附加 2–5 万
- 特定技能 1 号硬性要求：**工资与日本人同等以上**——面试时拿同岗位日本员工待遇基准对照

### 二、工资构成拆解（看 offer 必看项）

| 项目 | 说明 | 警惕点 |
|---|---|---|
| 基本给 | 固定部分 | 占比过低=靠加班凑收入 |
| 乗務手当/出勤手当 | 按乘务日数/出勤次数 | 请假即减收 |
| 时间外手当 | 加班费（1.25 倍起） | 是否按法定计算、有无"固定残業代" |
| 早朝/深夜手当 | 22–29 时 1.25 倍以上 | 夜间干线的主要收入来源 |
| 积込/积下ろし手当 | 装卸费 | 有无——影响实际劳动强度 |
| 赏与 | 年 1–4 个月不等 | 特定技能初期公司是否同等待遇 |
| 各类保险 | 雇保/健保/厚生年金 | 必须加入（永住证据链） |

**年收换算公式**：（基本给+诸手当）×12 + 赏与 − 欠勤减额。

### 三、2024 年（令和 6 年）劳动合规新规——"物流 2024 年问题"

2024-04-01 起，自动车运送业全面适用働き方改革：

| 规制 | 数值 |
|---|---|
| 时间外劳动上限（原则） | **月 45 小时 · 年 360 小时** |
| 特别条项（36 协定）上限 | **年 960 小时** |
| 时间外+休日劳动合计 | **月 100 小时未满**、2–6 个月平均 80 小时以内 |

来源：厚生劳动省ポータサイト https://driver-roudou-jikan.mhlw.go.jp/truck/notice

**对个人的影响**：

1. 加班收入天花板下降（新规前月 100h+ 加班的公司很多）——工资谈判时看公司**是否已适应新规**（适应差的公司可能转嫁为倒班增加或大量离职）
2. 运力不足 → 行业结构性缺人 → **对外国人司机反而是长期利好**（缺员推算 2030 年约 14 万人）
3. 月 100h 未满是红线：超过说明公司违法或制度混乱，入职前必须问清

### 四、入职前必问清单（面试验证用）

- [ ] 平均月加班时间？最近 3 个月实绩？
- [ ] 36 协定特别条项是否签订？年加班上限多少？
- [ ] 固定残业代制还是全额实算制？
- [ ] 休日：月 several 回？运输行业常见的"シフト休"如何安排？
- [ ] 赏与・昇给实绩（前 3 年）？
- [ ] 特定技能员工现有几名？支援体制（自家/登录支援机关）？
- [ ] 社保（健保+厚生年金）加入？——从第一天起影响永住证据链

### 五、红牌信号（出现即谨慎）

- 月给数字漂亮但"乗務手当"占比 >50% 且无加班实算
- "残業は自己申告制"（=不给加班费的话术）
- 无厚生年金（只有国民年金）→ 违法+毁永住积累
- 高离职率（面试可问"先辈特定技能员工现在几人在职"）

## 03 安全规范与现场制度

> 信息核对日期：2026-11-11。对应阶段 2（熟悉安全规范、劳动法规）。安全记录直接决定续更、2 号移行与职业升级。

### 一、法定运行管理制度（货运）

| 制度 | 内容 | 个人要点 |
|---|---|---|
| **点呼** | 出车前后由运行管理者进行指示+确认 | 酒气检查（アルコールチェック）必须配合；拒检=重大违规 |
| **运行指示書** | 记载行车路线、时刻、载货 | 必须携带并按其运行 |
| **驾驶时间纪录（運行記録）** | 每日记录驾驶开始/结束、行驶距离 | 数字化（デジタル走行記録計）公司为主 |
| **连续驾驶休息** | 4.5h 连续驾驶后至少 30min 休息 | 长途干线关键规则 |
| **定期训练** | 每年法定 5 项训练（安全/省燃费等） | 出席率记入个人档案 |
| **日常点检** | 出车前 60+ 项检查 | 发现异常必须报告，禁止"带病出车" |

### 二、事故与异常处理流程

1. 事故发生：确保安全 → 救护优先 → 报警（110）→ 联系公司运行管理者 → 不可自行与对方"私了"
2. 车辆异常：立即靠边 → 报告 → 等指示（自行处置可能违反点呼制度）
3. 货物异常（破损/短缺/温度异常）：拍照 → 保留传票 → 当日报告——冷链温度异常是高责任场景
4. 交通违规：点数制（6 点内停驾照 courses），特定技能者重大违规直接影响在留更新

### 三、饮酒与药物（红线）

- 酒测：出车前后各一次，**检出即点呼不通过 → 当日停驾**
- 前夜饮酒次日晨检出（残留酒精）也是事故实绩高发点——当天的酒当天止
- 特定技能者因酒精/药物事故 = 几乎必然失去在留资格

### 四、恶劣天气与季节性风险

| 场景 | 要点 |
|---|---|
| 冬季积雪（北陆/东北/北海道） | 冬用轮胎、链子携带义务地区、排雪期运费变化 |
| 台风（7–10 月） | 停运判断权在公司，个人不硬闯 |
| 夏季高温 | 冷链货物风险、车厢内热中症 |

### 五、入职初期 90 天安全路线图

```text
W1–2   点呼/点检/传票流程背熟，跟乘先辈路线
W3–6   独立短路线，每日复盘：急刹/急转/礼让记录
W7–12  全路线独立，学习异常处理与客户对应
```

安全实绩（无事故无违规月数）是阶段 3 管理岗评估与 2 号移行审查的正面材料。

## 05 求职渠道与简历面试

> 对应阶段 1（准备简历、资格材料、面试话术和求职渠道）。

### 一、求职渠道矩阵

| 渠道 | 特点 | 优先级 |
|---|---|---|
| **特定技能专门中介/登录支援机关** | 与接受企业绑定，包支援义务，风险最低 | ★★★ 主渠道 |
| Hello Work（ハローワーク） | 公共职介，契约·待遇透明，部分招外国人 | ★★ |
| Indeed Japan / 求人ボックス | 汇总检索，筛"特定技能 可"关键词 | ★★ 情报源 |
| トラバイト等运输专门转职站 | 司机岗位全、薪资行情直观 | ★★ |
| 行业团体（全日ト協各県支部等）介绍 | 信度高，小企业多 | ★ |
| 直接应聘地方中坚运输企业官网 | 竞争小，地方生活成本低 | ★ |

筛选原则：**只投能做"特定技能受入计划书认定"的企业**（未认定企业无法雇特定技能者——让对方出示认定证明或说明申请进度）。

### 二、地域选择策略（影响收入与生活）

| 因素 | 建议方向 |
|---|---|
| 运输需求 | 大都市圈岗位多但竞争/物价高；地方（北关东、东海、九州）缺人更明显 |
| 薪资 | 干线/大型岗位：地方反而高（月 35 万+常见） |
| 生活支持 | 选有特定技能前辈/多文化对应的企业聚集地（爱知、埼玉、群马、福冈等） |
| 冬季 | 避免初入行就选豪雪地带（驾驶风险） |

### 三、简历（履歴書/職務経歴書）要点

- 履歴書：JIS 规格手写或打印均可，照片正装，全角日期，学历职历从新往旧不空白（空白期写「日本語学習」等）
- 职务经历书：突出**驾驶经历（车种/里程/事故率）、装卸/仓库经验、资格（驾照/试验合格）**
- 中文驾照驾龄换算为「運転歴○年」并注明车种
- 附上：ClassNK 合格证明、JLPT/JFT 成绩（复印件）

### 四、面试高频问题与回答方向

| 问题 | 回答方向 |
|---|---|
| なぜ日本で？なぜ運送業？ | 物流职业规划（司机→管理→技术）+ 已考取的试验合格=行动证明 |
| 運転歴・車種？ | 实话+车种对应表（→ [01-司机岗位全景](#01-司机岗位全景)） |
| 夜勤・長距離できる？ | 诚实回答体能边界，给出意向区间 |
| 日本語は？ | 当场演示：点呼应答/传票确认/事故报告三段话术 |
| 給与の希望？ | 参考市场数据报价区间，问清构成（→ [02-薪资结构与工时合规](#02-薪资结构与工时合规)） |

### 五、契约审查清单（签约前逐项核对）
