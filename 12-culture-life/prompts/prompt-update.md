# 日本 · 文化与生活 · 周期更新提示词（职业就业调研型）

> **用途**：覆盖职业就业调研型**三档节拍**——月度核验轻运行 / 季度主更新 / 年度复盘，以及重大事件触发器命中时的模块升级。可直接复制，替换顶部变量后提交给 AI 执行。
> **产出**：季度 / 年度报告落盘 `{{OUTPUT_PATH}}`（`reports/{{YYYY-MM}}-<slug>.md` 或 `reports/{{YYYY-MM}}-<slug>.md` + 同名 HTML）；月度轻运行只更新登记册，不重写报告；事件触发插刷件 `reports/{{YYYY-MM}}-<slug>.md`（命名不在标准正则内，validate 仅 WARN 不阻断，属预期）。
>
> **继承声明（四层体系）**：本文件 = [通用基座](../../engine/report_templates/prompt-generic-base.md) × [监测报告通用规范](../../engine/report_templates/monitoring-common-spec.md) × [周期更新类型模板（职业就业调研型）](../../engine/report_templates/employment-research/prompt-update-template.md) × [业务专属配置](./business-config.md)。冲突时以本文件为准。

## 运行变量（每次运行前填写）

```
{{CURRENT_DATE}}         = 本次执行日期，格式 YYYY-MM-DD
{{CADENCE}}              = 月 / 季 / 年（按本次节拍填写）
{{PREVIOUS_REPORT_PATH}} = 上一期同周期报告路径（首期季度为空，仅锚定基线）
{{BASELINE_REPORT_PATH}} = reports/{{YYYY-MM}}-<slug>.md
{{REGISTRY_PATH}}        = data/culture_life_indicator_registry.md
{{OUTPUT_PATH}}          = reports/{{YYYY-MM}}-<slug>.md 或 reports/{{YYYY-MM}}-<slug>.md
{{REPORT_VERSION}}       = 本次版本号，格式 vYYYY.MM.DD
```

固定值（不填，读自业务配置第一节）：`{{REGION}}`、`{{TOPIC}}`、`{{FRESHNESS_PRIORITY}}`、`{{SOURCE_LANGUAGE_RULE}}`、`{{REPO_RAW_URL_BASE}}`。

**任务目标**：完成「核验 → 更新 → 建议 → 可靠性」闭环；按节拍实例化（见第一节）；继承已修正事实清单；无触发且窗口未到时不启动，不得虚构变化。

## 一、节拍与触发

三档节拍设计见[周期更新类型模板第一节](../../engine/report_templates/employment-research/prompt-update-template.md)：

| 节拍 | 定位 | 触发条件 | 输出 |
|---|---|---|---|
| 月度 | 核验型轻运行：只核验登记册活值与触发器状态，不重写报告 | 常规月度窗口；**无触发不启动新报告**，仅在登记册标注「截至本次日期无更新」 | 登记册更新记录；命中触发器时升级为季度重点更新 |
| 季度 | 主更新节拍：全模块刷新 | 每季度窗口，或任一重大事件触发器命中 | 完整九节更新版报告（结构逐字继承基线） |
| 年度 | 复盘：预测对照 + 清单复审 + 路线图重排 | 每年固定窗口 | 年度版报告 + 登记册年度复盘留痕 |

业务触发器清单（`事件 → 受影响模块`）见[业务配置第七节](./business-config.md)：

```
- 劳动文化相关制度变化（联动 09-politics-law） → 01 职场文化与人际
- 生活制度变化（在留卡手续、年金手续等，联动 08-visa-immigration） → 02 生活指南与适应
- 个人新生活经验沉淀 → 02
- 医疗保险制度 / 自付比例 / 高额疗养费上限变化 → 03 医疗与健康
- 劳灾保险给付口径、工伤申领流程变化 → 03
- 体检 / 健诊制度（特定健診、ストレスチェック义务）变化 → 03
- 賃贷保护法制 / 家賃补给等住宅施策变化 → 04 住房与安家
- 多文化共生施策、外国人支援体制变化 → 05 社会融入与社群
- 大规模灾害 / 防灾气象预警体系变化 → 02 防灾小节（六）
```

## 二、项目专属硬性约束

1. **受众与结论边界**：面向在日本从事货运司机工作、需要职场文化适应与日常生活落地的读者；经验类内容须与制度类内容分离存放并标注个案。
2. **来源语言规则**：制度类须日文官方原文；经验类不限（标注为个案）。
3. **口径纪律**：法规义务 ≠ 职场惯例；健康保险 ≠ 国民健康保险；敷金 ≠ 礼金；「先輩後輩」等文化描述标注为一般化观察；习惯性做法不得表述为法定要求。
4. **边界纪律**：维权流程链接 09、地域选择与生活成本链接 13 / 07、税费社保年金链接 07、现场安全制度链接 02、在留手续链接 08；本主题只写生活制度 + 手续 + 适应框架。
5. **交叉验证锚**：保险费率、自付上限、给付比例等活值只入 `{{REGISTRY_PATH}}`，正文只写制度结构与查询入口；租金行情活值归 13 / 07 登记册；工伤现场处理与事故报告流程以 02-career-driver 03 章为准。

## 三、各模块更新要点

按[业务配置第 3.2 节](./business-config.md)的结构映射逐模块实例化：

- **职场文化与人际（对应岗位技能要求）**：报联相 / 挨拶 / 5S、上下关系与沟通、评价体系、跨文化生存策略；更新现场观察沉淀（个案标注）；动态获取相关调查 / 官方指引；保持主题框架。
- **生活指南与适应（对应就业落地路径建议）**：落地 2 周手续清单、生活基础设施、安全习惯、心理健康与社群、防灾与应急；动态获取在留手续、生活制度官方现行流程、防灾气象预警口径；更新个人适应记录（个案标注）；保持清单结构与防灾小节（六）。
- **医疗与健康（对应行业与政策发展趋势 / 数据可靠性与局限）**：健保体系、就医全流程、体检与预防、劳灾保险与工伤、心理健康资源、就医日语最小集；动态获取医疗保险制度与自付口径、高额疗养费上限、マイナ保険証动向、劳灾给付范围、健诊 / ストレスチェック义务；更新就医经验（个案标注）；保持就医流程与就医日语结构。
- **住房与安家（对应就业落地路径建议）**：租房流程与初期费用、保证会社与外国人入住、UR 公营住宅、签约时序与水电煤网开通、退去与敷金清算；动态获取賃贷法制 / 家賃补给等住宅施策、UR 等公营住宅申込口径；更新个人安家经验（个案标注）；保持租房流程与费用结构框架。
- **社会融入与社群（对应行业与政策发展趋势）**：外国人支援体系、多文化共生施策、同乡会与志愿组织参与；动态获取多文化共生施策（総務省 / CLAIR）、地域国際化協会窗口信息；更新个人参与记录（个案）；保持支援体系地图。

## 四、基线锚定与防回退

- 读取 `{{PREVIOUS_REPORT_PATH}}`（首期季度为空）与 `{{BASELINE_REPORT_PATH}}`，继承结构与全部已核实结论。
- 逐条继承「已修正事实清单」，产生修正后追加（格式见[通用基座第五节](../../engine/report_templates/prompt-generic-base.md)）；严禁重新引入已被推翻的说法；无来源不得入清单。
- 已修正事实清单以最新版报告文首为单一事实源；登记册不重复维护。

## 五、追踪表与登记册联动

按[业务配置第八节](./business-config.md)的 7 项追踪指标逐项核对并填写「是否更新」；运行前从 `{{REGISTRY_PATH}}` 读取活值与研究边界档案 → 复核有效性 → 运行后回写。数据变更摘要至少覆盖全部 7 项；未核实项单列「待复核清单」。prompt 模板内不填活值。

## 六、执行方式（建议）

1. 按调研维度并行启动研究子代理（劳动制度与职场调查 / 生活手续与自治体支援），全部限定日 / 英来源、逐点引用，每条数据附可直接访问的 URL。经验类内容作为个案沉淀单独标注。
2. 主代理读取 `{{PREVIOUS_REPORT_PATH}}` 与基线做差异合并，继承已修正事实清单，应用第三节更新要点。
3. 冲突数据保留双份引用；无法核实项单列「待复核清单」。
4. 回写报告与登记册后运行 `python engine/tools/md2html.py` 重新生成 HTML，并运行 `python engine/tools/lint_reports.py` 校验。

## 七、渲染与交付

- 交付格式：md + 同目录自包含 HTML；季度 / 年度报告含顶部九锚点导航（`.report-nav`），`.nav-url` = `{{REPO_RAW_URL_BASE}}` + `/reports/{本期文件名}`。
- HTML 须通过 `lint_reports.py` 标签配对校验。
- 月度报告常驻 `reports/` 顶层；每主题保留最新 12 期，超出移入 `reports/archives/`。

## 八、质量自检（通用清单之外的本主题专属项）

- [ ] 结构逐字继承基线（或经批准的九节骨架），无增删节、无顺序调整
- [ ] 已修正事实清单已继承并续写，无回退
- [ ] 法规义务与职场惯例已区分；经验类内容全部标注为个案
- [ ] 医疗章节未硬编码费率 / 上限，活值均落在 `{{REGISTRY_PATH}}`
- [ ] 与 09-politics-law、08-visa-immigration 的联动触发器正确
- [ ] 追踪表 7 项均已核对并填写「是否更新」
- [ ] `{{REGISTRY_PATH}}` 已读已写，变更摘要与登记册一致
- [ ] 数据变更摘要与待复核清单已产出
- [ ] HTML 通过 lint（标签配对）
